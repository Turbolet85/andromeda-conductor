Since 2026-09-07 the driven arm is no longer the SOLE carrier of Tab-traversal assertions: hold-free traversal and `document.activeElement` probing also run unattended on the routine arm.
- **Pattern:** scripted Tab / Shift+Tab traversal reading `document.activeElement` (`browser.execute(() => document.activeElement?.getAttribute('data-testid'))`) after each `browser.keys(['Tab'])`, asserting: run-console-HOLD `alertdialog` trap entry on open (over dimmed/inert console), Tab/Shift+Tab cycle staying inside the trap across the operator-checklist rows (reachable, `aria-checked` readable, Space-toggleable) and Proceed/Abort, Escape-escapable trap (SC 2.1.2), focus restoration to the triggering control on dialog close — asserted against the explicit `onCloseAutoFocus` / `restoreFocusTo` contract (target = the recorded hold invoker, never `<body>`), NOT a Radix default — and visible `--color-focus` ring on the active element (SC 2.4.7, paired with the contrast harness for the 3:1 ring).
