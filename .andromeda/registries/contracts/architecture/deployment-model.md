**Deployment model:** Local-only — `cargo build --release` produces the `conductor-cli` binary run beside Pulse via `scripts/agent-run.sh`; the Tauri 2 bundler produces the optional GUI installer set. The bundler is a HOST dev-tool (`tauri-cli` / `tauri-bundler`), absent from `Cargo.lock` — the tree resolves no bundler version at all, and the `2.11.3` this line long carried mirrored the `tauri` CRATE version, which is a different artifact and still correct. Its floor is met by the installed CLI, `tauri-cli` 2.11.4 on first install, and its output is the Windows installer set that `bundle.targets = "all"` yields on this host — **as measured 2026-09-10**: nsis 4.21 MB · msi 5.87 MB, both under gitignored `target/`. The MB scale is the durable fact and the byte count is not: two builds of the same source that day emitted nsis 4 418 544 B and then 4 414 280 B (msi 6 152 192 B both times), so a byte-exact installer size states more than this toolchain reproduces. The roster floor lives in test-plan §4. No Docker / Compose / Kubernetes / serverless — Pulse binds loopback `:4317`, so execution is necessarily co-located on the dev host.
