## Output Protocol

Rules for iteration agents working on the Conductor a11y plan (`a11y-plan-draft.md`):

1. **Output patches, not the document.** Emit only the specific `Old → New` text changes plus a changelog. Do NOT reproduce the full a11y plan, and do NOT re-emit unchanged sections.
2. **Patch format** — for each change:
   - `### Patch N: <short description>`
   - `**Old:**` followed by the exact verbatim text currently in the document (enough surrounding text to be unambiguous, copied character-for-character).
   - `**New:**` followed by the replacement text.
3. **Changelog** — after the patches, one line per change:
   - `[Iteration N] [substantive|cosmetic] <description>`
   - `substantive` = changes meaning, coverage, a tool/version, a WCAG SC mapping, a token pair, a constraint, or a binding contract. `cosmetic` = wording/typo/formatting only.
4. **PROHIBITED:**
   - Full document reproduction or wholesale section re-emission.
   - Restructuring (reordering sections, renaming headings, re-tabulating) without a stated correctness reason.
   - Cosmetic edits labeled `substantive`, or substantive edits hidden as `cosmetic`.
   - Inventing tools, versions, design tokens, or WCAG SCs not already anchored in the plan / upstream.
5. **If no issues are found:** output exactly `No patches` followed by a single cosmetic changelog line (e.g. `[Iteration N] [cosmetic] reviewed; no changes`).
6. **Patch budget discipline (8 patches max per iteration).** Spend the budget in priority order: all `[priority: high]` bucket-1 (Downstream-blocking) findings first, then `[priority: high]` bucket-2 (Implementation-misleading), then `[priority: medium]` bucket-3 (Signal-diluting) only when the fix is one line and undeferrable. A cosmetic patch that displaces a `substantive` bucket-1 fix is a budget defect. Do not split one logical fix across multiple state/section sites into separate patches if a single patch with adequate surrounding context covers them — but DO patch every site a value must agree at (a stale value left in one of N sites is still a live bug).
