# a11y extract

## No domain coverage
This chunk (log + error-boundary redaction at the Rust/CLI edge) has no a11y domain applicability: it operates below the UI surface (tracing-subscriber field-allowlist + anyhow error sanitization), with no interactive controls, focus management, ARIA roles, keyboard shortcuts, color contrast, or screen-reader announcements. a11y-plan §1 explicitly flags the CLI surface as "not-assertable" (no DOM / native widget tree). The desktop-webview UI surfaces that require a11y coverage are built in later chunks and are untouched by this redaction-layer scope.
