## Anti-patterns to avoid
- Never invent alternate status names or abbreviations (`[PASS-OK]`, `[HOLD-WAIT]`, etc.) — the crosswalk table defines the only six canonical names.

- Never render a Blocked row with literal `null` or struct debug output for unmeasured fields — emit em-dash or "(absent)" as the scope specifies.
