## Patterns to follow
- Semantic `banner` landmark wrapping the frameless titlebar (per a11y-plan §4 landmarks inventory).
- Semantic `<button>` elements for window controls (titlebar minimize/close) with `aria-label` for icon-only controls, never `role="button"` on `<div>`.
- Global visible focus ring via `--color-focus` token on every interactive control (`--border-emphasis` for selection-vs-focus distinction per a11y-plan §6).
- Real prose empty/in-progress states (not color-alone signal for state — six-state lamp text labels always paired, per a11y-plan §6 not-color-alone).

## Anti-patterns to avoid
- NEVER use `role="button"` on `<div>` (use semantic `<button>` for window controls).
- NEVER omit visible focus ring (`:focus { outline: none }` without `--color-focus` ring replacement is SC 2.4.7 violation per a11y-plan §11 Keyboard).
- NEVER skip landmark roles (frameless window MUST expose `banner` for titlebar per a11y-plan §11 Screen Reader).
