## Patterns to follow
- CSS-only motion: `@keyframes` pulse on count while `live` (gentle opacity/scale breath per scope.md); heartbeat halts on `hold` (SC 2.3.3 token-binding); resume on `proceed` restores `--count-nominal` (a11y-plan §6 Motion tokens).
- Token-naming discipline: count tint binds `var(--count-nominal)` / `var(--count-hold)` / `var(--count-blocked)` by NAME in Titlebar.css (never raw hex/px); `--motion-micro` / `--ease-quiet` for durations/curves (a11y-plan §6 Motion tokens).
- State-naming crosswalk: per a11y-plan §6 State-naming crosswalk (amended 2026-06-21), HOLD row carries `verdict == CalibrationRegion` + `state == ManualCheck`; phase-line text flip to "HOLD" + `aria-live="assertive"` signals the hold (a11y-plan-amendments.md 2026-06-21).

## Anti-patterns to avoid
- NEVER use motion as the only hold signal — text flip ("HOLD") + `aria-live="assertive"` + tint+freeze are co-required (a11y-plan §11 Motion).
- NEVER flash the `Fail`/abort lamp — hold motionless, no pulsing (a11y-plan §11 Motion, SC 2.3.1).
- NEVER autoplay motion without reduced-motion drop — count tint transition MUST collapse to none/0s under `prefers-reduced-motion: reduce` via CSS (a11y-plan §11 Motion, SC 2.3.3).
