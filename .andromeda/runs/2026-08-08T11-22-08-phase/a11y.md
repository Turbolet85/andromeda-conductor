- The six lamp states are closed: do not introduce a seventh state for the manifest fault; each of the six is token-backed and text-label + glyph paired (per a11y-plan §6 → State color tokens; §11 § Visual).

- The named precondition string, wherever it reaches a report artifact, must not carry an absolute host path or an internal seam-crate struct name (per a11y-plan §3 → Structured violation JSON schema; §9 CI Integration → CI-specific resource attributes; §11 § SLO).
- No a11y gate applies to this chunk's verification: the a11y lane exists only at the operator/local `wdio run` webview-E2E stage; the Unit row is explicitly n/a (per a11y-plan §9 CI Integration, per-pipeline-stage table).

## Patterns to follow
- Reuse the existing state enum rather than extending it — `Blocked` already exists in the envelope and already has its crosswalk row, token, and glyph (a11y-plan §6 → State color tokens).
- Verdict-first lamp precedence: a state with no verdict renders as its own lamp, so keep the manifest-fault row **verdict-free** (`verdict` n/a) exactly as the `Blocked` row specifies (a11y-plan §6 crosswalk; established by the 2026-06-21 amendment).
- Overflow detail rides `fingerprints[]`, never new top-level fields — the established channel for rule-id / tag / selector-style detail; a manifest-fault discriminator belongs there if one is needed (a11y-plan §3 → Structured violation JSON schema).
- Real-prose failure text: the precondition must read as human prose naming the manifest (which the chunk DoD already requires), not a bare code — this is what the downstream screen-reader must-announce list consumes (a11y-plan §3 → Screen reader test pattern; §11 § Visual).

## Anti-patterns to avoid
- NEVER let the manifest fault surface as a state distinguishable only by color/lamp treatment once rendered — the `Blocked` label + hollow-ring glyph pairing is mandatory (a11y-plan §11 § Visual).
- NEVER treat this chunk's cli/headless error output as an a11y verification path — ASCII prefixes / NO_COLOR pairing are output-stream discipline, not accessibility conformance (a11y-plan §11 § Universal).
- NEVER let the precondition or its artifact leak absolute host paths / internal struct names into the shared envelope (a11y-plan §11 § SLO).
