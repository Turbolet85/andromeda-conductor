## Constraints
- **Tier is Minimal (0), and the 7 critical paths are capped** — per test-plan §1 (Test Scope Summary / Critical paths) and §2 (pyramid). This chunk adds unit-tier assertions on existing seams; it must not mint an 8th critical path or a new E2E scenario.
- **Rendered-artifact assertions live at the unit tier with exact-string goldens** — per test-plan §4 (conductor-report bullet): the canonical shape is locked via exact-string `assert_eq!`, insta is reserved as the E2E journal-golden mechanism. The roll-up line change re-baselines the existing exact-string golden; it does not loosen it to a `contains`.
- **`conductor-tauri/ui` carries no Rust/nextest unit tests — build-gated only** (`tsc --noEmit` + `vite build` + `npm audit` + `vite preview` render smoke), webview coverage deferred to Epoch 9 — per test-plan §4 (conductor-tauri/ui bullet) and §9 (pipeline stages). The CSS/TSX treatment is proven by the build gate, not by an invented component-test driver.
- **The envelope's `verdict`/`state` vocabulary is frozen** — per test-plan §3 (Status endpoint shape). Tests parse those exact tokens, so the out-of-scope treatment may not introduce a sixth state token into any surface a test reads; and per §3 (`run` exit-code semantics) + §11 (E2E, stack-specific ban), a non-`Fail` classification must never become a non-zero exit.
- **Coverage assertions stay manifest-derived** — per test-plan §6 (Coverage-matrix completeness gate scenario, as amended 2026-08-09): set-equality against the accepted set, no literal count and no P-ID range. The new roll-up/denominator assertions inherit this.
- **CLI signal must survive `NO_COLOR` and piping via its text label** — per test-plan §1 (Surfaces / cli Signal) and §6 (cli driver row: NO_COLOR-stable labels).
- **Zero-flakiness, zero retries, `--fail-under-lines 60`** — per test-plan §10 (Zero-flakiness budget + Coverage thresholds). The renders are pure functions, so every new assertion must be deterministic with no sleep/retry.

The out-of-scope cell extends this exact pair (per test-plan §1 cli Signal, §6 cli driver).
- **Substring-denylist negative test over rendered output** — `D:\dev\projects\conductor\crates\conductor-cli\src\render.rs` (`renders_leak_no_host_paths_or_struct_names`) and `D:\dev\projects\conductor\crates\conductor-report\src\coverage.rs` (`no_host_paths_or_struct_names_leak`). The chunk's negative guarantee (`[FAIL]`/`[BLOCKED]` vocabulary absent from an out-of-scope row) is the same shape, per test-plan §3 (Status endpoint shape) + §11 (Test Data).

- **assert_cmd E2E piped-output check** — `piped_coverage_output_carries_no_ansi_escapes` in `cli_smoke.rs` is the existing headless proof that the treatment reads correctly under piping (per test-plan §6 cli driver row).

## Anti-patterns to avoid
- **NEVER hard-code a literal capability count, an out-of-scope count, or a P-ID range** in the new roll-up/denominator assertions — manifest-derived only (test-plan §6 completeness-gate scenario, as amended 2026-08-09; §11 Unit ban on brittle fixture-internal assertions).
- **NEVER assert the visual treatment via hashed Tailwind/CSS class names or xpath** — text/role + brand-anchor selectors only, which the never-color-alone rule guarantees (test-plan §11 E2E; §6 Selector strategy).
- **NEVER loosen a failing golden or the coverage threshold to absorb the new roll-up line** — re-baseline the exact string (test-plan §11 Quality; §10).

## Contract bindings
- **tests ↔ design-system / a11y:** the never-color-alone invariant is what makes the text-label selector reliable; the cli plain/colored pair and any webview assertion both key on the text label, never the token (test-plan §6 Selector strategy; §1 desktop-webview Signal).
- **tests ↔ obs:** the "no absolute host paths / no internal struct names in rendered artifacts" boundary is asserted here by the leak-negative test while the redaction layer itself is obs-owned (test-plan §3 Bootstrap phases → `log-format-bind-with-obs`; §3 Status endpoint shape).
- **tests ↔ arch/verdict model:** the frozen `verdict`/`state` token set in the Run-report envelope is the contract the negative guarantee is written against (test-plan §3 Status endpoint shape).
- **tests ↔ frontend build gate:** the `conductor-tauri/ui` treatment's CI coverage is the Lint/Build stage (`tsc --noEmit` + `vite build` + preview smoke), not a nextest stage (test-plan §4 ui bullet; §9 pipeline).
