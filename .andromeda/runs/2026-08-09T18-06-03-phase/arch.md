# arch extract

## Relevance
Partial — arch governs where the posture artifact lands (crate/surface), which contracts it may extend, and the env/resource registry it must respect; the interpretation-correctness *judgment* itself is a verify/report-domain concern.

## Constraints
- **Verdict/error wall is absolute** — an interpretation-correctness leg's outcome is a typed VALUE (`Verdict`/`ReportState`), never a `Result::Err`; `Err` stays reserved for harness faults (transport down, MCP unreachable, manifest unparseable) per arch §Established Decisions [Error Handling] + §Cross-cutting Patterns (Verdict/error wall).
- **Model-interpretive claims are calibration-region, never hard-fail** — "top hypothesis identifies the injected root cause" is exactly the model-interpretive class arch §Established Decisions [Probabilistic-Assertion Policy] names (it lists P-008 root-vs-deep weighting as a sibling); default mapping `CalibrationRegion→ManualCheck` via `Verdict::default_report_state`, lamp chosen verdict-first. Branch A cannot be a hard pass/fail assertion on an exact hypothesis string.
- **Coverage classification is code-native and set-equal to the manifest** — P-033's `CoverageMode::Auto` row lives in `coverage_matrix()` (a no-runtime-IO `static`); any reclassification is a Rust edit that `check_sut_drift` holds to set-equality against `contracts/pulse-capabilities.toml`, and an accepted id with no row is `CoreError::SutDrift` (arch §Established Decisions [Accepted Capability Set], as qualified by the 2026-08-09 amendment).
- **No scenario without a P-ID; the accepted set is manifest data** — a Branch-A leg must be keyed to a manifest-accepted P-ID (P-033), loaded via `Scenario::from_toml_str_with(&str, &CapabilityManifest)` at a binary-edge load site; a manifest miss is a harness fault, never `Blocked` (arch §Cross-cutting Scope law + §Established Decisions [Accepted Capability Set]).
- **Env-var namespace is closed to `CONDUCTOR_*`; `ANDROMEDA_PULSE_*` is Pulse-side** — `ANDROMEDA_PULSE_L4_DETERMINISTIC` is an SUT-owned flag in the same family as `ANDROMEDA_PULSE_MCP_ENABLED`/`_DATA_DIR`, which arch §Occupied Resources records as "asserted **not** set by Conductor itself"; if this chunk observes/propagates it, it must land in that registry (wrap amendment), not as a new `CONDUCTOR_*` handle.
- **Run-report envelope is the shared shape** — any caveat that travels with a green result must be additive to the pinned per-check envelope (`run_id`/`seed`/`scenario`/`p_ids`/`verdict`/`state`/`slo_tier`/…) with `verdict ∈ {Pass,Fail,CalibrationRegion}`, `state ∈ {Pass,Fail,ManualCheck,KnownResidual,Blocked}` — no sixth state, and the `runs.db` row shares the shape with column types fixed on first write, no migration framework (arch §Standard Contracts + §Conventions Data model).
- **Live legs are never a CI gate** — dynamic proof requiring a live Pulse is an operator/local gate; CI runs `cargo build`/nextest (zero-retry `ci` profile)/clippy only (arch §Established Decisions [CI/CD] + §Infrastructure Patterns CI/CD approach), which independently forbids a non-deterministic real-model leg in the CI test set.

## Patterns to follow
- **Crate-per-seam placement** (arch §Established Decisions [Module Boundaries] + §Infrastructure directory tree): hypothesis-assertion/verdict logic → `conductor-verify`; scenario/coverage types + `coverage_matrix()` → `conductor-core`; report-envelope + Markdown + `runs.db` → `conductor-report`; any orchestration → `conductor-run`; presentation-only caveat rendering → `conductor-cli` (owo-colors/comfy-table, tty-gated, never color-alone). Cross-seam edges are `Cargo.toml` edges; a forbidden one won't compile.
- **Blocked-with-named-precondition** (arch §Standard Contracts readiness gate): the existing shape for "we could not measure this, and here is why" — identity fields populated, `verdict`/`latency_ms`/`fingerprints` JSON `null`, `blocked_precondition` naming the missing precondition. A Branch-B deferral or an unrunnable real-model leg reuses this rather than inventing a new signal, and cross-run latency/percentile queries MUST keep excluding NULL-measurement rows.
- **KnownResidual for pre-accepted deviation** (arch §Established Decisions [Read-Back Dependency Posture]): the state that distinguishes an accepted, recorded gap from a real `Fail` — the natural envelope home if the deferral is to travel with run artifacts.
- **Declarative TOML + garde at load** (arch §Conventions Config conventions + §Established Decisions [Scenario Config Format]): a P-033 scenario is a `scenarios/*.toml` file, serde-deserialized, bounds-checked with garde co-located in the owning seam crate — `CoreError::Config` on parse, `CoreError::Validation` on garde.
- **Two-source drift assertion** (arch §Established Decisions [Accepted Capability Set]): manifest data vs code-native classification compared by `check_sut_drift` — deliberately not collapsed into a self-check. Any posture touching P-033's classification keeps both sources and the equality assertion.

## Anti-patterns to avoid
- **Do not add a report state or verdict variant** for "interpretation unverified" — the two enums are pinned in §Standard Contracts; use `CalibrationRegion`/`ManualCheck`/`KnownResidual`/`Blocked`.
- **Do not introduce a new `CONDUCTOR_*` env handle** for SUT-mode observation, and do not have Conductor *set* `ANDROMEDA_PULSE_*` (arch §Occupied Resources asserts Conductor does not set the Pulse-side gates; `CONDUCTOR_AGENT_MODE` precedent is read-only, never written).
- **Do not put a real-model, non-deterministic leg behind `cargo nextest`/CI** — it breaks the zero-retry `ci` profile and the determinism-under-seed discipline (arch §Infrastructure Build system + §Cross-cutting Determinism discipline).

## Contract bindings
- **Run-report envelope ↔ report/design/a11y/tests**: any caveat field or lamp affecting a green result binds `conductor-report` Markdown, the `runs.db` row shape (column types fixed on first write), the `conductor-cli` table/lamp rendering, and the webview — arch §Standard Contracts is the shared shape all four consume; lamp precedence is verdict-first (per the 2026-06-21 amendment).
- **Coverage classification ↔ tests/docs**: `coverage_matrix()` ↔ `contracts/pulse-capabilities.toml` set-equality (`check_sut_drift`) and the `coverage-matrix.md` artifact — arch §Occupied Resources names `coverage-matrix.md` as "every capability in the SUT capability manifest classified" (the definition-of-done under §Cross-cutting Scope law).
- **Preflight readiness gate ↔ security/tests**: SUT-mode observation (`ANDROMEDA_PULSE_L4_DETERMINISTIC`) would extend the readiness result shape in arch §Standard Contracts; arch scopes that assertion to Epoch-2 `v2-18`, so this chunk should bind to it by reference, not extend it.
- **Dependency-floor changes ↔ security**: a `cargo-audit` floor raise touches arch §Infrastructure Patterns Build system tooling only via the security-plan's authoritative §Dependency Security (the 2026-08-08 anyhow precedent: arch carries derived version echoes, security-plan owns the decision).

## Acceptance criteria contributions
- (arch) Any new code lives in the correct workspace crate per §Established Decisions [Module Boundaries] — verify logic in `conductor-verify`, coverage/scenario types in `conductor-core`, envelope/artifact in `conductor-report`, orchestration in `conductor-run`, presentation in `conductor-cli` — with no new cross-seam `Cargo.toml` edge beyond the existing graph, and no 10th workspace member unregistered in §Occupied Resources.
- (arch) The interpretation outcome is a typed value, not an error: a Branch-A hypothesis check returns `Verdict::CalibrationRegion` (→ `ManualCheck`) rather than hard-failing on an exact hypothesis match, and `Result::Err` appears only for harness faults (§Probabilistic-Assertion Policy + §Error Handling).
- (arch) Any recorded posture/caveat conforms to the §Standard Contracts run-report envelope — no new `verdict`/`state` variant, `runs.db` columns unchanged or additive-with-fixed-types, and NULL-measurement rows still excluded from cross-run latency/percentile and P-036 fingerprint queries.
- (arch) No new env var beyond the `CONDUCTOR_*` namespace, and Conductor does not write any `ANDROMEDA_PULSE_*` flag (§Occupied Resources); no real-model leg enters the CI test set (§CI/CD — operator/local gate only).
