# security extract

## Relevance
Relevant — the chunk touches three named security surfaces: the preflight readiness gate's `blocked_precondition`, the hardened sidecar spawn / `ANDROMEDA_PULSE_DATA_DIR` env handle, and artifact hygiene on an operator-facing string; plus a folded-in dependency-audit gate re-check.

## Constraints
- The detected workspace-key divergence MUST surface as the distinct `blocked` state with a **named** precondition string — never silently downgraded to pass / fail / manual-check, and never a false pass-as-empty for the zero-row `query_incident_list` canary (per security-plan §Security Anti-Patterns → Universal; §Security Anti-Patterns → Input, empty-canary rule).
- The precondition string, the run report (`<run_id>.md`), `runs.db` rows and JSONL journals MUST carry verdict/state/identity fields only — no absolute host paths (the canonicalized `CONDUCTOR_*` dirs, `ANDROMEDA_PULSE_DATA_DIR`, the detected project root) and no internal seam-crate struct/field names (per security-plan §Error Handling → Run-report artifact sanitization; §Security Anti-Patterns → Logging).
- A `blocked` row populates only identity fields with the named precondition string; measurement fields stay JSON `null` (per security-plan §Error Handling → Run-report artifact sanitization).
- A divergence detection is a typed `Blocked` VALUE returned as `Ok(...)`; `Result::Err` stays reserved for harness faults and a malformed child/transport input MUST NOT panic — JSON-RPC errors / decode faults route through `VerifyError::{JsonRpc,Decode,Transport}` (per security-plan §Error Handling → Internal logging; §Security Anti-Patterns → Universal, verdict/error wall).
- Any reading or comparison of the sidecar's data-dir key MUST keep the spawn hardening intact: fixed hard-coded `andromeda-pulse-mcp` program path, `ANDROMEDA_PULSE_DATA_DIR` passed strictly via `.env(...)` with argument-injection metacharacters rejected before spawn — never interpolated into argv or a shell (per security-plan §Input Validation, `ANDROMEDA_PULSE_DATA_DIR` row; §Security Anti-Patterns → Input, Code Patterns).
- Conductor's production code MUST NOT open, copy, or exfiltrate Pulse's `corpus.db` (plaintext SQLite) to diagnose the divergence — corpus access is via MCP read-back only, and no corpus content is persisted into Conductor artifacts (per security-plan §Security Anti-Patterns → Data Protection; §Data Protection).
- The audit gate re-check is an advisory-**DATABASE** fault under a bounded wait: re-check each chunk, verify `cargo deny check advisories bans licenses sources` actually ran green as the overlapping signal — never raise the floor, never add a `deny.toml` ignore, never edit CI, never silently accept (per security-plan §Dependency Security, two-fault split; §Security Anti-Patterns → Universal).

## Patterns to follow
- Preflight readiness-gate blocked-precondition pattern: the existing three modes (protocol mismatch · missing tool · empty canary) each map a failed precondition to a named string with no path content — the new divergence precondition follows that same shape (per security-plan §Input Validation, pinned-MCP-contract-manifest row; §Threat Model Summary → MCP read-back attack surface).
- `e.kind()`-only fault reporting: the committed SUT-facing manifest loaders record read faults by error kind, never by path — the same discipline applies to any workspace-key / data-dir comparison surfacing a fault (per security-plan §Input Validation, committed-SUT-facing-manifests row).
- `resolve_under` traversal guard on any artifact path derived from `CONDUCTOR_RUNS_DIR` (report/journal/log sinks that receive the precondition string) — reuse the shipped guard rather than re-deriving path handling (per security-plan §Input Validation, non-path env-handle note).
- `thiserror` typed enums inside `conductor-verify`, collapsed to `anyhow` only at the `conductor-cli` / `#[tauri::command]` edges, with sanitization at that edge (per security-plan §Error Handling → Error format).
- Bounded line-delimited JSON-RPC decoding of child stdout (serde_json recursion limit + soft per-line size bound) for any additional read-back call used to observe the divergence (per security-plan §Input Validation, MCP-read-back-child-stdout row).

## Anti-patterns to avoid
- NEVER embed an absolute host path (detected project root, `data_dir`, `ANDROMEDA_PULSE_DATA_DIR`) in the precondition string, stderr, run report, `runs.db`, or the journal — the artifacts are agent-parseable ground truth shared across hosts (per security-plan §Security Anti-Patterns → Logging; §Security Anti-Patterns → API, internal-error-detail ban).
- NEVER let the divergence become a `Result::Err`, a panic, or a generic pass/fail — a silently downgraded preflight is the exact class the readiness gate exists to prevent (per security-plan §Security Anti-Patterns → Universal).
- NEVER work around the divergence by spawning the sidecar from an operator-chosen command, by interpolating a workspace/data-dir value into argv or a shell, or by having Conductor touch Pulse's corpus code or `corpus.db` directly (per security-plan §Security Anti-Patterns → Input, Code Patterns, Data Protection).

## Contract bindings
- **Artifact hygiene** binds to obs (journal/report field schema — the precondition string is an emitted value that must stay path-free) and to tests (a fixture asserting no absolute-path substring in the precondition / report row).
- **Blocked precondition string** binds to architecture §Standard Contracts (readiness-result shape) — this chunk adds a value to an existing field, not a new field or new failure mode.
- **Dependency-audit gate** binds to tests §CI Integration — the audit/deny gate is a job in the single existing workflow; the bounded wait must not alter it (per security-plan §Dependency Security → CI integration).

- (security) A simulated workspace-key mismatch yields `ReportState::Blocked` with a distinct named precondition string returned as `Ok(...)` — not `Err`, not a panic, not pass/fail/manual-check (per security-plan §Security Anti-Patterns → Universal, readiness-gate rule).
- (security) The precondition string and any run-report / `runs.db` / journal row carrying it contain no absolute host path and no internal seam-crate struct name; grep/assert over the emitted artifact verifies (per security-plan §Error Handling → Run-report artifact sanitization).
