## Anti-patterns to avoid
- Do **not** add a seventh lamp / seventh bracket label / sixth `ReportState` for a contract term — the set is closed and downstream agents parse it (per layout-templates §cli Component — Primary content block 2 · §cli IA notes → Command model).
- Do **not** render an unmet term red or as `[FAIL]`, and do not let it collapse into a `Fail` roll-up — `Blocked` ≠ red, it was never measured (per layout-templates §desktop-webview Component — Primary content block 2).
- Do **not** signal any new state by color alone or add a `comfy-table` column without a `--format` flag (a column addition is a breaking change to the parsed shape) (per layout-templates §cli Primary content block 1 · §cli IA notes).
