## Constraints
- No WCAG assertion is owed by this chunk: it adds no DOM/widget tree, and the CLI/headless run path is explicitly not-assertable — a11y's only assertable surface is the desktop-webview (per a11y-plan §1 A11y Scope Summary, §1 Critical paths).
- The obs §6 Run-report envelope is reproduced VERBATIM in two places in a11y-plan; any field-name/type change to that envelope by this chunk requires amending both reproductions in the same wrap (per a11y-plan §3 Structured violation JSON schema).
- `report.generate`'s `verdict` / `state` attributes must carry the exact obs enum spellings (`Pass|Fail|CalibrationRegion` / `Pass|Fail|ManualCheck|KnownResidual|Blocked`) — a11y's lamp→journal-row join and verdict-first HOLD precedence key on them (per a11y-plan §6 State color tokens — State-naming crosswalk).
- New span fields must clear the redaction boundary: no absolute host paths, no internal seam-crate struct names in the shared journal envelope — a11y artifacts fold into that same envelope and inherit the constraint (per a11y-plan §11 SLO, §9 CI-specific resource attributes).
- Service identity on the shared sinks (`service.name` = `"conductor-tauri"` / `"conductor-ui"`, `deployment.environment` = `CONDUCTOR_ENV`) plus `run_id` is the cross-correlation key a11y artifacts use — keep it stable/unshadowed (per a11y-plan §1 Service identity tagging, §2 Naming conventions).
- Focus-lifecycle spans (`focus.shift` / `focus.trap.enter` / `focus.trap.exit` / `focus.restore`) are a standing a11y recommendation to obs, NOT this chunk's to add — do not invent them here, and do not adopt a span-naming convention that would preclude the dotted family later (per a11y-plan §3 Focus management test harness).

## Patterns to follow
- Envelope-fold discipline: auxiliary detail rides inside existing fields (a11y folds axe rule-id + WCAG tag + selector into `fingerprints[]`) rather than introducing new top-level envelope fields — mirror that if per-span detail needs to reach the journal (per a11y-plan §3 Structured violation JSON schema).
- Verdict-first row reading: a row with `verdict == CalibrationRegion` is HOLD regardless of `state`; a `ManualCheck` state with no verdict is `Manual` (per a11y-plan §6 State-naming crosswalk).
- Artifact channel reuse: a11y results surface through tests' existing 5-command `logs` command rather than a parallel emitter — the chunk's reuse of the shipped agent-mode log-schema conformance scaffold matches this "one stack, no parallel harness" posture (per a11y-plan §3 CI integration, §9 Pipeline integration).
- Dotted span-name family (`verify.readback.*`) is the established convention a11y's recommended `focus.*` names assume — reconciling by renaming shipped spans is not required by a11y (per a11y-plan §3 Focus management test harness).

## Anti-patterns to avoid
- NEVER treat the cli / headless surface as accessibility-assertable — its ASCII prefixes / NO_COLOR pairing are output-stream discipline, not an a11y verification path (per a11y-plan §11 Universal).
- NEVER let artifacts leak absolute host paths or internal seam-crate struct names into the obs §6 envelope (per a11y-plan §11 SLO).
- NEVER treat span-tree coverage of a run as WCAG evidence — conformance claims require axe-core / colorjs.io / WebdriverIO JSON (per a11y-plan §11 Strategy).
