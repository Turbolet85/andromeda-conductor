# arch extract

## Relevance
Relevant — the chunk adds instrumentation inside two locked workspace crates (`conductor-run`, `conductor-report`) and edits a crate's dependency edge, both squarely arch-governed.

## Constraints
- Code lands in the existing locked workspace members `conductor-run` (composition root, above the seams and below both bins) and `conductor-report` (JSONL journal + Markdown report + `runs.db` storage seam); no new crate, and the root span in `conductor-run` is what gives CLI↔Tauri parity for free (per architecture.md §Occupied Resources — Crate names, §Infrastructure Patterns — directory structure).
- `tracing` 0.1.44 + `tracing-subscriber` 0.3.23 is the pinned self-observation stack and is explicitly NOT an OTel SDK — OTLP is the PRODUCT emission only (per architecture.md §Stack and Technologies — Self-observation).
- Adding `tracing` to `conductor-report`'s `[dependencies]` is an external-crate edge, not a cross-seam edge; the crate-per-seam rule only forbids seam→seam dependency edges, and `conductor-report` must not gain a dependency on another seam crate to satisfy the chain (per architecture.md §Established Decisions [Module Boundaries], §Design Philosophy — compiler-enforced module seams).
- The verdict/error wall holds: `Verdict`/`ReportState` remain values recorded as span fields; instrumenting `report.generate` must not convert an outcome into `Result::Err` nor `Result::Err` into a verdict (per architecture.md §Cross-cutting Patterns — Verdict/error wall, §Established Decisions [Error Handling]).
- No new `CONDUCTOR_*` env var, no new on-disk artifact: the two self-obs sinks `logs/agent-latest.jsonl` and `logs/conductor-tauri.jsonl` are already-registered resources and only gain fields (per architecture.md §Occupied Resources — Environment variables, On-disk artifacts).
- Span field values must respect the registered identity/format conventions: `run_id` is the filesystem-safe hyphen-delimited stamp, `seed` is the scenario seed, `p_ids` are manifest-accepted `P-NNN` ids, and `verdict ∈ {Pass, Fail, CalibrationRegion}` / `state ∈ {Pass, Fail, ManualCheck, KnownResidual, Blocked}` (per architecture.md §Standard Contracts — Run report envelope, Timestamp formats).
- Instrumentation must not perturb determinism: no clock reads substituted into journal-relative math, no additional runtime tasks/threads spawned under the `current_thread` flavor to carry spans (per architecture.md §Cross-cutting Patterns — Determinism discipline, §Established Decisions [Async Runtime Flavor]).

## Patterns to follow
- Composition-root instrumentation: `conductor-run` already holds `execute_scenario` / `persist` / `drive_run` as the single pipeline both bins call, so one root span there is the established "instrument once, inherit in both shells" pattern (arch §Occupied Resources — Crate names; §Established Decisions [Workspace / Core Structure]).
- Existing seam-local span sites (`conductor-timeline`, `conductor-emit`, `conductor-verify`) instrument in-place inside their own crate with no cross-crate plumbing — `conductor-report` follows the same shape rather than routing events upward.
- Sink routing via `conductor_core::ObsSink` (the shipped `ObsWriter`/`ObsSink` enum-dispatch that already serves `agent-latest.jsonl` and `conductor-tauri.jsonl`) — reuse it, do not add a second sink path (arch §Occupied Resources — On-disk artifacts; amendments 2026-06-24 ×2).
- New external dep registration precedent: a new audit-green crate/edge is recorded in §Stack / §Occupied Resources at wrap rather than silently absorbed (arch §Stack and Technologies; the serde_json/toml/clap precedent).
- Raw-SQL storage seam stays synchronous and off the async runtime — `db.insert_run` instrumentation wraps a synchronous `rusqlite` call (arch §Established Decisions [Database], [Run-History Persistence]).

## Anti-patterns to avoid
- Do not introduce an OTel SDK, an `opentelemetry-*` tracing bridge, or any OTLP export of self-observation — the only OTLP egress is the product fault stream to `127.0.0.1:4317` (arch §Stack and Technologies — Self-observation; §Occupied Resources — Ports).
- Do not add a cross-seam `Cargo.toml` edge (e.g. `conductor-report` → `conductor-verify`/`conductor-run`) to reach span context; a forbidden edge is designed to fail to compile (arch §Established Decisions [Module Boundaries]).
- Do not emit host paths, `data_dir`, or internal struct names as span fields — every self-obs surface is host-path-free/redacted (arch §Standard Contracts — readiness-gate precondition strings are host-path-free; §Cross-cutting Patterns — Trust boundary).

## Contract bindings
- **arch ↔ obs**: obs-plan §4 Critical Path 1 names the chain and the required attributes; arch supplies the crate placement and the locked `tracing` (non-OTel) stack the chain must be built on. The `run_id`/`seed`/`scenario`/`p_ids` and `verdict`/`state` field values bind to the §Standard Contracts run-report envelope (same names, same closed enums).
- **arch ↔ security**: the new span fields cross the tracing field-allowlist / `anyhow`-edge redaction boundary; arch's host-path-free + no-secrets trust boundary is the rule those fields must clear.
- **arch ↔ tests**: verification asserts parent/child linkage over the emitted JSON in `logs/agent-latest.jsonl` — an arch-registered on-disk artifact whose location moves with `CONDUCTOR_RUNS_DIR`, so the test harness must resolve it through that handle rather than a fixed path.
- **arch ↔ CI**: any workspace `cargo build`/`nextest`/`clippy` touching `conductor-tauri` requires `ui/dist` built first (`generate_context!` compile-time resolution) — relevant because this chunk's Tauri-parity claim compiles that bin.

## Acceptance criteria contributions
- (arch) The root span lives in `conductor-run` and the two terminal spans in `conductor-report`; no new workspace member is added and no seam→seam `Cargo.toml` edge appears (per architecture.md §Occupied Resources — Crate names, §Established Decisions [Module Boundaries]).
- (arch) `conductor-report`'s only new dependency is the workspace-pinned `tracing` 0.1.44 (external crate, `[workspace.dependencies]`-inherited); no `opentelemetry-*` / OTel-SDK crate enters any crate, and `cargo audit` / `cargo deny check` stay green (per architecture.md §Stack and Technologies — Self-observation, §Infrastructure Patterns — Build system).
- (arch) No new `CONDUCTOR_*` env var and no new on-disk artifact: `logs/agent-latest.jsonl` / `logs/conductor-tauri.jsonl` gain fields only, still written via `conductor_core::ObsSink` as siblings of the runs dir under `CONDUCTOR_RUNS_DIR` (per architecture.md §Occupied Resources — Environment variables, On-disk artifacts).
- (arch) Span field values use the registered forms — `run_id` hyphen-delimited filesystem-safe stamp, `verdict`/`state` from the closed three/five-variant sets — and carry no host path, `data_dir`, or internal struct name (per architecture.md §Standard Contracts — Run report envelope + Timestamp formats).
