## Relevance
Partial — the chunk is a backend dispatch layer with no new surface, but it feeds two shipped cli output elements (the heartbeat live counter, the run-level load-envelope caption) and can move derived counts that the layout plan pins.

## Constraints
- cli stdout structure is a parse contract for downstream agents: adding a `comfy-table` column or a new output element without a `--format` flag is a breaking change — a per-phase emission dispatcher must not introduce new stdout lines or columns (per layout-templates §Surface: cli — IA notes → Command model).
- The per-P-ID bracket/lamp set is **closed at six** (`[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`); stdout carries exactly one additional **run-level, non-lamp** label, `[ENVIRONMENT-SUSPECT]`. An emission-shape condition may not become a seventh lamp or a sixth `ReportState` (per layout-templates §Surface: cli — Component: Primary content block 2).
- The load-envelope caption is printed **once per run, above the verdict lines, outside the lamp column**, ANSI 246, ASCII label always printed, and **omitted entirely** when the run is in-envelope or pinned exempt. If this chunk's fork changes what `check_load_envelope` can assert, the caption's trigger condition changes and its shape must stay exactly this (per layout-templates §Surface: cli — Output structure `conductor run` + §Primary content block 2).
- The `indicatif` heartbeat is the only live-counter surface during a run — it carries count + step index + the live counter on one line, spinner appears only after ~200ms (honest progress), and on HOLD it **stops in place**, never hides and never animates to 100% (per layout-templates §Surface: cli — Expression level + §Component — Hero / signature output).
- Pipe discipline: raw artifact data on stdout, human messages on stderr; errors are `error: <short>` + detail + `hint: <fix>`, sanitized of absolute host paths / internal struct names / stack traces, stack traces only under `--debug`/`-v`. A reported primitive gap is a stderr message, not stdout noise (per layout-templates §Surface: cli — Component: Footer / terminator + error output; §IA notes → Pipe discipline).
- Headless invariant: the agent-driven path is **never** gated on an interactive prompt — the dispatcher must add no `inquire`/TTY-dependent step to the emit path (per layout-templates §Surface: cli — IA notes → Headless invariant).
- Derived counts render identically on all three surfaces and are **never literals** — the coverage roll-up's `(N unbacked)` qualifies the auto term only, is never a fifth summand, and reaches the webview via the coverage matrix's `unbacked` prop from the `unbacked_auto` command (per layout-templates §Surface: cli — Primary screens → `conductor coverage [--write]`).

## Patterns to follow
- **Run-level qualifier precedent** — if the dispatcher must surface a run-scoped condition (e.g. a declared shape it could not realize), reuse the `[ENVIRONMENT-SUSPECT]` shape: ANSI 246 (Residual-mute reuse, no new token), rides outside the lamp column, alters no per-check state, ASCII label always printed, omitted when not applicable (layout-templates §cli Output structure `conductor run`).
- **Mode-cell recessive-treatment precedent** — a classification that is *remit*, not an outcome, gets the recessive `--status-residual` ↔ ANSI 246 ↔ Markdown-emphasis treatment with the label always rendered, deliberately not `--status-fail`/`--count-blocked` (layout-templates §Component — Primary content block 1, coverage matrix).
- **Heartbeat line composition** — emission counting lands inside the existing single heartbeat line (`⠹ {count}  step {n}/{m}  {live counter}`), not as a new per-phase print (layout-templates §cli Output structure `conductor run` + §Hero / signature output).
- **Tokens adapted, never forked** — anything visual emerging here reuses the existing name↔ANSI mappings (`count-nominal` ↔ 114, `count-hold` ↔ 179, `status-fail` ↔ 203, `count-blocked` ↔ 60, `color-id-cyan` ↔ 117, journal-text ↔ 146) (layout-templates §cli IA notes → Multi-surface coordination).

## Anti-patterns to avoid
- Do **not** add a bracket label, lamp state, or `comfy-table` column for emission shape — six per-P-ID labels + one run-level qualifier is the complete stdout label set, and a silent column addition breaks agent parsers (per layout-templates §cli Primary content block 2 + §IA notes Command model).
- Do **not** render an unrealizable / mismatched emission shape as a red `Fail` or as `Blocked` — no-surprise-failure rule; a pre-accepted or out-of-remit condition is never red (per layout-templates §Component — Primary content block 2, distinct non-result states).
- Do **not** emit per-phase dispatch chatter to stdout or add cursor manipulation / full-screen redraw for a live emission view (ratatui deliberately omitted; linear top-to-bottom stdout only) (per layout-templates §cli Component — Primary navigation).

## Contract bindings
- **layouts ↔ obs** — the `emission_count` this chunk produces feeds both obs-plan §4 CP1's `timeline.execute` span attribute and the cli heartbeat's live counter; they must be the same number, and the heartbeat's per-phase display must not be derived from a second, independent tally (layout-templates §cli Hero / signature output ↔ obs-plan §4 CP1).
- **layouts ↔ architecture (load envelope)** — the `[ENVIRONMENT-SUSPECT]` caption is the *only* rendered surface of `check_load_envelope`; if the fork adds a rate/occurrence-count field and the "declared-not-derivable" justification stops holding (architecture §Occupied Resources), the caption's trigger set changes and that change is a layout-surface event, not a silent widening (layout-templates §cli Output structure `conductor run`).
- **layouts ↔ scenario catalog** — if the fork moves shape into `scenarios/*.toml` and any edited scenario newly names a P-ID, `conductor_core::UNBACKED_AUTO` shrinks and the `(N unbacked)` roll-up qualifier moves on all three surfaces (cli · Markdown artifact · webview header strip via the `unbacked` prop) (layout-templates §cli Primary screens → `conductor coverage`).
- **layouts ↔ a11y / NO_COLOR** — every status stays paired with its ASCII prefix so it survives `NO_COLOR` / piping / screen readers; a11y derives conformance from that pairing (layout-templates §Surface: cli signature-placement footnote).
