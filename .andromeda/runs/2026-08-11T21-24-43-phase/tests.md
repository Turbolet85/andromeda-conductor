## Constraints
- Unit tier is the bulk of the suite: dispatcher phase→primitive selection is per-seam crate-local `#[cfg(test)] mod tests` under `cargo nextest run -p conductor-run`; do not push this to E2E (E2E is the 7 critical paths only) (per test-plan §2 Test pyramid + §4 Conventions).
- `conductor-emit` wire assertions in CI go through the loopback tonic `TraceService`/`LogsService` stub over `tokio-stream::TcpListenerStream` on ephemeral `127.0.0.1:0` — never `:4317` (reserved for the Epoch-4 port-occupier), and never a live-Pulse leg (per test-plan §2 Integration row + §11 project-specific).
- Determinism is a hard bar: assert seeded stream shape, drive scheduling with `#[tokio::test(flavor="current_thread", start_paused=true)]` + `tokio::time::advance`, never a real elapsed duration; any dispatcher randomness must come from the seeded RNG with a deterministic replay path (per test-plan §2 Agent-runnable invariants + §11 Unit).
- If the fork extends `EmissionSpec`, the new fields need a valid/invalid garde fixture matrix (range + `#[garde(custom)]` cross-field) as rstest `#[case]` rows, plus the property-test leg over the cross-field invariants (per test-plan §1 Coverage triggers → Vector 2 / property-test + §4 Scenario-config validation surface).
- Scenario TOMLs stay the committed declarative fixtures one-per-P-ID under `scenarios/`; a migration must leave every committed file load-validating and must not introduce developer-seeded data (per test-plan §7 Seed strategies + Self-bootstrapping requirement).
- The `emission_count` obligation lands on the self-obs span line, NOT the Run-report envelope — the two schemas must not be conflated, and journal/report stamps never come from the virtual clock (per test-plan §3 Log format).
- Quality gates bind: `--fail-under-lines 60` (line ≥60%, function ≥70%) and a zero-flakiness budget — no nextest `retries`, quarantine-and-fix (per test-plan §10).

## Anti-patterns to avoid
- Never bind `:4317` or make any real network call in a test — ephemeral loopback stubs only; the live egress leg is the local/operator gate (per test-plan §11 Universal + project-specific).
- Never assert on real wall-clock elapsed time or use an unseeded generator/unordered iteration to produce a stream under assertion (per test-plan §11 Unit + Test Data).
- Never force-fit wiremock onto the gRPC egress, and never mock the pure functions under test (dispatcher selection, garde validation, envelope serialization are tested directly) (per test-plan §8 What NOT to mock + §11 Mocking).
