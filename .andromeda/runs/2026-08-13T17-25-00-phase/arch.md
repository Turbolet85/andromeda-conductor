# arch extract

## Relevance
Relevant — the chunk is governed by arch's determinism discipline, lives inside locked workspace crates, and the CARRY edits a registered `contracts/` artifact + its core-side check.

## Constraints
- Determinism is an architectural property, not a test convention: "same scenario + seed ⇒ same emission stream shape" is enforced by the `current_thread` runtime flavor + a seeded `ChaCha8Rng` (`seed_from_u64`) as the scheduler's SOLE non-determinism source; the emission golden must freeze that shape, not a re-derived one (per architecture.md §Design Philosophy, §Established Decisions [Determinism RNG], §Cross-cutting Patterns · Determinism discipline).
- Journal/wall-clock stamps come from `std::time::SystemTime`/`Instant` and NEVER tokio's virtual clock; conversely a golden captured under `start_paused` must contain no `std::time` value — the two clocks may not cross into a committed snapshot (per architecture.md §Cross-cutting Patterns · Determinism discipline, §Data model conventions).
- Test/replay code stays inside the crate that owns the seam: timeline replay + pacing goldens in `conductor-timeline`, `check_load_envelope` in `conductor-core`; crate-per-seam edges are the architecture and a cross-seam dep that violates them must not be introduced (per architecture.md §Established Decisions [Module Boundaries], §Occupied Resources · Crate names).
- The load envelope is a **transcribed SUT record, never a Conductor measurement**; `contracts/pulse-load-envelope.toml` is runtime-read + bounds-checked at load via a fixed `LoadEnvelope::default_path()` through `resolve_under` with deliberately NO `CONDUCTOR_*` override handle — the re-scope may not add one (per architecture.md §Occupied Resources · On-disk artifacts).
- The rate terms are recorded as *derivable but deliberately not yet asserted*, with the exemption ledger held to exact-set equality in both directions so it can only shrink under compulsion; re-scoping to emitting-phase duration + retiring the exemptions is explicitly carried as chunk work — so (a)+(b)+(c) land together or the gate reads as ledger rot (per architecture.md §Occupied Resources · `contracts/pulse-load-envelope.toml`).
- A malformed/absent/unparseable contract manifest is a **harness fault** (`CoreError`, `Result::Err`), never a verdict/report state and never a silent widening; the verdict/error wall applies in every seam crate (per architecture.md §Established Decisions [Accepted Capability Set], [Error Handling]; §Cross-cutting Patterns · Verdict/error wall).
- Dependency posture: this is test-surface + a core-side re-scope; no new crate belongs in `[workspace.dependencies]`, and the `cargo audit` / `cargo deny` pair is the standing gate (`deny.toml` exceptions are inline-justified, audit + deny stay green) (per architecture.md §Infrastructure Patterns · Build system).

## Patterns to follow
- Insta golden snapshots under `crates/conductor-timeline/tests/snapshots/`, one committed file per seed, frozen through the full `Scenario::from_toml_str → PhaseTimeline::from → run_timeline` pipeline — the emission golden extends this existing shape rather than inventing a second mechanism (per architecture.md §Infrastructure Patterns · Build system, dev-test stack incl. insta/proptest/rstest).
- Zero-retry `ci` nextest profile in `.config/nextest.toml` — no retries mask flakes, because retry-masking is precisely the determinism invariant's blind spot; a seed-space replay property must pass on first run (per architecture.md §Infrastructure Patterns · Build system).
- Declared-data emission model: `EmissionSpec { signal, occurrences, shape }` with `occurrences: 0` as a deliberate silence window and `EmissionShape::Error { error_percent: u32 }` (integer, so `PhaseSpec`/`Scenario` keep `Eq`) — the golden's per-phase identity should key off this declared shape, and `Eq` is what makes snapshot comparison sound (per architecture.md §Conventions · Config conventions).
- Contract-artifact loading convention shared by all four `contracts/` manifests: fixed `default_path()` → `resolve_under` → serde + garde bounds-check at load → `CoreError` on failure (per architecture.md §Occupied Resources · On-disk artifacts).
- Naming: snake_case Rust files/identifiers, `conductor-<seam>` kebab crate names, kebab-case on-disk artifacts — snapshot filenames follow the existing `replay__fixture_seed_<n>.snap` convention (per architecture.md §Conventions · Naming patterns).

## Anti-patterns to avoid
- Do NOT let a `std::time` instant, host path, or wall-clock-derived value enter a committed golden — it destroys replayability and leaks host state (per architecture.md §Cross-cutting Patterns · Determinism discipline; §Standard Contracts · precondition strings are host-path-free).
- Do NOT reach for a second RNG, a `StdRng`, a multi-threaded runtime, or ambient `HashMap` iteration order to produce the emission stream — `ChaCha8Rng` under `current_thread` is the only sanctioned non-determinism source, and work-stealing was rejected for exactly this reason (per architecture.md §Established Decisions [Async Runtime Flavor], [Determinism RNG]).
- Do NOT add a `CONDUCTOR_*` override handle for the load envelope, or widen/relax the exemption ledger to make the re-scoped assertion pass — the ledger may only shrink under compulsion (per architecture.md §Occupied Resources · `contracts/pulse-load-envelope.toml`).

## Contract bindings
- **arch ↔ tests:** the workspace crate names and the crate-per-seam boundary fix where the replay/pacing goldens live (`crates/conductor-timeline/tests/`), and the zero-retry nextest `ci` profile is the harness contract that makes a determinism golden meaningful (architecture.md §Occupied Resources · Crate names; §Infrastructure Patterns · Build system).
- **arch ↔ tests/CI:** golden tests are an explicit CI gate (`cargo build` / nextest / clippy), while live-Pulse dynamic proof is an operator-local gate — this chunk's goldens must be CI-runnable with no live Pulse (architecture.md §Established Decisions [CI/CD]; §Infrastructure Patterns · CI/CD approach).
- **arch ↔ security:** the `cargo audit` re-check + `cargo deny check` pair and the inline-justified `deny.toml` exceptions are arch-registered build-system gates that security-plan §Dependency Security owns the floors for (architecture.md §Infrastructure Patterns · Build system).
- **arch ↔ core/contracts:** `check_load_envelope` in `conductor-core` and `contracts/pulse-load-envelope.toml` are one registered pair — the assertion surface, provenance framing, and exemption ledger must stay mutually consistent, and the arch body's own "derivable but not yet asserted" wording is part of the (c) reconciliation (architecture.md §Occupied Resources · On-disk artifacts).

## Acceptance criteria contributions
- (arch) Emission-stream golden code lives in `crates/conductor-timeline/tests/`, the load-envelope re-scope in `crates/conductor-core/src/load_envelope.rs`; no new cross-seam `Cargo.toml` edge is introduced (per architecture.md §Established Decisions [Module Boundaries] · §Occupied Resources Crate names).
- (arch) No committed golden contains a `std::time`/wall-clock stamp or a host path; the replay runs on the `current_thread` virtual clock (`start_paused`) with `ChaCha8Rng`-seeded jitter as the only non-determinism, so the same scenario + seed reproduces byte-identical bytes on any host (per architecture.md §Cross-cutting Patterns · Determinism discipline · §Established Decisions [Determinism RNG]).
- (arch) `check_load_envelope` keeps its fixed `LoadEnvelope::default_path()` → `resolve_under` load path with NO `CONDUCTOR_*` override handle added, and a malformed/absent envelope stays a `CoreError` harness fault rather than any verdict/report state (per architecture.md §Occupied Resources · On-disk artifacts · §Established Decisions [Error Handling]).
- (arch) `Cargo.lock` gains zero new `[[package]]` entries; `cargo audit` result recorded and `cargo deny check` verified exit 0, with no new `deny.toml` ignore added (per architecture.md §Infrastructure Patterns · Build system).
