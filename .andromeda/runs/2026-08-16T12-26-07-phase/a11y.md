# a11y extract

## Relevance
**Partial (thin)** — this chunk builds no UI surface (scenario TOML, `conductor-emit`/`-core`/`-verify` Rust crates, log-harvest, MCP read-back, all cli/headless), and the cli surface is declared **not-assertable** per a11y-plan §1 (A11y surfaces & assistive tech reach) and §11 Universal; the only live edges are the shared obs run-report envelope (`fingerprints[]`, `verdict`/`state`, `slo_tier`) that a11y reproduces verbatim, and the artifact-hygiene constraint a11y inherits.

## Constraints
- The cli / headless `conductor run` surface carries **no a11y assertion obligation** — a11y-plan §1 marks it not-assertable (no DOM/widget tree, no axe/Lighthouse/pa11y reach) and §11 § Universal bans ever treating it as accessibility-assertable; its ASCII prefixes / NO_COLOR text-pairing are output-stream discipline, not an a11y verification path. Nothing this chunk adds to the cli output creates an a11y gate.
- a11y-plan §3 § Structured violation JSON schema requires a11y violation artifacts to align **verbatim** to the obs §6 run-report envelope (a11y narrows, obs fixes the shape), with axe rule-id + WCAG-SC tag + node selector folded into **`fingerprints[]`** and **no new top-level fields**. If this chunk changes the envelope's field set or re-specifies `fingerprints[]` semantics/population, the plan's two verbatim reproductions (§1 harness spec + §3) must be amended to track it — whether this chunk touches the envelope shape at all is research's question.
- a11y-plan §6 § State color tokens fixes a binding **display-label ↔ obs `verdict` ↔ obs `state` crosswalk** (`Pass`/`HOLD`/`Fail`/`Blocked`/`Manual`/`Residual`; HOLD identified **verdict-first** on `CalibrationRegion`). Any re-calibration this chunk makes to `verdict`/`state` values or to `slo_tier` enum members must not introduce a state outside that crosswalk, or the six-lamp not-color-alone assertion loses its join.
- a11y-plan §9 § CI-specific resource attributes and §11 § SLO require that artifacts folded into the obs §6 envelope **never leak absolute host paths or internal seam-crate struct names** (inherited from tests' Status JSON constraint). The chunk's proposed log-harvest reader (reading a SUT-owned log under `{data_dir}/logs/`) sits directly on that rule; whichever hygiene mechanism it establishes, a11y artifacts are a downstream inheritor of it.
- a11y-plan §3 § CI integration + §9 require the a11y gate to stay **operator/local-gated, not a CI gate**, riding tests' `wdio run` webview-E2E job on Linux+xvfb — consistent with this chunk's "Not a CI gate" boundary; this chunk must not push a live-Pulse-dependent step into the CI lane a11y also relies on staying operator-gated.
- a11y-plan §10 forbids soft gates and retry-once policies for a11y signals (parallel to tests' zero-flakiness). No calibration this chunk performs on tokens/tiers may be generalized into a retry or soft-threshold pattern for the a11y gate.

## Patterns to follow
- **Envelope reuse, never envelope extension** — a11y-plan §3 § Structured violation JSON schema shows the established pattern for carrying domain-specific detail (rule-id/tag/selector tuples) inside the existing `fingerprints[]` array rather than adding fields; any new evidence this chunk needs to carry should follow the same "fold into the fixed envelope" discipline.
- **Named-anchor citation over raw values** — a11y-plan §6 anchors every assertion on token/enum **names** with raw values kept in design-system (`[NO_RAW_DESIGN_VALUES]`); the same posture applies to re-calibrated thresholds/labels this chunk produces (name the anchor, keep the measured value in the artifact).
- **Machine-verifiable evidence for every claim** — a11y-plan §2 § Agent-runnable invariants requires each criterion to have at least one agent-runnable verification path with manual observation supplemental only; the chunk's "assert on surfaces that actually carry the evidence" strand is the same discipline applied to a non-a11y domain.
- **Single automation stack reuse** — a11y-plan §3 § A11y testing tool pick / §12 Decisions Log record reusing tests' existing `@crabnebula/tauri-driver` + WebdriverIO session instead of standing up a parallel stack; if this chunk introduces a new harvest/read capability, the analogous "reuse the existing seam" preference applies.

## Anti-patterns to avoid
- **NEVER treat the cli surface as accessibility-assertable** (a11y-plan §11 § Universal) — do not attach WCAG/a11y acceptance to this chunk's cli or log-harvest output; ASCII/NO_COLOR pairing there is not an ARIA verification path.
- **NEVER let artifacts folded into the obs §6 envelope leak absolute host paths or internal seam-crate struct names** (a11y-plan §11 § SLO) — directly relevant to harvesting SUT log content into any Conductor artifact.
- **NEVER add a seventh state or a color-only state signal** (a11y-plan §11 § Visual + §6 § State color tokens, incl. the `--status-residual` Mode-cell carve-out) — if this chunk's re-calibration surfaces a new coverage-mode or verdict distinction, it must not land as an unlabelled lamp state.

## Contract bindings
- **a11y ↔ obs (D-a11y-obs-schema):** a11y-plan §3 § Structured violation JSON schema reproduces the obs §6 run-report envelope verbatim and rides `fingerprints[]`; a change to that envelope (fields or `fingerprints[]` semantics) in this chunk obligates an a11y-plan amendment — precedent set at the `2026-06-16-emission-journal-writer` amendment below.
- **a11y ↔ tests:** a11y-plan §3 § CI integration + §9 bind the a11y step to tests' 5-command harness contract (boot / run / status / cleanup / **logs**) and to tests' Status JSON no-host-path constraint; the chunk's log-harvest/artifact-hygiene decision lands on the same `logs` artifact surface a11y emits through.
- **a11y ↔ design:** a11y-plan §6 State-naming crosswalk joins design's six state tokens to the obs `verdict`/`state` enums this chunk asserts against.

## Acceptance criteria contributions
- (a11y) No new top-level field is introduced into the obs §6 run-report envelope, and `fingerprints[]` remains a flat array of opaque string entries — a11y violation artifacts fold rule-id + WCAG-SC tag + selector tuples into that array and cannot survive a shape change (per a11y-plan §3 § Structured violation JSON schema).
- (a11y) Any `verdict` / `state` value this chunk asserts or re-calibrates resolves to exactly one of the six crosswalk rows (`Pass` / `HOLD`(=`CalibrationRegion` verdict-first) / `Fail` / `Blocked` / `Manual` / `Residual`) — no seventh state (per a11y-plan §6 § State color tokens (not-color-alone)).
- (a11y) No artifact produced by the log-harvest leg persists an absolute host path or an internal seam-crate struct name into anything folded into the obs §6 envelope (per a11y-plan §11 § SLO + §9 § CI-specific resource attributes).
- (a11y) The chunk adds no WCAG/a11y gate to the cli or headless surface, and does not move the a11y step off its operator/local gate onto CI (per a11y-plan §1 not-assertable cli + §9 § Pipeline integration).
