- **Roll-up caption propagation** — cli caption ← manifest-derived counts; webview header strip receives the same roll-up shape via a typed prop from a Tauri command; Markdown artifact renders the same shape (§cli Primary screens; §desktop Primary content block 1).
- **Color always paired with a text label** — bracket prefix (cli) / lamp + status text (webview), so state is never color-only (§cli signature-placement note; §desktop Primary content block 1).
- **Terminator line naming the artifact destination** — `run report → runs/<run_id>.md` in the dimmed mapping, path un-colorized when piped (§cli Footer / terminator).

## Anti-patterns to avoid

- Do **not** add a column to either `comfy-table` shape (results/SLO 6-col, coverage 4-col) to carry new evidence, and do not hardcode table width — terminal-detected only (§cli Primary content block 1; §cli IA notes).
- Do **not** bake a derived count (unbacked qualifier, in-scope denominator, step denominator, per-state tally) as a literal in any caption, label, or sample — every number is manifest-derived (§cli Primary screens `conductor coverage`).
