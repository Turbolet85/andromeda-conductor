## Patterns to follow
- Fixed-path committed-artifact resolution: `default_path()` → `resolve_under`, explicit `validate()` in `conductor-core`, deliberately no `CONDUCTOR_*` override handle, read faults carrying `e.kind()` only and never the path (per security-plan §Input Validation, committed SUT-facing manifests row) — the model for where a new log-harvest reader should sit if it becomes a shipped seam rather than a test-only affordance.
- garde `#[derive(Validate)]` `range` + `#[garde(custom)]` cross-field rules co-located with the serde structs in their owning seam crate, failed `Report` → `ConfigError` via `#[from]` as a harness fault (per security-plan §Input Validation, scenario-config row).
- Typed errors module-internal via `thiserror` enums, collapsed to `anyhow` only at the `conductor-cli` edge; verification outcomes stay typed VALUES in `Ok(...)` while `Result::Err` is reserved for harness faults (per security-plan §Error Handling).
- Bound rusqlite parameters for any `runs.db` write this leg produces (run_id/seed/fingerprint-JSON1), never `format!`-built SQL (per security-plan §Input Validation, `runs.db` writes row).
- Declaration-only env reads: `ANDROMEDA_PULSE_L4_DETERMINISTIC` is read, never written, and never becomes a path/argv element/log value; an absent declaration surfaces as an unmet run-contract term naming both candidate causes, never as a claimed measurement of `pulse-app` (per security-plan §Input Validation, L4-deterministic row).

## Anti-patterns to avoid
- NEVER let Conductor's production code directly open, copy, or exfiltrate Pulse's `corpus.db`, nor persist SUT-owned content into Conductor artifacts — corpus access is MCP read-back ONLY (per security-plan §Security Anti-Patterns → Data Protection). The log-harvest strand reads a different SUT artifact; the same never-persist discipline governs it.
- NEVER mark a nested spec field `#[garde(skip)]` — garde will not descend and the rules silently never run; `dive` is the only correct annotation (per security-plan §Security Anti-Patterns → Input).
- NEVER silently downgrade a failed preflight, and never let a malformed child/transport input panic on the read-back path (per security-plan §Security Anti-Patterns → Universal).
