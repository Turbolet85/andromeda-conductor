- Verdict-first lamp precedence table (a11y-plan §6) as the canonical join from an emitted row back to its rendered lamp — reuse it rather than re-deriving state→lamp mapping in the leg evidence.
- Operator-checklist component pattern (a11y-plan §4 per-component catalog): declare-only / `ManualCheck` items already have a render contract (checkbox-per-item exposing induced-state + expected-observation text, unticked-count roll-up) — a check retired to declare-only lands in that existing pattern; no new component is implied.
- Artifact emission through the tests 5-command `logs` surface (a11y-plan §3 CI integration / §9) — the standing route for machine-readable gate artifacts, if this chunk emits anything beyond the journal/runs.db pointers.
