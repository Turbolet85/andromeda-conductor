# design extract

## Relevance
Partial — no webview/token/typography/motion work, but the `cli` surface's status-output conventions govern every verdict, table row, operator gate, and Markdown evidence artifact this leg produces.

## Constraints
- The surface of record here is `cli`, not `desktop-webview`: color is ANSI 256 applied via `owo-colors` through `anstream`, auto-stripped when piped, honoring `NO_COLOR` + `TERM=dumb`; webview spacing/radius/typography tokens do not apply (per design-system §Surface: cli / Tokens, §Spacing surface-conditional, §Border Radius surface-conditional).
- The per-P-ID state vocabulary is a CLOSED set — `[PASS]` / `[HOLD]` / `[FAIL]` / `[MANUAL]` / `[RESIDUAL]` / `[BLOCKED]`; §Surface: cli / Tokens requires the run-level `[ENVIRONMENT-SUSPECT]` load-envelope caption to sit OUTSIDE the lamp column as a run qualifier, never a seventh lamp or sixth `ReportState`. A live leg that breaches the SUT load envelope must use that existing caption rather than inventing a state.
- A report row must carry BOTH `Verdict` (3) and `ReportState` (5); §Color Palette (Verdict-vs-ReportState note) requires `KnownResidual` to render muted/dashed (`~`, ANSI 246) with its "expected until {named fix}" note and to be visually NOT red. The scope's "retires to declare-only … never a vacuously-passing `Absent`" disposition must land in that treatment, not as a green pass and not as `Fail`.
- `Blocked` is *never measured*, not failed: §Surface: cli / Component Patterns #3 requires a `Blocked` row to carry its named precondition string with measurement columns rendered `—`/null, never a red error — directly applicable when the five-item operator recipe's preconditions (sidecar on PATH, `ANDROMEDA_PULSE_L4_DETERMINISTIC`, `ANDROMEDA_PULSE_MCP_ENABLED`, data-dir) are unmet.
- Operator gating must go through the `isatty`-checked `inquire` prompt, and §Surface: cli / Component Patterns #2 + §Platform-Specific Notes require the headless `agent-run.sh` path to be NEVER blocked on a prompt — the non-interactive policy applies and the decision is recorded to the artifact. This chunk is explicitly "operator-gated, never CI", so the interactive/headless split is load-bearing.
- Any error surfaced by the leg goes to stderr, sanitized (no absolute host paths, internal struct names, or stack traces outside `--debug`/`-v`), with `error:` reusing Fail red (ANSI 203) and `hint:` the Residual mute (ANSI 246) behind a stderr-specific `IsTerminal` gate (per §Surface: cli / Component Patterns #5).
- The reserved mono ID-cyan tier (ANSI 117) is for P-IDs, run_id, SLO timings (`<5s`/`<20s`/`<90s`), `latency_ms`, and fingerprints only — never a generic accent (per §Typography Data row, §Surface: cli / Tokens). The §4 `slo_tier` re-calibration changes the *value* in that column; the tier's rendering contract is unchanged.

## Patterns to follow
- Per-P-ID verdict/report-state line shape from §Surface: cli / Component Patterns #4 — glyph + `[STATE]` + P-ID + label + timing, e.g. the `✓ P-009  Pass  1840ms <5s` / `~ P-032  Residual  … → v0.3.0` forms; color always paired with the ASCII prefix.
- Results / SLO table from §Surface: cli / Component Patterns #3 — `comfy-table` 6 columns (P-ID · scenario · state · `slo_tier` · `latency_ms` right-aligned cyan · fingerprints), width detected dynamically from the terminal. Distinct from `conductor coverage`'s separate 4-column table, which carries no state column. Whether the shipped CLI already renders this exact column set for this family is research's question.
- Paused-count hold-point CLI mirror (§Surface: cli / Component Patterns #1) — the `indicatif` spinner STOPS in place at the exact value with a bold amber `HOLD — operator pause` line above the `inquire` prompt; spinner appears only after ~200ms and is TTY-gated so agent-captured artifacts stay clean. Relevant because this leg's captured evidence must not be polluted by spinner frames.
- Markdown has no color channel: §Surface: cli / Tokens (Residual-mute entry) requires the surface-adapted counterpart — the bracket label or emphasis (`_not-conductors_`-style) carries the signal. Applies to `evidence/leg-verdict.md` and any harvested-slice write-up.

## Anti-patterns to avoid
- Never emoji in machine-parseable/piped output — ASCII prefixes only there (per §Anti-Patterns / Per-Surface Bans: cli); the leg's artifacts are captured and diffed.
- Never collapse "declare-only", "no result yet", or `Blocked` into `Fail`, and never a flashing/blinking red on `Fail` (per §Anti-Patterns / Rejected Defaults: "Conflating 'no result yet' with 'failed'", "A flashing / pulsing red banner…").
- Never hide the spinner or animate it to 100% at an operator pause, and never hardcode table widths or wrap at arbitrary points (per §Anti-Patterns / Per-Surface Bans: cli).

## Contract bindings
- **Not-color-alone → a11y §Use of Color (SC 1.4.1):** the `[PASS]`/`[FAIL]`/`[RESIDUAL]`/`[BLOCKED]` ASCII prefixes are what carries the signal under `NO_COLOR` and for screen readers; design supplies the tint only.
- **Verdict/ReportState pair → architecture's run-report envelope:** §Color Palette defers the two-field row shape to arch; design owns only its rendering. The scope's `slo_tier` re-calibration values (`<5s`/`<20s`/`<90s`) are architecture §Timing-Tolerance's, rendered in the mono ID-cyan tier.
- **Headless-never-blocked → security plan + the agent harness (`scripts/agent-run.sh`):** §Surface: cli / Platform-Specific Notes states an interactive prompt on that path would silently break the release gate; the harness/ops domain owns the invocation, design owns the TTY-gated presentation.

## Acceptance criteria contributions
- (design) Every per-P-ID status the leg prints carries its ASCII bracket prefix from the closed six-state set, with color as reinforcement only — verified under `NO_COLOR` / piped stdout (per design-system §Surface: cli / Tokens).
- (design) Any check retired to declare-only, or any pre-accepted gap, renders as `[RESIDUAL]` (`~`, ANSI 246) with its "expected until {named fix}" note — never red `[FAIL]`, never a silently-green vacuous pass; unmet-precondition rows render `[BLOCKED]` with the named precondition and `—` measurement columns (per §Color Palette Verdict-vs-ReportState note; §Surface: cli / Component Patterns #3, #4).
- (design) The leg's operator gate is `isatty`-checked and the headless `agent-run.sh` path completes without blocking on a prompt, with the recorded decision landing in the run artifact (per §Surface: cli / Component Patterns #2; §Surface: cli / Platform-Specific Notes).
- (design) If an operator-pause fires during the leg, the `indicatif` spinner stops in place at its exact value (never hidden, never animated to 100%) and the amber `HOLD — operator pause` line prints above the prompt (per §Surface: cli / Component Patterns #1; §Motion High-impact moments).
