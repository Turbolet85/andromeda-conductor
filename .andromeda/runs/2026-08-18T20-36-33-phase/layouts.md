- The `conductor run <scenario>` stdout shape is a documented layout artifact (header → preflight line → optional run-level caption → phase line → `indicatif` heartbeat → per-P-ID verdict lines → table → `run report →` terminator); downstream agents parse it, so leg captures and harvest predicates must be read against that fixed order, not an ad-hoc one (per layout-templates §Surface: cli — Output structure `conductor run <scenario>` / §cli IA notes Command model).
- The per-P-ID verdict/report-state bracket label set is **closed at six** (`[PASS]` / `[HOLD]` / `[FAIL]` / `[MANUAL]` / `[RESIDUAL]` / `[BLOCKED]`); whatever state this family's leg resolves to must map into that set — no seventh lamp, no new label (per §cli Primary content block 2).

- The `slo_tier` cell (`<5s` / `<20s` / `<90s`) is a rendered column in both the 6-column results/SLO table and the per-P-ID verdict lines; a TOML re-declaration therefore changes what these surfaces print, and the doc's sample rows track the shipped value (per §cli Primary content block 1 + §Component — Primary content block 2; precedent: amendment 2026-08-18-error-baseline-spike-live-proof).
- The run-level `[ENVIRONMENT-SUSPECT]` caption is the *only* non-lamp stdout label: printed **once per run, above** the verdict lines it qualifies, riding **outside** the lamp column, ASCII bracket always printed, naming the breaching **emitting phase** + which sustained term it left — and **omitted entirely** when the run is in-envelope or pinned exempt (per §cli Output structure + §cli Primary content block 2).
- The headless invariant binds `scripts/agent-run.sh`: the agent-driven source-of-truth path is **never** gated on an interactive prompt, and `inquire` holds are `isatty`-checked — any SEED-disposition edit to that script must not introduce a prompt or a TTY-dependent branch on the headless leg (per §cli Component — Hero / signature output + §cli IA notes Headless invariant).
- Roll-up captions and any coverage numbers are **manifest-derived, never a literal**; the unbacked qualifier qualifies the `auto` term only and is never a fifth summand — the scope's "scenario keeps its manifest-accepted P-IDs" boundary is what keeps these captions stable (per §cli Primary screens `conductor coverage [--write]`).

## Patterns to follow
- **`agent-run.sh` is a registered cli screen.** The 5-command `boot`/`run`/`status`/`cleanup`/`logs` harness and its `--unit`/`--integration`/`--e2e` stage flags are documented in §cli Primary screens; the established pattern (amendments ch1–ch3, detector D-layout-surface) is that any genuinely-new harness verb/flag surface gets registered there. A SEED-behavior change that adds no flag adds no surface; a SEED **flag** would.
- **Sample-row sweep pattern.** When a scenario re-declares its tier, every sample row naming that scenario is swept in one pass across all sites (the P-009 `<5s`→`<90s` five-site sweep, amendment 2026-08-18) — set-naming prose lines left untouched.
- **De-literalization over re-literalization.** Where a sample bakes a derived number that will re-stale, the standing pattern is the placeholder form (`(N unbacked)`, amendment 2026-08-16-fingerprint-storm-live-proof), not a fresh literal.
- **Status paired with an ASCII prefix, always.** Every cli state cell pairs its color with its bracket prefix so the signal survives `NO_COLOR` / piping — this is what makes verbatim leg captures a stable harvest-predicate substrate (per §cli signature-placement preamble + §cli IA notes Pipe discipline).
- **`restart-suppression` is the named step in the signature moment.** The operator-pause HOLD wireframe and the cli HOLD line both use "Commit next timeline step: restart-suppression?" as the illustrative gated step (per §Wireframe — Run console (HOLD) and §cli Output structure) — this chunk's scenario is the doc's own example of the hold-point.

## Anti-patterns to avoid
- Rendering `Blocked` or `KnownResidual` in the fail treatment, or collapsing either into `Fail` — the "no surprise failure" rule; `Blocked` ≠ red, `KnownResidual` is never red (per §Component — Primary content block 2 + §Decisions Log Cross-surface IA decisions).
- Introducing a new bracket label / lamp state / stdout column to carry a new leg outcome — the lamp set is closed at six and adding a column without a `--format` flag is a breaking change for parsing agents (per §cli Primary content block 2 + §cli IA notes Command model).
- Blocking the headless leg on an interactive gate, or emitting a native OS toast for any run state — Conductor never emits one; titlebar + footer + matrix carry all live state in-window (per §cli IA notes Headless invariant + §Component — Footer).
