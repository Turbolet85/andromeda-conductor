## Patterns to follow
- The bounded-wait re-pin pattern from security-plan §Dependency Security: run `cargo deny check advisories bans licenses sources` and OBSERVE its true exit code rather than echoing a claim ("deny observed, never echoed"), then state the changed basis when re-pinning the deferral.
- The accepted-exception mechanism in security-plan §Dependency Security (deny.toml ignore/allow entries, each with a justifying comment) is the ONLY sanctioned route for a new license/advisory surfaced by deny — and `deny.toml` itself is the authority on the full set, not the plan's prose list.
- Fixed-path, non-operator-steerable resolution for committed SUT-facing manifests per security-plan §Input Validation: `default_path()` through `resolve_under`, no `CONDUCTOR_*` override handle, read faults carrying `e.kind()` only and never the path. Any new contract/manifest reading this chunk adds follows this shape.
- The typed verdict/error wall per security-plan §Error Handling: harness faults are `Result::Err` (`VerifyError::{JsonRpc,Decode,Transport}`, `ConfigError`), verification outcomes are typed VALUES returned as `Ok(...)`; MCP error responses and `tonic::Status` are first-class typed inputs, never panics. Harvest-parser additions on the read-back/journal path inherit this.
- Scenario-config validation per security-plan §Input Validation: any `scenarios/restart-suppression.toml` re-shape stays inside the garde boundary — `[phases.emission]` `kind` REQUIRED whenever the table exists, `occurrences` bounded by `MAX_OCCURRENCES` (`0` = a declared silence window, i.e. this chunk's gap phase), per-shape cross-field rules, and every nested spec field `dive`, never `skip`.

## Anti-patterns to avoid
- NEVER add a `deny.toml` ignore, raise a tool floor, or edit CI to make the RUSTSEC-2026-0244 DB fault go green (security-plan §Dependency Security; §Anti-Patterns → Universal) — a floor raise here is unexecutable and "would look like compliance while changing nothing".
- NEVER let the live leg's journal/report/harvest captures carry absolute host paths, `ANDROMEDA_PULSE_DATA_DIR` values, or internal struct/field names into committed evidence (security-plan §Anti-Patterns → Logging; §Error Handling).
- NEVER silently downgrade a failed preflight or an unreachable read-back into pass/fail/manual-check to keep the leg "green" (security-plan §Anti-Patterns → Universal) — and never let a malformed child/transport input panic on the read-back path, which the new harvest parser must respect.
