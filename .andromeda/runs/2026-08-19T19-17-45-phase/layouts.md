- cli per-P-ID line shape: glyph + bracket label + P-ID + scenario + state + latency + tier, with an INDENTED detail sub-line for the qualifier (`observe:` for Manual, `residual:` for Residual, `precondition:` for Blocked) — P-035's `observe:` sub-line is the existing instance to extend (per layout-templates §cli Output structure `conductor run` + §cli Component — Primary content block 2).

- Verdict/report-state lamps resolve motionless over a colour transition — no flash, no blink, including for a `Fail` (per layout-templates §Component — Primary content block 2).

- Adding a `comfy-table` column (e.g. a scrub-category or excerpt column) without a `--format` flag — downstream agents parse the output, so column additions are a breaking change (per layout-templates §cli IA notes Command model).
- Baking fresh literals (slo_tier values, unbacked counts, per-state tallies) into wireframe/output samples instead of the set-named placeholder form — the line's own prose requires manifest-derived numbers (per layout-templates §cli Primary screens `conductor coverage`; playbook set at the 2026-08-16 / 2026-08-18 amendments).
