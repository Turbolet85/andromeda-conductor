## Patterns to follow
- Verdict-first lamp identification when emitting or joining envelope rows — identify/join HOLD on `verdict`, never on `state` (per a11y-plan §6 State-naming crosswalk).
- A token-tinted classification that is not a lamp state stays a **classification**, carrying its own always-rendered text label rather than a seventh lamp entry (precedent: `--status-residual` on the coverage-matrix out-of-scope Mode cell) (per a11y-plan §1 A11y triggers → non-lamp reuse; §6).
- Crosswalk drift caused by a backend serializer/classifier is corrected by a **wrap-owned §6 amendment**, never a mid-phase plan edit (per a11y-plan §6 + amendment history below).
- One webview-automation stack only — a11y injects into tests' `@crabnebula/tauri-driver`/WebdriverIO session; nothing in this chunk should stand up automation tooling on a11y's behalf (per a11y-plan §3 A11y testing tool pick; §11 CI).

## Anti-patterns to avoid
- NEVER treat the cli/headless surface as accessibility-assertable — ASCII status prefixes / `NO_COLOR` text-pairing are output-stream discipline, not an ARIA verification path (per a11y-plan §11 Universal).

- NEVER let artifacts folded into the obs §6 envelope leak absolute host paths or internal seam-crate struct names (per a11y-plan §11 SLO).
