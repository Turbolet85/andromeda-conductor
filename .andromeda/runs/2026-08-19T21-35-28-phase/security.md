## Constraints
- The `:4317` port-occupier bind is the SOLE deliberate inbound bind, loopback-only, and is an intentional in-host fault under the `conductor-faults` seam — never a general-purpose listener accepting external input, and the driver must not widen it (per security-plan §Threat Model Summary, attack-surface "single deliberate exception" + §Security Anti-Patterns → API/Universal). Whether the shipped RAII `occupy`/`release` already binds loopback-only and releases on drop is research's question.
- The live legs' artifacts (`<run_id>.md`, `runs.db` rows, JSONL journal) must record verdict/state/identity fields WITHOUT leaking absolute host paths — including the per-leg `%TEMP%/pulse-legs/` data dirs, `ANDROMEDA_PULSE_DATA_DIR`, and canonicalized `CONDUCTOR_*` directories — or internal seam-crate struct names (per §Error Handling, run-report artifact sanitization; §Security Anti-Patterns → Logging).
- A failed occupier bind (the expected live condition when Pulse holds `:4317`) and any transport fault must route through the verdict/error wall as a typed value (`Ok(Verdict/ReportState)`) or a typed harness fault (`Result::Err`) — never a panic, never a silent pass (per §Error Handling; §Security Anti-Patterns → Universal, "NEVER let a malformed child/transport input panic").
- The PREREQ re-check follows the advisory-DATABASE-fault remedy only: bounded wait, with `cargo deny check advisories bans licenses sources` VERIFIED green (never assumed) as the sole coverage — no floor raise, no `deny.toml` ignore, no CI edit (per §Dependency Security, two-fault split).
- The chunk's NEW `conductor-run` → `conductor-faults` `Cargo.toml` edge means the deferral's stated basis ("ZERO dependency delta / `Cargo.toml` untouched") must be restated on its actual changed footing, and the deny overlap must be verified green over the resulting `Cargo.lock` (per §Dependency Security, "Admitting a NEW dependency while the fault persists"). Whether an intra-workspace path edge produces any `Cargo.lock` delta at all is research's question.
- Any re-based scenario TOML for P-001..P-004 must remain garde-validated at load with `dive` (never `skip`) on every nested spec field, including `[phases.emission]` (`kind` required whenever the table exists, `occurrences` bounded by `MAX_OCCURRENCES`) (per §Input Validation, scenario-config row; §Security Anti-Patterns → Input).
- No scenario without a Pulse P-ID, and the accepted set stays manifest-driven from the fixed-path, `validate()`-checked `contracts/pulse-capabilities.toml` — never defaulted, never silently widened (per §Security Anti-Patterns → Universal; §Input Validation, committed SUT-facing manifests row).

## Patterns to follow
- Hardened sidecar spawn for each live leg: fixed hard-coded `andromeda-pulse-mcp` program path, per-leg data dir passed strictly through the `.env(...)` builder with argument-injection metacharacters rejected first — never interpolated into argv or a shell (per §Input Validation, `ANDROMEDA_PULSE_DATA_DIR` row; §Security Anti-Patterns → Code Patterns).
- Path handles resolved through the shipped `resolve_under` traversal guard plus `std::fs::canonicalize` + type/existence bounds-check at the `conductor-cli` edge before any `runs.db`/journal write (per §Input Validation, env-var path handles row).
- `thiserror` typed enums per seam crate (`EmitError`, `VerifyError`, `ConfigError`) collapsing to `anyhow` only at the `conductor-cli` / `#[tauri::command]` edge — the pattern the new driver's fault classification should reuse (per §Error Handling).
- `runs.db` evidence rows written with rusqlite bound parameters, fingerprint arrays as JSON1 TEXT — never `format!`-built SQL (per §Input Validation, `runs.db` writes row).
- Journal/report wall-clock stamps taken from `std::time`, never tokio's virtual clock, so journal-relative SLO math on the state-walk legs stays correct (per §Security Anti-Patterns → Logging).

## Anti-patterns to avoid
- NEVER promote the `conductor-faults` `:4317` bind into a general-purpose inbound listener, and NEVER introduce any other inbound listener of Conductor's own while wiring the driver (per §Security Anti-Patterns → API + Universal).
- NEVER let the live legs' artifacts leak absolute host paths or internal struct/field names — they are agent-parseable ground truth shared across hosts (per §Security Anti-Patterns → Logging).
- NEVER close the red audit with a `deny.toml` ignore, a floor raise, or a CI edit; and NEVER silently downgrade a failed preflight on any leg — each of the five named preconditions must surface as its own distinct `blocked` string (per §Dependency Security; §Security Anti-Patterns → Universal).
