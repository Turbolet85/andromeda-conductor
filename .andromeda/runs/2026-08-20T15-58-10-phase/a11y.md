## Constraints
- The cli / headless `conductor run` surface is **not-assertable** — no DOM or widget tree, no axe/Lighthouse/pa11y reach; it is excluded from the strategy and ARIA sections, so this chunk gains no ARIA, focus, keyboard, or contrast obligation (per a11y-plan §1 A11y Scope Summary, cli entity; §11 Universal).
- a11y's violation-JSON envelope is a **verbatim reproduction of the obs §6 log format** (a11y narrows, obs fixes the schema) — it carries `latency_ms` and the `slo_tier` enum `<5s | <20s | <90s`. If this chunk changes that field set or the SLO-tier vocabulary, a11y §3's reproduction must track it in lockstep (per a11y-plan §3 Structured violation JSON schema). The scope lists "[inferred] possibly its SLO tier" for `scenarios/latency-regression.toml`; whether the re-shape stays inside the existing three-tier enum is research's question.
- The **State-naming crosswalk is binding** for the display-label ↔ obs `verdict` ↔ obs `state` join (`Pass`/`HOLD`/`Fail`/`Blocked`/`Manual`/`Residual` ↔ `Pass | Fail | CalibrationRegion` / `Pass | Fail | ManualCheck | KnownResidual | Blocked`). The chunk's "row's non-Blocked clause re-thought" and harvest-tier grading must land inside that existing enum set; a new or renamed `verdict`/`state` member would require a crosswalk row plus its own text label + glyph before any lamp can render it (per a11y-plan §6 State color tokens — State-naming crosswalk).
- HOLD is identified **verdict-first**: `verdict == CalibrationRegion` ⇒ HOLD lamp regardless of `state`; join HOLD on `verdict`, never on `state` (per a11y-plan §6 crosswalk). Any grading re-work that emits `CalibrationRegion` for a latency row inherits this precedence.
- a11y artifacts MUST NOT leak absolute host paths or internal seam-crate struct names into the obs §6 envelope (inherited from tests' Status JSON constraint) — applies to any a11y-tagged artifact this chunk's leg would produce, not to `evidence/leg-verdict.md` prose (per a11y-plan §11 SLO; §3 Structured violation JSON schema).
- The a11y gate is **operator/local, on the tests' Linux+xvfb `wdio run` webview job**, emitted through the tests harness `logs` command — it is a distinct gate from `cargo audit` / `check_load_envelope` / cargo-nextest and must not be folded into them (per a11y-plan §9 CI Integration).

## Patterns to follow
- Envelope-tracking pattern: when obs §6 changes shape, a11y amends its verbatim reproduction in the same chunk rather than diverging (per a11y-plan §3; precedent in the 2026-06-16 amendment).
- Classification-vs-lamp-state discipline: a value that classifies coverage (e.g. a Mode cell) is not a new lamp state and must not be matched by the six-label assertion; it carries its own always-rendered text label (per a11y-plan §1 A11y triggers → non-lamp reuse note; §6 State color tokens).
- Not-assertable-surface exclusion: cli output discipline (ASCII status prefixes, `NO_COLOR` text-pairing) is stream discipline, deliberately kept out of the a11y verification path (per a11y-plan §1 cli entity; §11 Universal).
- Single-envelope emission: keyboard/contrast/axe results all fold into the one obs §6 envelope with no new top-level fields — extra signal rides `fingerprints[]` (per a11y-plan §3 Structured violation JSON schema).

## Anti-patterns to avoid
- NEVER treat the cli surface as accessibility-assertable — do not add an axe/pa11y/a11y assertion over the headless leg's terminal output or evidence files (per a11y-plan §11 Universal).
- NEVER claim WCAG conformance without machine-verifiable evidence — this chunk's `evidence/leg-verdict.md` must not assert any a11y outcome (per a11y-plan §11 Universal / §11 Strategy).
- NEVER introduce a state/verdict value that reaches a lamp without its text label + glyph supplement — color-alone state is banned (per a11y-plan §11 Visual; §6 State color tokens).

- **a11y §3 violation-JSON ↔ obs §6 log format** (D-a11y-obs-schema): a11y reproduces the obs envelope verbatim, including `latency_ms` / `slo_tier`; obs owns the schema, a11y tracks it. Any envelope or SLO-tier change in this chunk propagates to a11y §3.
- **a11y §6 State-naming crosswalk ↔ obs `verdict`/`state` enums**: the crosswalk is the join key from a failing lamp back to its journal row; the grading re-work must not introduce an enum member absent from it.
- **a11y §9 CI gate ↔ tests 5-command harness (`logs`)**: a11y results ride the tests' webview E2E job, not this chunk's `.claude/rules/verification-harness.md` live-leg harness — no binding to add here.
