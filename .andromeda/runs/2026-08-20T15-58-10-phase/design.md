## Relevance
Partial — the chunk's core (scenario TOML re-shape, Rust predicates, envelope gate, `cargo audit`) is outside the design domain; design binds only where the re-proof's outcome *renders* on the `cli` surface (per-P-ID verdict/report-state lines, the SLO-tier cell, the load-envelope caption, and the ReportState chosen for the re-thought non-Blocked clause).

## Constraints
- Any P-011/P-012 result line this chunk causes to render must pair its tint with an ASCII label from the closed set `[PASS]`/`[FAIL]`/`[HOLD]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]` (glyphs `✓`/`✗`/`?`/`~`/`•` TTY-only) — color is never the signal (per design-system.md §Surface: cli / Component Patterns 4 + §Per-Surface Bans → cli).
- The SLO-tier cell must render the scenario's **declared** `slo_tier` drawn from the closed `<5s`/`<20s`/`<90s` set, never a baked per-scenario literal — so a longer/denser re-shape changes the scenario's declaration, not a hardcoded sample (per §Surface: cli / Component Patterns 4). Whether the shipped renderer already reads the declaration rather than a literal is research's question.
- Re-thinking the row's non-Blocked clause is a **ReportState** choice bound to the 5-valued semantics: `Blocked` = named precondition, *never measured* (measurement columns render `—`/null, never a red error); `KnownResidual` = *measured but pre-accepted*, carries "expected until {named fix}", rendered dashed/muted and explicitly NOT red; neither may collapse into `Fail` (per §Color Palette → Verdict(3)-vs-ReportState(5) note + §Anti-Patterns → Rejected Defaults, "Conflating 'no result yet' with 'failed'").
- A `check_load_envelope` breach surfaces as the run-level `[ENVIRONMENT-SUSPECT]` caption printed **once** in the Residual-mute tier (ANSI 246) *above* the per-P-ID lines — a qualifier on the run, never a seventh lamp or a sixth `ReportState` (per §Surface: cli / Tokens + §Component Patterns 4).
- Zero new colors / ANSI map entries: any new latency-state rendering must reuse the shipped pairs (nominal 114 · hold 179 · fail 203 · blocked 60 · manual 146 · residual 246 · ID-cyan 117), and mono ID-cyan is reserved for P-IDs / run_id / SLO timings / `latency_ms` / fingerprints (per §Anti-Patterns → Universal Bans + §Typography → Data row).
- The live fresh-dir legs run agent-driven and headless: the headless path must never be gated on an interactive `inquire` prompt (`isatty` check first; decision recorded to the artifact instead), and tinting must stay TTY-gated through `anstream` honoring `NO_COLOR` / `TERM=dumb` / pipe-stripping (per §Surface: cli / Component Patterns 2 + §Platform-Specific Notes → cli).
- Evidence and report Markdown have no color channel — the surface-adapted counterpart for a recessive/qualified state is emphasis (`_…_`) or the bracket label in a blockquote, never a color-dependent cue (per §Surface: cli / Tokens → Residual-mute entry).

## Patterns to follow
- **Results / SLO table** (§Surface: cli / Component Patterns 3): `comfy-table`, 6 columns — P-ID (ANSI 117) · scenario · state prefix · `slo_tier` · `latency_ms` (cyan, right-aligned) · fingerprints; width detected dynamically from the terminal. Distinct from the narrower 4-column `conductor coverage` table, which carries no verdict/state column.
- **Verdict / report-state lines** (§Surface: cli / Component Patterns 4): in-place per-P-ID line, glyph + P-ID + state word + timing + `<slo_tier>`; `Fail` resolves motionless in ANSI 203 with no blink.
- **Paused-count hold-point, CLI mirror** (§Surface: cli / Component Patterns 1): if a re-shaped longer/denser scenario surfaces a live `indicatif` count, the spinner appears only after ~200ms and **stops in place** (never hides, never animates-to-100%) at any hold.
- **Error output** (§Surface: cli / Component Patterns 5): stderr, sanitized (no absolute host paths / struct names / stack traces outside `--debug`), `error:` reusing Fail red 203 and `hint:` the Residual mute 246 on their own stderr `IsTerminal` gate.

## Anti-patterns to avoid
- Never let an unmeasured or pre-accepted latency outcome read as `Fail` — `Blocked` and `KnownResidual` are deliberately distinct treatments so no result silently downgrades to red (§Anti-Patterns → Rejected Defaults).
- Never add a new palette row / ANSI entry for a new latency state, and never use color purely as decoration — every tint must map to a Verdict / ReportState (§Anti-Patterns → Universal Bans; precedent: the `hint:` and Mode-cell reuses recorded in amendments rather than added as colors).
- Never emit emoji in machine-parseable piped output, hardcode table widths, or mix raw artifact data (stdout) with human messages (stderr) in the leg harness capture (§Per-Surface Bans → cli).

## Contract bindings
- **cli status tint ↔ a11y (SC 1.4.1 use-of-color):** the ASCII bracket label carries the signal for `NO_COLOR` + screen-reader paths; design mandates the pairing, a11y owns the criterion.
- **Residual-mute ANSI 246 ↔ webview `var(--status-residual)`:** a by-name pair; per the 2026-08-09 amendments the tier's non-lamp uses are documented as a **set** (never a literal count), so a fourth reuse landing in this chunk is an amendment obligation, not a new token.
- **`[ENVIRONMENT-SUSPECT]` caption ↔ arch/tests `check_load_envelope`:** design owns only the render half (once-per-run, above the lamp column, 246); the gate's asserted sustained terms and exact-set `[[exempt]]` equality are arch/tests' contract.
- **ReportState lamp set ↔ arch's run-report envelope:** each report row carries BOTH a `Verdict` and a `ReportState`; the design lamp/prefix set is the render of that envelope, so the re-thought non-Blocked clause must resolve to one of the five, not a new value.
