## Patterns to follow
- **Qualifier-outside-the-lamp-column precedent**: the `not-conductors` Mode-cell treatment is the stated precedent the `[ENVIRONMENT-SUSPECT]` caption follows — a recessive ANSI 246 tint over an always-printed label, never a new lamp state (per layout-templates §cli Component — Primary content block 2).
- **Two distinct `comfy-table` shapes**: the 6-column results/SLO table (`run`/`suite`: P-ID · scenario · state · slo_tier · latency_ms · fingerprints) vs the 4-column coverage matrix (`coverage`: P-ID · Title · Category · Mode, no verdict column, no bracket prefix). The re-proof's latency numbers surface in the 6-column table's right-aligned `latency_ms` cell (per layout-templates §cli Component — Primary content block 1).
- **De-literalize, never re-pin**: where a wireframe/sample row would bake a scenario-derived value (tier, unbacked count), the established form is the set-named placeholder (`<slo_tier>`, `(N unbacked)`) — three prior re-staling cycles drove this rule (per layout-templates §amendments 2026-08-16 / 2026-08-18 / 2026-08-19). Note the plan's sample rows today name P-001/002/003/008/009/010/014/022/032/035 — no `latency-regression` / P-011 / P-012 sample exists, so a tier re-declaration here likely requires no layout sweep.
- **Motionless verdict resolution**: lamps resolve over a `motion-micro` color transition, never flashing; `Fail` is a motionless `status-fail` lamp, `no blink` on the cli side (per layout-templates §Component — Primary content block 2 + §cli Component — Primary content block 2).

## Anti-patterns to avoid
- Do **not** introduce a seventh lamp state, a sixth `ReportState`, or a new bracket label / ANSI code for "regression undetected" or "window-absorbed" — the lamp set is closed at six and any run-level signal must ride outside the lamp column (per layout-templates §cli Component — Primary content block 2).
- Do **not** add a column to either `comfy-table` shape (e.g. a latency-delta / window-size column) without a `--format` flag — output structure is stable across versions because downstream agents parse it; an added column is a breaking change (per layout-templates §cli IA notes Command model).
- Do **not** substitute a fresh literal into any sample caption/row if a scenario-derived value moves this chunk (tier, unbacked count) — the de-literalized placeholder form is the ratified fix for this class (per layout-templates §amendments 2026-08-16-fingerprint-storm-live-proof).
