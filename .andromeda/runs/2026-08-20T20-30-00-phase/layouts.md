## Relevance
Partial — the chunk creates/modifies no surface, region, component placement, focus order, breakpoint, modal or empty state; layouts binds only where its killing assertions and the runner-portability fix touch cli output shape and the `Blocked`-with-named-precondition render contract.

## Constraints
- `Blocked` is a never-measured state, never red and never a `Fail`: it renders a hollow ring / `[BLOCKED]` (ANSI 60), its measurement cells render `—` / null, and it **carries a named precondition string** — per layout-templates §desktop-webview Component — Primary content block 2 and §cli Component — Primary content block 2. Scope §1 (`declares` family) says the architecture requires "a distinct `Blocked` naming each unmet term"; that named term is precisely the text these two sections require be renderable, so the killing assertion and the render contract assert the same string.
- The per-P-ID verdict/report-state label set is **closed at six** (`[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`), with exactly one run-level non-lamp qualifier (`[ENVIRONMENT-SUSPECT]`) riding outside the lamp column — per layout-templates §cli Component — Primary content block 2. Test/harness work may not introduce a seventh label or a sixth `ReportState`.
- cli output structure is a **parsed contract**: downstream agents parse it, so adding/removing/reordering a `comfy-table` column without a `--format` flag is a breaking change — per layout-templates §cli IA notes (Command model). The two shapes must stay distinct: 6-column results/SLO (`run`/`suite`) vs 4-column coverage (`coverage`) — per layout-templates §cli Component — Primary content block 1.
- Headless invariant: `inquire` prompts are always `isatty`-gated and the agent-driven source-of-truth path is **never** gated on a prompt — per layout-templates §cli IA notes (Headless invariant). Scope §2's "passes under either test runner" must not be satisfied by anything that can introduce an interactive gate on the non-TTY path.
- Status is never color-alone: the ASCII bracket prefix is always printed, ANSI auto-strips when piped, and `NO_COLOR` / `TERM=dumb` are honored — per layout-templates §cli Signature placement, §cli Component — Header / banner and §cli IA notes (Pipe discipline). Any assertion over cli stdout should key on the ASCII label so it holds identically under a TTY runner and a captured/piped one.
- cli error output goes to **stderr**, sanitized: `error: <short>` + contextual detail + `hint: <fix>`, with no absolute host paths, internal struct names or stack traces (traces only under `--debug`/`-v`) — per layout-templates §cli Component — Footer / terminator + error output. This is the layout-level statement of the chunk's own boundary invariant ("no host paths or internal struct names in any artifact a test writes or reads back").

## Patterns to follow
- Match on the always-printed ASCII bracket label, not on ANSI codes, when a test observes cli state output — the pairing rule exists so the signal survives piping and `NO_COLOR` (per layout-templates §cli Component — Primary content block 2).
- Enumerate stdout labels as "the closed six per-P-ID set **plus** the run-level qualifier" if any assertion parses state labels — the `[ENVIRONMENT-SUSPECT]` precedent is explicitly a qualifier, not a lamp (per layout-templates §cli Component — Primary content block 2).
- `Blocked` rows render the named precondition string in the detail slot with measurement columns as `—`/null on both surfaces — the same shape the `declares` predicate's unmet-term naming must feed (per layout-templates §cli Component — Primary content block 1 and §desktop-webview Component — Primary content block 2).
- stdout carries raw artifact data, stderr carries human messages, never mixed without intention — the split that constrains how the portability fix may capture or assert output (per layout-templates §cli IA notes, Pipe discipline).

## Anti-patterns to avoid
- Do not change cli table column count/order or add a bracket label as a side effect of test-hardening work — an unflagged column change is a breaking change for parsing agents (per layout-templates §cli IA notes, Command model).
- Do not assert or render a `Blocked` (or an unmet run-contract term) as red / as a `Fail` — `Blocked` was never measured (per layout-templates §cli Component — Primary content block 2).
- Do not satisfy the cross-runner requirement with anything that blocks the headless path on a prompt (per layout-templates §cli IA notes, Headless invariant).
