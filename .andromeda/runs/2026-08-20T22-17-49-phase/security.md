## Patterns to follow
- The duplex-transport test seam already used by `tests/jsonrpc_line_bound.rs` (the prior chunk's `MAX_LINE_BYTES` kill over the same bounded-decode boundary) and `tests/preflight.rs` / `tests/readback.rs` — asserting the boundary without constructing a `TokioChildProcess`, so the hardened-spawn invariant is untouched (per §Input Validation, MCP read-back child stdout row).
- Verdict/error wall discipline as the assertion vocabulary: harness faults as `Result::Err` with typed `thiserror` enums, verification outcomes as `Ok(Verdict/ReportState)` values (per §Error Handling, Internal logging + Error format).
- Artifact hygiene precedent from the committed-manifest readers — read faults carry `e.kind()` only, never the path (per §Input Validation, committed SUT-facing manifests row); the same path-free rule governs anything the ShapeWitness self-obs capture asserts on.
- Bounded-wait record discipline: verify `cargo deny check advisories bans licenses sources` **actually ran green** rather than assuming it, and state the changed basis when re-pinning the deferral — "no dependency delta" stops being available as a reason once a dep lands (per §Dependency Security, advisory-DATABASE fault bullet).

## Anti-patterns to avoid
- Never clear the red `cargo audit` by raising a tool floor, adding a `deny.toml` ignore, or editing CI — that suppresses a real signal class for a transient external fault (per §Dependency Security; §Anti-Patterns → Universal, audit-green rule).
- Never let a malformed, out-of-order, or unpairable child response panic on the read-back path — a panic there corrupts run classification (per §Anti-Patterns → Universal).
- Never bake an absolute host path, internal seam-crate struct name, or secret-shaped string into new test fixtures or captured-artifact assertions (per §Anti-Patterns → Logging, artifact-leak ban; → Secrets, no-secret-in-workspace ban).
