# design extract

## Relevance
Partial — this is a CLI/headless live-proof chunk with no webview surface, but its grading outcomes (CalibrationRegion severity, declare-only retirements, Blocked legs, the `AutoResolved` read-back arm) render through the cli status vocabulary, which design owns.

## Constraints
- The per-check status vocabulary is a **closed set**: design-system §Surface: cli / Tokens fixes the bracket labels `[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]` (+ the run-level non-lamp `[ENVIRONMENT-SUSPECT]` caption) and the glyphs `✓`/`✗`/`?`/`~`/`•`/`→`. Every outcome this leg produces — including whatever the `route_read_back` `AutoResolved` arm surfaces — must land inside that set; §Surface: cli requires no new lamp state, no new ANSI entry, no new bracket label. Whether the shipped run/verify path already renders the auto-resolve outcome inside the closed set is research's question.
- **CalibrationRegion is amber, never red.** design-system §Color Palette (Verdict-vs-ReportState note) maps amber to `Verdict::CalibrationRegion` (model-interpretive, report-for-human) and holds Fail red as a reserved, muted alarm edge. The scope's "severity choice asserted CalibrationRegion, never hard-failed on exact values" binds directly to that mapping (cli: ANSI 179 / `[HOLD]`-class).
- **A retirement to declare-only must render as neither green nor red.** design-system §Color Palette requires `ReportState::Blocked` (never measured — named precondition string, measurement columns `—`/null, ANSI 60 `[BLOCKED]`), `KnownResidual` (measured-but-pre-accepted, dashed/muted ANSI 246 `[RESIDUAL]`, carrying "expected until {named fix}"), and `ManualCheck` (no programmatic read-back, ANSI 146 `[MANUAL]`) to stay visually distinct so none silently reads as `Fail` — and §Surface: cli Component Pattern 4 requires the measurement be shown, not omitted. The scope's "never a vacuous green" and design's "never a surprise red" are the two halves of the same rule.
- **Closed SLO-tier set, rendered from the declared value.** design-system §Surface: cli / Component Patterns 4 (as amended 2026-08-18) requires the tier cell to render the scenario's declared `slo_tier` from the closed `<5s`/`<20s`/`<90s` set, never a baked per-scenario literal. Flag: the family's lifecycle windows named in scope (120s idle / 30s resolver ticks) sit above the set's `<90s` ceiling — whether any family scenario can declare a tier its observation actually meets is research's question; design's requirement is only that whatever is declared comes from the closed three.
- **Never color alone; ANSI-stripped legibility.** design-system §Surface: cli / Tokens + §Per-Surface Bans (cli) require every status to carry its ASCII prefix, `NO_COLOR`/`TERM=dumb`/piped-stdout stripping to be honored via `anstream`, and (per the 2026-08-09 amendment) the color-free Markdown counterpart to be emphasis or the bracket label — which governs this chunk's `leg-verdict.md` and captured journal evidence.
- **The headless path is never gated on a prompt, and the spinner stops rather than hides.** design-system §Surface: cli Component Patterns 1–2 + §Per-Surface Bans require `inquire` prompts to be `isatty`-gated with the headless decision recorded to the artifact, and require the `indicatif` spinner to STOP in place at a hold (never hide, never animate-to-100% — §Motion "High-impact moments"). Relevant because the P-023 ack stimulus / `mark_incident_resolved` and any `[MANUAL]` item must not block the agent-driven leg, and the family's long lifecycle waits are exactly where a progress affordance would be tempting.
- **stdout/stderr split with token reuse.** design-system §Surface: cli Component Pattern 5 requires raw artifact data on stdout and sanitized human messages on stderr (`error:` reusing Fail red ANSI 203, `hint:` the Residual mute ANSI 246, stderr-specific TTY gate) — no new colors for a new error edge.

## Patterns to follow
- **Results / SLO table** (design-system §Surface: cli Component Patterns 3) — the 6-column per-check table (P-ID · scenario · state · slo_tier · latency_ms · fingerprints) with dynamically detected width; a `Blocked` row carries its named precondition and renders measurement columns as `—`. Explicitly NOT the 4-column `conductor coverage` table, which carries no state column.
- **Verdict / report-state lines** (design-system §Surface: cli Component Patterns 4) — the per-P-ID in-place line shape, color always paired with the bracket prefix, `?` = awaiting operator, `~` = pre-accepted gap, `•` = never measured.
- **Recessive-tier reuse over new palette rows** (design-system §Color Palette Residual entry + §Surface: cli Tokens) — a new non-lamp de-emphasis (e.g. a declare-only qualifier, an out-of-scope cell, a run-level caption) reuses ANSI 246 / `var(--status-residual)` as a use-site note; the always-rendered text label carries the signal.
- **Run-level qualifier, not a seventh lamp** (design-system §Surface: cli Component Patterns 4) — `[ENVIRONMENT-SUSPECT]` prints once above the per-check lines when the profile breaches the SUT load envelope; qualifiers on a run never become new per-check states.

## Anti-patterns to avoid
- Inventing a new lamp state, bracket label, ANSI entry, or color token to express this family's new grading outcome (design-system §Anti-Patterns Universal Bans — color communicates Verdict/ReportState only; §Surface: cli Tokens closed set).
- Collapsing "not measured / structurally ungradeable" into `Fail` red, or greying it the same as "no result yet" (design-system §Anti-Patterns Rejected Defaults — conflating no-result-yet with failed; `Blocked` is a distinct state carrying its precondition).
- Emoji or color-dependent signalling in machine-parseable piped output, and hiding/animating the spinner at an operator-pause (design-system §Per-Surface Bans / cli).

## Contract bindings
- **design ↔ a11y:** the never-color-alone ASCII-prefix pairing (design-system §Surface: cli Tokens, §Iconography "Rule") is design's half; the conformance claim (SC 1.4.1) is a11y-plan's — this chunk's cli/headless legs make no conformance claim.
- **design ↔ layouts:** layout-templates §Surface: cli owns leg-transcript / table-column placement; design owns only the label + tint vocabulary that fills those columns.
- **design ↔ arch/obs (envelope enums):** the rendered `verdict` / `state` values must be the same closed domains the run-report envelope defines (arch's Verdict 3 / ReportState 5, per design-system §Color Palette Verdict-vs-ReportState note) — design constrains the render vocabulary, not the envelope schema.

## Acceptance criteria contributions
- (design) No new color token, ANSI entry, lamp state, or bracket label is introduced; every outcome of this leg — including the auto-resolve observation — renders inside the closed `[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]` set (per design-system §Surface: cli / Tokens).
- (design) Severity-choice grading renders hold-amber `[HOLD]`-class (CalibrationRegion), and any declare-only / ungradeable retirement renders `[RESIDUAL]`- or `[BLOCKED]`-class with its "expected until {fix}" note or named precondition and its measurement cells as `—` — never Fail red, never a green `[PASS]` (per design-system §Color Palette, Verdict-vs-ReportState note).
- (design) Any `slo_tier` rendered on a family row is drawn from the scenario's declared value within the closed `<5s`/`<20s`/`<90s` set, never a baked literal (per design-system §Surface: cli / Component Patterns 4).
- (design) Captured leg evidence (per-leg journal, `leg-verdict.md`) is fully legible with ANSI stripped — the ASCII bracket label carries the signal and the Markdown artifact assumes no color channel (per design-system §Surface: cli / Tokens + §Per-Surface Bans cli).
