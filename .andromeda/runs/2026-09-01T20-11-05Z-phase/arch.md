# arch extract

## Relevance
Relevant — arch binds workspace placement, harness-lifetime resources, the `--e2e` build precondition, and the scope law governing this leg; it adds no new external surface of its own.

## Constraints
- **All spec/harness/markup work lands in the npm subtree, not a Cargo member.** `crates/conductor-tauri/ui/` (specs, `wdio.conf.ts`, `src/**`) is registered as the frontend asset subtree and is invisible to cargo; the workspace-member roster is closed at the ten `conductor-*` names, so no chunk change may introduce a crate (per architecture.md §Occupied Resources — Frontend asset subtree · Crate names).
- **The driver handle and its ports are already the registered maximum for this leg.** `CONDUCTOR_MSEDGEDRIVER` is mandated read-only, `wdio.conf.ts`-only (never a shipped binary), never shell-interpolated, validated at the harness edge (existence + `isFile` + shell-metacharacter rejection) and passed as a separate argv element of an array-form spawn; unset or non-file MUST skip at exit 0 with a host-path-free precondition plus fetch recipe, never a hard failure. Loopback `4444`/`4445` are the only listeners the leg may bind, dev-only and harness-lifetime (per architecture.md §Occupied Resources — Environment variables · Ports).
- **The `--e2e` build precondition is a FEATURE, not a profile.** `tauri-build`'s `generate_context!` resolves `build.frontendDist` at compile time, so `npm run build` / `ensure_frontend` must precede any cargo compile of `conductor-tauri`; and only `--features tauri/custom-protocol` makes the binary serve the embedded bundle rather than `devUrl` — a bare release build opens `http://localhost:5173` (per architecture.md §Infrastructure Patterns — Build system).
- **Scope law: one automation stack, Conductor's own webview only.** Driving Conductor's webview is explicitly in-scope as the dev-only `--e2e` self-verify leg — one WebdriverIO + tauri-driver session, never a second stack, never Pulse's UI, whose visual claims ride the operator checklist (per architecture.md §Cross-cutting Patterns — Scope law · Trust boundary).
- **The leg stays a local/operator gate.** CI is build + test only (`cargo build` / nextest / clippy) on the dev OS target; dynamic proof requiring a live Pulse is an operator/local gate by decision, which is the arch basis for the chunk's own "not the A11y CI gate" boundary (per architecture.md §Established Decisions [CI/CD] · §Infrastructure Patterns — CI/CD approach).
- **The operator-checklist subject is a declared config surface with a fixed shape.** `[[checklist]]` is an array-of-tables of `ChecklistItem { induced, observation }`, both halves bounded by `MAX_CHECKLIST_TEXT = 200` — explicitly "a dialog row's display bound" — carried on `Scenario` and on `HoldPoint` so the hold projects the rows to its shell; `Scenario::check_checklist` rejects a `[[checklist]]` beside a non-empty `expected`, and exactly two committed scenarios declare it (`halo-hue-encoding`, `halo-breathing-encoding`). Any driven run that must render checklist rows is therefore constrained to a declare-only checklist scenario (per architecture.md §Conventions — Config conventions · §Established Decisions [Validation Library]).
- **Host paths stay out of artifacts.** Precondition strings are mandated host-path-free and `data_dir` redacted in the readiness result; the same discipline governs anything this leg emits, including the `--e2e` leg's CWD-relative `crates/conductor-tauri/ui/logs/conductor-tauri.jsonl` byproduct, which arch requires to be git-ignored (per architecture.md §Standard Contracts — Readiness gate · §Occupied Resources — On-disk artifacts).

## Patterns to follow
- **Skip-with-named-precondition, exit 0** — the established shape for an absent harness prerequisite (`CONDUCTOR_MSEDGEDRIVER` unset), and the structural precedent for the chunk's "subject absent ⇒ skip-with-reason, never fail" treatment (architecture.md §Occupied Resources — Environment variables).
- **Blocked-state discipline: never synthesize a value for something never measured** — a blocked row populates identity fields only, emits `null` for unmeasured fields, and writes zero per-check rows; cross-run queries must exclude them. The same "no phantom value" logic is what forbids a vacuously-asserted spec (architecture.md §Standard Contracts — Readiness gate · Per-check record).
- **ManualCheck is the terminal operator-judgment state** for a visual/operator-checklist claim with no programmatic read-back — the arch-side anchor for this chunk's display-gate split (judgment class stays operator-gated; affordance proof does not) (architecture.md §Established Decisions [Read-Back Dependency Posture] · [Probabilistic-Assertion Policy]).
- **Verdict-first lamp precedence with independent `verdict`/`state`** over the closed sets `Verdict ∈ {Pass, Fail, CalibrationRegion}` / `ReportState ∈ {Pass, Fail, ManualCheck, KnownResidual, Blocked}` — the state vocabulary the Blocked-vs-Fail token-distinctness assertion sits on (architecture.md §Established Decisions [Probabilistic-Assertion Policy] · §Standard Contracts).
- **Frontend styling rides `:root` design tokens under Tailwind v4** (`ui/src/styles/tokens.css`; `@theme` tree-shakes non-namespace tokens), self-hosted fonts, TypeScript strict — the shape any markup/ARIA/token fix for the axe violation must keep (architecture.md §Occupied Resources — Frontend asset subtree · §Inherited Defaults — Frontend).

## Anti-patterns to avoid
- **A second automation stack, or automating Pulse's UI** — both are named non-goals under the scope law (architecture.md §Cross-cutting Patterns — Scope law).
- **A new `CONDUCTOR_*` handle, a new listener, or a committed driver path** — the namespace is reserved for handles arch already defines, `CONDUCTOR_MSEDGEDRIVER` is the one entry naming a host dev-tool and its value is explicitly never committed, and shipped binaries open no port at all (architecture.md §Occupied Resources — Environment variables · Ports · §Cross-cutting Patterns — Trust boundary).
- **Promoting the leg into a CI gate, or letting a bare `cargo build --release` stand in for the `custom-protocol` build** — the first contradicts the locked CI decision, the second silently drives `devUrl` instead of the bundle (architecture.md §Established Decisions [CI/CD] · §Infrastructure Patterns — Build system).

## Contract bindings
- **arch ↔ a11y-plan §3/§5/§6** — arch owns the state vocabulary and lamp precedence (`Verdict`/`ReportState`, verdict-first) that the not-color-alone and Blocked-vs-Fail assertions read; a11y-plan owns the paths, keyboard, contrast pairs and motion the specs assert.
- **arch ↔ scenario config (core)** — the operator-pause/checklist subject is reachable only through the `[[checklist]]` + `HoldPoint` contract and its two declaring committed scenarios; whether the existing driven leg actually selects such a scenario and raises the hold is research's question.
- **arch ↔ tests harness** — the `--e2e` leg's build precondition (`ensure_frontend` → `npm run build`, then `--features tauri/custom-protocol`) and the 4444/4445 driver stack are arch-registered; the leg's invocation lives in `scripts/agent-run.{sh,ps1}`.
- **arch ↔ security** — the `CONDUCTOR_MSEDGEDRIVER` harness-edge validation (isFile + metacharacter rejection + array-form spawn) and the host-path-free/redaction rule are stated in arch but adjudicated by security-plan; the frontend dependency gate is `npm audit --omit=dev` with `package-lock.json` committed, if this chunk touches devDeps at all.

## Acceptance criteria contributions
- All spec, harness and markup changes live under `crates/conductor-tauri/ui/`; no new workspace crate and no change to the closed `conductor-*` member roster (per architecture.md §Occupied Resources — Frontend asset subtree · Crate names).
- The leg introduces no new `CONDUCTOR_*` env handle and binds no listener beyond dev-only harness-lifetime `127.0.0.1:4444`/`4445`; `CONDUCTOR_MSEDGEDRIVER` stays `wdio.conf.ts`-only, uncommitted, array-form-spawned, and unset ⇒ exit 0 skip with a host-path-free precondition (per architecture.md §Occupied Resources — Environment variables · Ports).
- Any driven run of the leg is built `npm run build` / `ensure_frontend` first, then `cargo build --release -p conductor-tauri --features tauri/custom-protocol` — whether the shipped `agent-run.{sh,ps1}` `--e2e` path already does exactly this is research's question (per architecture.md §Infrastructure Patterns — Build system).
- Exactly one WebdriverIO + tauri-driver session against Conductor's own webview, and the leg remains an operator/local gate rather than a CI gate (per architecture.md §Cross-cutting Patterns — Scope law · §Established Decisions [CI/CD]).
- No absolute host path appears in any artifact or precondition string the leg emits, and the `--e2e` leg's CWD-relative `ui/logs/conductor-tauri.jsonl` byproduct stays git-ignored — whether the ignore rule already covers it is research's question (per architecture.md §Standard Contracts — Readiness gate · §Occupied Resources — On-disk artifacts).
