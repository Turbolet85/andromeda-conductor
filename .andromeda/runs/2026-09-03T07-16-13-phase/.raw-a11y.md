## Constraints
- The load-envelope banner's DOM contract is a11y-owned: per a11y-plan §4 (per-component catalog, load-envelope banner row) the envelope `label` is **always rendered** plus its optional `cause`, and the banner is **omitted entirely when the run stayed in-envelope**. This independently corroborates the scope's layout-templates `:144` reading — the a11y-visible defect of `run_envelope -&gt; Ok(None)` is an **over-envelope run rendering nothing**, not the label vanishing from an in-envelope run. Whether the shipped `run_envelope` already produces that distinction is research's question.
- The routine a11y arm's subject must stay producible: per a11y-plan §4 (banner row) + §9 (E2E row) the routine arm seeds an over-envelope `run_envelope` row **through the production writer** (`cargo test -p conductor-run --test envelope_fixture` under `CONDUCTOR_E2E_SEED_DIR`) and the label spec + axe assert against that DOM state. §9 requires that a spec whose DOM state the seeded subject cannot produce **context-skips, never passing green** — so any reshaping/relocation of that fixture in service of killing survivors must keep the over-envelope subject writable.
- No a11y assertion can serve as a mutation-killing test: per a11y-plan §9 (Pipeline integration) + §3 (CI integration) the entire a11y gate rides the `wdio run` webview-E2E job and is **operator/local-gated, not CI-gated**, with no `npm test` lane in the Rust-first stack. A cargo-mutants kill for `run_envelope:224` therefore requires a Rust-side test; existing a11y coverage of the banner cannot substitute.
- The HOLD sites (`HoldGate::deliver:66`, `resolve_operator_hold:105`) back a must-be-accessible path: a11y-plan §1 (Critical paths — Operator-pause go/no-go) and §10 (zero WCAG AA violations on the four paths, no soft SLO) apply to what they gate. Per §9's E2E row, the driven arm asserting that path (`a11y:driven`: trap entry, Tab containment, Space toggle, `role=status`, Escape→NoGo, restoration) **requires a live Pulse plus its full firing form** — so no a11y evidence for these sites is obtainable inside this chunk's stated budget.
- A killing test may not weaken the banner's text signal: a11y-plan §11 (Visual) bans conveying state by color alone and §6 (Color contrast pairs) asserts `--status-residual`/`--color-raised-1` at **SC 1.4.3 4.5:1 because the token colours TEXT** — the always-rendered label *is* the signal, not a decoration a test may treat as optional.
- Artifact hygiene applies to whatever the fixture work produces: a11y-plan §3 (Structured violation JSON schema) requires node targets stored as DOM-relative selectors / `data-testid` and §11 (SLO) bans absolute host paths and internal seam-crate struct names in the obs §6 envelope. Staged-repo-root fixtures used to kill `resolve_handle:38` / `scenarios_dir:44` / `runs_dir:48` / `manifest_path:52` must not push host-absolute paths into artifact-bound values.

## Patterns to follow
- Committed fixture written through the production writer + read back through the production reader — a11y-plan §4's banner row names `conductor_run::read_envelope`'s round-trip **and the Tauri mock-runtime IPC test** as the banner's existing **non-DOM** verification path. That is the closest existing shape to a Rust-side kill for `run_envelope:224`, and it is the same precedent the scope's P4 fork (reuse across the package boundary vs. seed its own) is deciding between.
- Two-part coverage split (a11y-plan §6, note under the pairs table): a render-INDEPENDENT token-pair assertion plus a render-DEPENDENT DOM assertion. A Rust-side killing test is a third, non-DOM leg that should mirror the banner's contract rather than displace either existing half.
- State-naming crosswalk (a11y-plan §6, State color tokens): display label ↔ obs `verdict` ↔ obs `state`, verdict-first for HOLD. Any killing assertion touching lamp/verdict/state values must join through this table rather than inventing a mapping.
- Host-handle gating precedent (a11y-plan §3 Bootstrap `a11y-ci-gate-wire` / `screen-reader-test-spec-setup`): `CONDUCTOR_MSEDGEDRIVER` / `CONDUCTOR_NVDA` unset ⇒ **skip at exit 0**. If new fixture seeding needs a host/env handle, this is the established shape.

## Anti-patterns to avoid
- Never claim WCAG conformance without machine-verifiable evidence (a11y-plan §11 Strategy) — no accepted-deliberate ledger entry may cite "a11y already covers it" as its standing rule, since none of a11y's three arms run in this chunk.
- Never let artifacts leak absolute host paths or internal seam-crate struct names into the obs §6 envelope (a11y-plan §11 SLO).
- Never stand up a second browser-automation stack (puppeteer/CDP) for a11y (a11y-plan §11 CI) — if a webview-facing survivor tempts a driver-based observation, the only sanctioned stack is tests' `@crabnebula/tauri-driver` + WebdriverIO session.
