## Constraints
- The probe's own output surfaces (`conductor-cli` verb, `scripts/agent-run.{sh,ps1}`) are on the **cli surface, which a11y-plan.md §1 declares not-assertable** (no DOM/widget tree, no axe/Lighthouse/pa11y reach). No ARIA/WCAG obligation attaches to the probe's text output, and no WCAG conformance may be claimed from this chunk (per a11y-plan.md §1 A11y Scope Summary).
- If the probe result is emitted as a Conductor artifact, a11y-plan.md §3 Structured violation JSON schema requires artifacts aligned to the obs §6 envelope to **carry no absolute host paths and no internal seam-crate struct names** — matching the scope's "a `PATH` miss must be named without echoing the `PATH`" (also banned at §11 SLO).
- a11y-plan.md §9 Per-pipeline-stage a11y artifacts (E2E row) requires that the **routine arm needs no live Pulse** (it seeds its own committed fixture through the production writer) while the **driven arm (`npm run a11y:driven`) requires a live Pulse plus its full firing form**, and the **screen-reader leg (`a11y:sr` / `sr-empty` / `sr-error`) requires a Windows+NVDA host**. A precondition probe therefore gates only the latter two arms; it must not be allowed to relax the first.
- a11y-plan.md §9/§10 require that a leg whose subject cannot be produced **context-skips and never passes green**. A probe reporting "live Pulse absent" must translate to a declared skip, never a green pass and never a manufactured failure (reinforcing the scope's "not a verdict" boundary).
- a11y-plan.md §3 Bootstrap phases establishes the plan's **host-tool-handle shape for absent preconditions**: `CONDUCTOR_NVDA` unset ⇒ skip at exit 0 (`screen-reader-test-spec-setup`), `CONDUCTOR_MSEDGEDRIVER` unset ⇒ skip at exit 0 (`a11y-ci-gate-wire`). Any Pulse-precondition handle this chunk introduces should follow that same shape rather than invent a new absence protocol.
- a11y-plan.md §3 CI integration + §9 Pipeline integration require a11y results to surface through the **`logs` command of tests' binding 5-command contract** (boot / run / status / cleanup / logs). A new probe verb must not displace, wrap, or alter that emission path; the scope's mandatory `.sh`/`.ps1` parity applies to it equally.
- a11y-plan.md §10 Performance budget records that the driven arm's **quiet-window precondition costs two 12-minute runs when violated**, with a 15-minute mocha ceiling — the recorded a11y-side cost that the scope's ban on building the probe over `conductor preflight` / `agent-run boot` protects.

## Patterns to follow
- The host-tool-handle skip: an unset/absent environment handle yields **exit 0 with a declared skip**, per a11y-plan.md §3 Bootstrap phases (`CONDUCTOR_NVDA`, `CONDUCTOR_MSEDGEDRIVER`) — the closest existing precedent for naming an absent precondition once instead of absorbing it.
- Arm separation: routine (unattended, fixture-seeded, no live Pulse) vs operator-only driven vs operator-only screen-reader, per a11y-plan.md §9 E2E row. A precondition statement should name which arms it gates, not gate "a11y" wholesale.
- Recording an unreachable subject as a **finding, never a pass and never a manual arm** — the treatment a11y-plan.md §3 Screen reader test pattern applies to the 14 browse-mode rows.
- Artifact tagging: `service.name` / `deployment.environment` resource attributes on emitted artifacts for obs cross-correlation, per a11y-plan.md §9 CI-specific resource attributes — applies if the probe result becomes an uploaded artifact.

## Anti-patterns to avoid
- **NEVER skip the a11y gate on a precondition failure** — a11y-plan.md §11 CI bans treating the a11y step as a warning (`violations.length > 0` → non-zero exit, fail-fast). A live-Pulse-absent probe result must not become a bypass for the routine arm, which needs no live Pulse.
- **NEVER define a soft a11y SLO** (a11y-plan.md §11 SLO) — the probe is scheduling information and must not be reachable as a reason to downgrade a WCAG-AA violation, not-color-alone failure, or reduced-motion failure to non-blocking.
- **NEVER treat the cli surface as accessibility-assertable** (a11y-plan.md §11 Universal) — the probe's ASCII status prefixes / NO_COLOR text-pairing are output-stream discipline, not an a11y verification path, and must not be counted as a11y coverage.

- **a11y ↔ obs §6 envelope:** a11y violation/assertion artifacts reproduce the obs Run-report envelope verbatim and inherit the no-host-paths / no-struct-names constraint (a11y-plan.md §3 Structured violation JSON schema) — the same hygiene rule the scope states for probe output.
- **a11y ↔ tests §6 driver/host handles:** `CONDUCTOR_MSEDGEDRIVER` (webview arm) and `CONDUCTOR_NVDA` (SR leg) are the existing absence handles a Pulse-precondition handle would sit beside (a11y-plan.md §3 Bootstrap phases).
