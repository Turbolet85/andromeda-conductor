Findings 3, 4, 5, 7 and 8 change what "as shipped" means at these sites, so the plan text itself likely needs an amendment at wrap — the fixes must not silently diverge from it (per a11y-plan.md §3 Screen reader test pattern; §1 harness spec SR bullet).

## Patterns to follow
- One webview-automation stack: axe via `@axe-core/webdriverio` and keyboard/focus via `browser.keys()` + `document.activeElement` readback, both over the tests' `@crabnebula/tauri-driver` + WebdriverIO session; the SR leg grades NVDA's own `-l 12` speech log with the operator reviewing the record (a11y-plan.md §3 A11y testing tool pick, Focus management test harness, Screen reader test pattern).
- Semantic HTML first, ARIA second — shadcn/Radix primitives supply `alertdialog` / `combobox` / native checkbox semantics; fixes should adjust semantics rather than add compensating ARIA (a11y-plan.md §2 Agent-runnable invariants; §4 Naming convention; §11 ARIA).
- Live-region shapes already specified per component: verdict lamp `status`/`aria-live`, HOLD phase-line `aria-live="assertive"`, unticked-count roll-up as the checklist view's own `role=status` line (a11y-plan.md §4 per-component catalog; §3 Screen reader test pattern).
- Emitted a11y/SR records fold into the obs §6 envelope with rule-id + SC tag + **DOM-relative selector / `data-testid`** riding in `fingerprints[]`, no new top-level fields, and no absolute host paths or seam-crate struct names — the shape any new surfaced field (e.g. `tabs_to_start`) must respect (a11y-plan.md §3 Structured violation JSON schema).
- Arm split as specified: routine unattended arm (axe + colorjs.io + not-color-alone + compiled reduced-motion rule) vs operator-only driven arm and the `sr` / `sr-empty` / `sr-error` leg gated by `CONDUCTOR_NVDA` (unset ⇒ skip at exit 0), none CI-wired (a11y-plan.md §9 CI Integration, E2E row).

## Anti-patterns to avoid
- **Never stand up a second browser-automation stack** for a11y — the ban that CARRY 2a (Guidepup) must be weighed against at P4 (a11y-plan.md §11 CI).
- Never use `role="presentation"` / redundant-label ARIA noise, never `aria-hidden` (or `display:none` without an alternative) on nodes whose `aria-live` announcement is required, never conflicting ARIA states (a11y-plan.md §11 ARIA + §11 Screen Reader).
- Never soften the gate: no retry-once on a11y results, no soft SLO, no WCAG claim without machine-verifiable JSON, and manual/SR-only review is never the sole method (a11y-plan.md §10 SLO invariants; §11 SLO + §11 Universal + §11 Strategy).
