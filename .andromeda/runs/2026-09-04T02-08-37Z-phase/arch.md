# arch extract

## Relevance
Partial — arch governs workspace placement, the one-stack / trust-boundary bounds on CARRY 2a & 2b, the build-order coupling that decides whether a UI fix is even under test, and env-handle discipline; the ARIA/announcement semantics themselves belong to a11y-plan and the row grading to test-plan.

## Constraints
- **Workspace placement is split across two boundary classes.** The seven webview fixes and the spec/row table live under `crates/conductor-tauri/ui/` — the Vite + React 19 SPA that is npm-managed and explicitly **NOT a Cargo workspace member** (invisible to cargo); finding 8's `drive_run` abort-poll fix lands in `conductor-run`, the run composition root sitting **above the seams and below both bins**, so the fix must not introduce a new cross-seam dependency edge (per architecture.md §Occupied Resources — Frontend asset subtree · Crate names, and §Established Decisions [Module Boundaries]).
- **One automation stack, and it is named.** §Cross-cutting Patterns — Scope law requires that driving Conductor's own webview ship as THREE suite families (four `wdio` suites) over **ONE** WebdriverIO + tauri-driver stack, with NVDA's own speech log as the driver — "never a second automation stack". A `@guidepup/guidepup` adoption (CARRY 2a) is a second stack under that clause; the chunk's own boundary already declares it not adopted, and arch supplies the standing rule the P4 weighing must clear.
- **The trust boundary bounds what CARRY 2b may be.** §Cross-cutting Patterns — Trust boundary requires that the `sr*` suites' spawned children — host NVDA named by `CONDUCTOR_NVDA` and the fixed-argv PowerShell window-activation script — **open no listener**, and that the only dev-only listeners are the harness-lifetime `127.0.0.1:4444` / `:4445` pair (§Occupied Resources — Ports). A `SendInput`/`SendKeys` injection path must therefore stay a leg-process (or activation-script) child with no listener and no reach into a shipped binary; Conductor's shipped binaries have no inbound listener except the port-occupier fault.
- **`CONDUCTOR_*` is the only reserved handle namespace, and host dev-tool handles have a fixed shape.** Per §Occupied Resources — Environment variables, `CONDUCTOR_MSEDGEDRIVER` and `CONDUCTOR_NVDA` are validated at the harness edge (existence + `isFile` + shell-metacharacter rejection), passed as a separate argv element of an **array-form** spawn, never interpolated into a shell; unset or non-file makes the requesting suite **SKIP at exit 0** with a host-path-free precondition plus a fetch recipe, and the value is never logged, echoed into an artifact, or committed. Any handle CARRY 2b needs inherits that shape.
- **Build-order coupling decides whether the UI fixes are under test at all.** §Infrastructure Patterns — Build system requires `npm run build` before any cargo build compiling `conductor-tauri` (`generate_context!` resolves `build.frontendDist` at compile time), and records that the **`custom-protocol` feature — not the profile —** decides bundle-vs-`devUrl`: a bare `cargo build --release -p conductor-tauri` loads `http://localhost:5173`. Re-running `sr*` against a stale bundle would grade the old markup. Whether the leg's current firing form already satisfies both is research's question.
- **The verdict/error wall and the closed state set bound finding 8's fix.** §Established Decisions [Error Handling] and §Standard Contracts (Run report envelope) require outcomes to be typed values with `state` in the closed five-variant set and `Result::Err` reserved for harness faults; a client-vs-backend divergence at Stop is reconciled inside those types — no new report state, no `Err` standing in for an outcome. The backend→frontend live path is the Tauri 2 IPC `Channel` (§Established Decisions [Real-time Strategy]; §Standard Contracts — Live update channel), not a second transport.
- **File artifacts are the agent-parseable ground truth.** §Design Philosophy (journal-relative ground truth) plus §Cross-cutting Patterns — Development Style (agent-driven) make the leg's emitted JSON the evidence surface, not a transcript reading — which is what makes surfacing `tabsToStart` through the parser the arch-consistent evidence path for finding 1. Whether the committed parser already emits it is research's question.

## Patterns to follow
- **Host dev-tool handle pattern** (`CONDUCTOR_NVDA` / `CONDUCTOR_MSEDGEDRIVER`, §Occupied Resources — Environment variables): harness-edge validation, array-form fixed-argv spawn, skip-at-exit-0 with a host-path-free precondition. The template for any new leg-side tool or injection handle.
- **Third handle class precedent** (`CONDUCTOR_E2E_SEED_DIR`, §Occupied Resources — Environment variables): a harness-SET, repo-relative path read only by a test and never by a shipped binary, a no-op when unset — the precedent if the parser/leg needs a new path handle rather than an operator-supplied one.
- **Per-suite self-obs landing site** (§Occupied Resources — On-disk artifacts, `logs/conductor-tauri.jsonl`): the sink resolves as `runs_dir.parent()/logs`, so the re-run's backend stream lands at `runs/sr-leg/logs/` for `sr` / `sr-error` and `runs/logs/` for `sr-empty`; no `sr*` suite leaves `CONDUCTOR_RUNS_DIR` unset.
- **Two callers, deliberately different dispositions** (§Standard Contracts — Liveness equivalent): one shared primitive, each caller's disposition stated explicitly rather than inherited. The shape to reuse if `drive_run`'s abort poll gains a second reading (client-facing stage vs persisted outcome).
- **Dependency-gate pattern for the frontend tree** (§Stack — Desktop frontend row; §Inherited Defaults — Frontend): `npm audit --omit=dev` is the gate (production-dep strict, dev-only test-tooling advisories accepted), with `package-lock.json` committed — the standing bar any CARRY-2a dependency delta would face.

## Anti-patterns to avoid
- Adopting a second automation stack or a driver package because it exists rather than because it reaches what the speech log cannot (§Cross-cutting Patterns — Scope law).
- Opening any new listener, port, or network surface for key injection or evidence transport — Conductor is a gRPC/MCP client with no inbound listener of its own outside the port-occupier fault (§Cross-cutting Patterns — Trust boundary; §Occupied Resources — Ports).
- Introducing a config handle outside the `CONDUCTOR_*` namespace, interpolating an operator-supplied path into a shell, or committing/logging such a handle's value (§Occupied Resources — Environment variables).

## Contract bindings
- **Scope law "one stack" ↔ tests + security** — the CARRY-2a fork is graded against arch's one-stack rule, test-plan §6's harness roster, and security-plan §Dependency Security (the standing advisory-DB deferral the chunk's PREREQ re-pins).
- **Trust boundary + handle discipline ↔ security** — a CARRY-2b `SendInput`/`SendKeys` path inherits arch's no-listener bound and the harness-edge validation/array-form-spawn rules that security-plan owns at input grain.
- **Frontend asset subtree ↔ a11y + design-system** — all seven markup/behaviour fixes land in the same `crates/conductor-tauri/ui/src/` tree whose token/typography bundle design-system governs; arch fixes the location, a11y-plan §4/§5 fixes the semantics.
- **Build-order coupling (`npm run build` + `--features tauri/custom-protocol`) ↔ tests** — arch mandates the ordering; the leg's firing form is test-plan's to state.
- **Per-suite `CONDUCTOR_RUNS_DIR` landing sites ↔ obs** — the re-run's `conductor-tauri.jsonl` stream inherits obs-plan §3's processor-stage redaction at whichever per-suite site arch records.

## Acceptance criteria contributions
- (arch) Webview and spec/row changes land under `crates/conductor-tauri/ui/` (npm subtree, not a Cargo member) and the abort-poll change in `crates/conductor-run`, with no new cross-seam Cargo dependency edge (per architecture.md §Occupied Resources — Frontend asset subtree · Crate names / §Established Decisions [Module Boundaries]).
- (arch) The `sr*` re-run drives the ONE WebdriverIO + tauri-driver + NVDA-speech-log stack; any injection path added spawns a fixed-argv, array-form child that binds no listener beyond the harness-lifetime `4444`/`4445` pair (per architecture.md §Cross-cutting Patterns — Scope law · Trust boundary).
- (arch) No env handle outside `CONDUCTOR_*`; any new leg handle validates at the harness edge, skips at exit 0 when unset, and never has its value committed or logged (per architecture.md §Occupied Resources — Environment variables).
- (arch) The binary the re-run drives is built from a fresh `npm run build` and with `--features tauri/custom-protocol`, so the window serves the embedded bundle rather than `devUrl` (per architecture.md §Infrastructure Patterns — Build system).
