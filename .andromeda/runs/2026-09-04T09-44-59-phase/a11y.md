## Constraints
- The `conductor` verb surface is **not-assertable** as a SET (no DOM / widget tree, no axe/Lighthouse/pa11y reach), so `conductor preconditions` — including any change to its human/`--json` finding shape — carries **no ARIA, landmark, focus-order or WCAG obligation** (per a11y-plan.md §1 A11y Scope Summary → `conductor-cli` entity; reinforced §11 Universal).
- a11y-plan.md §9 Pipeline integration requires a11y runs to **reuse tests' binding 5-command harness discipline (boot / run / status / cleanup / logs)** and emit results through `logs`. `scripts/agent-run.{sh,ps1}` is that command surface, so `boot`'s short-circuit behaviour is a11y-load-bearing even though the repair itself is not a11y content (per a11y-plan.md §3 CI integration + §9).
- The plan requires the **operator-only driven arm (`npm run a11y:driven`)** — keyboard trap entry, Tab/Shift+Tab containment, Space toggle, `role=status` announce, Escape→NoGo, focus restoration — to run only with **a live Pulse plus its full firing form**, and the `sr` / `sr-empty` / `sr-error` legs to gate on `CONDUCTOR_NVDA`. That is the same live-Pulse precondition the chunk's open premise ("what proving `boot` reaches the preflight costs") is reasoning about (per a11y-plan.md §9 E2E row).
- a11y artifacts folded into the obs §6 envelope **MUST NOT leak absolute host paths or internal seam-crate struct names** (inherited from tests' Status JSON constraint). The handle this chunk regrades, `ANDROMEDA_PULSE_DATA_DIR`, is path-valued, so any probe output that reaches an a11y artifact stream inherits that ban (per a11y-plan.md §3 Structured violation JSON schema; §9 CI-specific resource attributes).
- The zero-WCAG-AA-violations SLO is scoped to the **four must-be-accessible paths** (scenario pick/start, operator-pause go/no-go, run-report view, operator-checklist). This chunk touches none of them, so it adds no new SLO surface (per a11y-plan.md §10 SLO Invariants).
- Whether the routine / driven / `sr*` a11y legs currently invoke `boot` — and are therefore blocked today by the probe's `exit 1` short-circuit — is **research's question**; the plan mandates the harness reuse but does not attest which entry point each leg calls.

## Patterns to follow
- **Host-tool handles graded by presence, unset ⇒ skip at exit 0** — a11y-plan.md §3 Bootstrap `a11y-ci-gate-wire` and §9 E2E row specify exactly this shape for `CONDUCTOR_MSEDGEDRIVER` and `CONDUCTOR_NVDA`. These are the plan's own precedent for a handle whose *value kind* (a host-tool/path handle) is graded by presence rather than affirmative truthiness — the same distinction this chunk draws for `ANDROMEDA_PULSE_DATA_DIR`.
- **A documented env test hook rather than env mutation** — a11y-plan.md §6 Motion tokens names `CONDUCTOR_TEST_REDUCED_MOTION` as a documented hook read at runtime. Consistent with the chunk's `[inferred]` preference for a lookup parameter over `unsafe { set_var }`.
- **Results surface through `logs`, not a new command** — a11y-plan.md §9 requires the a11y JSON step to emit through the `logs` command of the 5-command contract; a `boot` repair should leave that command surface intact.
- **Platform claims stated as measured, per-shell** — a11y-plan.md §9 Platform states the CI *arrangement* (Linux+`xvfb`) is not a capability bound and records the Windows host arm separately. The chunk's ".sh/.ps1 parity" proof should likewise claim only what each shell measured.

## Anti-patterns to avoid
- **NEVER treat the cli surface as accessibility-assertable** — its ASCII status prefixes / `NO_COLOR` text-pairing are output-stream discipline, not an ARIA verification path; no WCAG/a11y claim may be made from the `preconditions` verb's output (per a11y-plan.md §11 Universal).
- **NEVER let a11y artifacts carry absolute host paths or internal seam-crate struct names** into the obs §6 envelope — relevant because the regraded handle is a filesystem path (per a11y-plan.md §11 SLO).
- **NEVER let the a11y step degrade into a warning or a green-reporting skip on gate failure** — it is required to be a fail-fast gate; a repaired `boot` must not convert a probe failure into a silent skip for legs that ride it (per a11y-plan.md §11 CI).
