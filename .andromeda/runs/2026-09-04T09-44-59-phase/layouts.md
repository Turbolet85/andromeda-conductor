## Patterns to follow
- The run-level non-lamp qualifier precedent (`[ENVIRONMENT-SUSPECT]`, `not-conductors` Mode cell): a qualifier rides outside the lamp column, carries an always-printed ASCII label, and is omitted entirely when its condition does not hold (per layout-templates.md §cli Primary content block 2, §desktop-webview Primary content block 1).
- Set-naming over literals: layout-templates.md repeatedly de-literalizes derived values so a code change cannot re-stale the doc (per layout-templates.md §cli Primary screens `conductor coverage` — "every number manifest-derived (never a literal)"). If this chunk's diagnostics enumerate handles, name the set (`OBSERVED_HANDLES`), never a baked three-name literal.
- Verb-noun, flat, one level deep; the verb SET is whatever `Commands` (`crates/conductor-cli/src/cli.rs`) declares, never baked as a sample (per layout-templates.md §Surface: cli — Component — Primary navigation).
- Output structure is a stability contract because downstream agents parse it — adding a column or label without a `--format` flag is a breaking change (per layout-templates.md §Surface: cli — IA notes, Command model). The scope's open premise "whether the `--json` output shape changes at all" is bound by this: expected not.
- Terminator / dimmed-metadata mapping (ANSI 146) and ID-cyan (ANSI 117) for identifiers, adapted not forked from the desktop token names (per layout-templates.md §Surface: cli — IA notes, Multi-surface coordination).

## Anti-patterns to avoid
- Do NOT mint a new bracket label, ANSI entry, lamp state or `ReportState` for the presence-graded handle — the lamp set is closed at six and `[PRECONDITION]` is already the qualifier for this surface (per layout-templates.md §cli Primary content block 2).
- Do NOT print an absolute host path (the `ANDROMEDA_PULSE_DATA_DIR` value) in the unmet-subject caption or any `error:`/`hint:` line — stderr is sanitized of host paths (per layout-templates.md §cli Component — Footer / terminator + error output).
- Do NOT introduce an interactive prompt or TTY-gated branch into the probe or the `boot` arm — the agent-driven source-of-truth path is never gated on a prompt (per layout-templates.md §cli IA notes, Headless invariant).
