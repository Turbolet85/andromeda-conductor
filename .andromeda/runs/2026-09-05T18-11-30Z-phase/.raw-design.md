# design extract

## Relevance
**Partial** — W1 (`conductor-cli/src/render.rs`, `main.rs hint_for`, `pause.rs kind`) and W4b (`render.rs` ↔ `conductor-report/src/coverage.rs` dedup) sit directly on the `cli` output surface this domain governs; W2/W3/W4a/W4c/W5/W6 are outside it (no rendered surface touched, and W4a's error strings are explicitly unchanged).

## Constraints
- **Color is never the sole carrier.** Every status line must pair its tint with the ASCII bracket prefix from the closed six-lamp set `[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`, and the glyphs `✓`/`✗`/`?`/`~`/`•`/`→` are TTY-only, never in piped machine-parseable output (per design-system §Surface: cli / Tokens + §Anti-Patterns → Per-Surface Bans (cli)). This is the design mandate behind the scope's own "the status-never-color-alone invariant makes the PLAIN path the one that must be asserted" — whether `render.rs` already emits those prefixes on the no-color path is research's question.
- **The lamp set is closed at six; the run-level captions are outside it.** `[ENVIRONMENT-SUSPECT]` (load envelope) and `[PRECONDITION]` (preconditions probe) are ANSI 246 run-level captions, neither a lamp state nor a `ReportState` (per design-system §Surface: cli / Tokens, status-prefix line). W1's `envelope_caption` survivors must be killed by assertions that keep the caption outside the lamp column — no assertion may promote it to a seventh lamp.
- **The ANSI map is a by-name closed set — no new codes.** 114 green / 179 amber / 203 red / 60 violet / 146 lavender / 246 mute / 117 ID-cyan, with P-IDs, run_id, SLO timings, latency_ms and fingerprints in 117 (per design-system §Surface: cli / Tokens). W1's `paint` / `lamp_code` / `latency` / `wire` kills and W4b's shared formatter must bind these existing values, never introduce a code or palette row.
- **The per-stream TTY gate has three conditions, decided independently per stream.** `owo-colors` behind `std::io::IsTerminal`, each of stdout and stderr requiring a terminal AND `NO_COLOR` unset AND `TERM != dumb` (per design-system §Surface: cli / Tokens preamble + §Platform-Specific Notes). Any seam W1 introduces for `stdout_color` / `stderr_color` (terminal-ness as a parameter, or an env override) must preserve all three conditions and the stdout/stderr independence.
- **Coverage and Results are two different tables.** `conductor coverage` renders 4 columns (P-ID · Title · Category · Mode), carries **no** verdict/state column and therefore **no** bracket prefix, and terminates in a roll-up caption; the Results/SLO table is the separate 6-column form (per design-system §Surface: cli / Component Patterns 3). W4b's shared formatter must not conflate them, and the out-of-scope Mode cell (`not-conductors`) keeps the Residual-mute tint.
- **Color-free media get a surface-adapted counterpart, not the ANSI.** Markdown has no color channel, so the Residual tier renders as emphasis (`_not-conductors_`) or the bracket label in a blockquote (per design-system §Color Palette / Residual-mute entry + §Surface: cli / Tokens). W4b moves a formatter into `conductor-report`, which renders Markdown — the shared code must keep the two surfaces' color-vs-emphasis expression distinct even where the roll-up logic is shared.
- **Terminal width is detected dynamically; the `error:`/`hint:` pair is fixed.** `comfy-table` widths are never hardcoded or wrapped at arbitrary points (per design-system §Spacing surface-conditional + §Anti-Patterns cli), and `error:` reuses Fail red 203 / `hint:` reuses Residual mute 246 on stderr's own gate with sanitized content (no absolute host paths, struct names or stack traces outside `--debug`/`-v`) (per design-system §Surface: cli / Component Patterns 5) — the constraint that shapes W1's `main.rs:55 hint_for` kill assertions.

## Patterns to follow
- **Prefix + color + de-literalized tier** — the shipped verdict-line form `✓ P-009  Pass  1840ms &lt;slo_tier&gt;`, where the tier comes from the scenario's declared value in the closed `&lt;5s`/`&lt;20s`/`&lt;90s` set rather than a baked per-scenario literal (design-system §Surface: cli / Component Patterns 4). Content assertions written to kill the string-builder survivors should assert the prefix and the structural form, not a frozen sample.
- **Reuse a shipped token pair rather than adding a palette row** — the `error:`/`hint:` precedent (203/246 reused, zero new entries) and the out-of-scope Mode cell (Residual-mute reused a third time) (design-system §Surface: cli / Tokens; amendments 2026-06-24, 2026-08-09).
- **Name the SET, never a literal count** — the non-lamp caption set and the Residual tier's reuse list are written as sets precisely so a fourth member does not re-stale the prose (design-system §Surface: cli / Tokens). If W1/W4b add or move a reuse site, the doc treatment is set-framing.
- **Spec-illustration → sound-impl reconciliation** — where a measured kill assertion shows the shipped render disagrees with an illustrative sample in the plan (a string, a column, a sample line), the routine is to correct the doc to the measured shipped value while the invariant holds, as done for `No coverage data.` / `No run yet` (amendments 2026-09-02, 2026-09-04).

## Anti-patterns to avoid
- **NEVER let a kill assertion depend on ANSI alone.** Asserting only the escape sequence (or only the colored variant) re-introduces the color-alone failure the ASCII prefix exists to prevent (design-system §Anti-Patterns → Per-Surface Bans (cli): "NEVER rely on color alone").
- **NEVER add a new ANSI code, palette row, lamp state, or bracket label** to satisfy a mutant or to give the shared formatter a "neutral" tint (design-system §Surface: cli / Tokens; §Anti-Patterns → Universal Bans: color communicates Verdict/ReportState only).
- **NEVER hardcode a table width, wrap point, or emoji** in the deduplicated formatter (design-system §Anti-Patterns → Per-Surface Bans (cli)).

## Contract bindings
- **Never-color-alone ↔ a11y §Use of Color (SC 1.4.1):** the CLI mirror of the not-color-alone rule is the ASCII bracket prefix; the plain/`NO_COLOR` path assertions W1 needs are the same artifact both domains rely on. Flag for a11y to confirm the shared proof.
- **Sanitized `hint:` ↔ security-plan §Error output / redaction boundary:** design mandates the `error:`/`hint:` shape, security owns what may appear in it — `hint_for` kill assertions must not pin host-absolute paths or internal struct names into a test expectation.
- **Design invariant ↔ test-plan §10/§12 cited rules:** where a survivor is accepted-deliberate rather than killed, a design rule (e.g. "the plain path is the asserted path") can be the cited rule only if it actually mandates the behaviour; a tint-only mutant with an asserted plain path is the shape that qualifies.
- **`--status-residual` ↔ ANSI 246 by-name pair:** W4b spans both surfaces of this pair (CLI ANSI, report Markdown); the pair is bound by name, so a shared formatter must not collapse it to one surface's expression.

## Acceptance criteria contributions
- Every status/caption line touched by W1's kills is asserted on the no-color path by its ASCII text (`[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`, `[ENVIRONMENT-SUSPECT]`, `[PRECONDITION]`, `error:`/`hint:`), so no assertion makes color the sole carrier (per design-system §Surface: cli / Tokens + §Anti-Patterns → Per-Surface Bans (cli)).
- No new ANSI code, palette row, lamp state, or bracket label is introduced by any kill assertion or by W4b's shared formatter; the six-lamp set and the two-member non-lamp caption set stay closed (per design-system §Surface: cli / Tokens + §Color Palette).
- After W4b, `conductor coverage` still renders its separate 4-column table (P-ID · Title · Category · Mode) with no verdict/state column and no bracket prefix, ending in its roll-up caption, while the 6-column Results/SLO table keeps its state column — and the Markdown surface keeps its emphasis counterpart rather than inheriting ANSI (per design-system §Surface: cli / Component Patterns 3 + §Color Palette Residual-mute entry).
- Any seam introduced to make `stdout_color` / `stderr_color` testable preserves the three-condition gate (IsTerminal AND `NO_COLOR` unset AND `TERM != dumb`) evaluated independently for stdout and stderr, and piped output still carries no ANSI (per design-system §Surface: cli / Tokens + §Platform-Specific Notes).
