## Patterns to follow
- **Sibling-module naming:** snake_case `.rs` files / module paths under a kebab-case `conductor-<seam>` crate (arch §Conventions — Naming patterns); the crate root `mod`s + `pub use`s them, mirroring the existing `dispatch.rs` sibling.
- **Edge-vs-seam error placement:** typed `thiserror` enums inside seam crates, `anyhow` only at `conductor-cli` / `#[tauri::command]` edges (arch §Established Decisions [Error Handling]) — W4a's shared resolve-and-map-error prologue belongs at the tauri edge, not pushed down into a seam crate.
- **Presentation stays in `conductor-cli`:** arch §Stack and Technologies places owo-colors/indicatif/comfy-table/inquire tty-gated rendering in `conductor-cli`, while the directory tree (§Infrastructure Patterns) makes `conductor-report` the JSONL/Markdown/`runs.db` storage seam — so a W4b shared formatter carries the roll-up, not the tty styling.
- **Library symbols are deliberately NOT arch-registered:** the §Occupied Resources enumeration tracks crates, ports, env vars, on-disk artifacts, MCP tool names and the Tauri command set — never module or `pub fn` inventories (see amendment history below), so a new `pub fn` in `conductor-report` and N new `conductor-run` modules need no arch registration.
- **Pure-function time inputs:** arch §Cross-cutting Patterns — Determinism discipline requires wall-clock stamps from `std::time::SystemTime`/`Instant` and never tokio's virtual clock; a `civil_from_unix` boundary-date test should feed fixed epoch values to the pure conversion rather than reaching a clock, and its rendered form stays colon-delimited RFC-3339 per §Standard Contracts — Timestamp formats.

## Anti-patterns to avoid
- **Discharging the route-owned standalone-build repair as W3 side effect.** arch §Established Decisions [Module Boundaries] records `cargo check -p conductor-verify --lib` red on `tokio::time::sleep` (`preflight.rs:336`) because tokio's `time` feature sits in that crate's `[dev-dependencies]` and not `[dependencies]`, and names the manifest repair route-owned (*Dependency polish*) — which this chunk's scope also excludes. Bounding a SHIPPED await (the tauri-chunk precedent W3 cites) would require that feature in `[dependencies]`; whether the shipped `jsonrpc.rs` path can already be bounded without a manifest change is research's question.
- **Changing the registered route-equivalent set.** arch §Occupied Resources — Interface routes declares the four consumed MCP tool names plus the Tauri command names (start/stop · scenario/suite picker · run-report view · operator-pause prompt) the COMPLETE route-equivalent set; a W4a prologue helper must not add, rename or collapse a command.
- **Letting a refactor move an arch-registered shape.** arch §Standard Contracts fixes the eleven-field run envelope and the nine-key `CheckRecord` (JSONL journal · `run_check` · Markdown detail line); the W5 split and the W4b/W4c dedups are byte-unchanged-behaviour work, so neither shape may shift.
