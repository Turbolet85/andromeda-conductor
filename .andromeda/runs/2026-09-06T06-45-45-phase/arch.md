# arch extract

## Relevance
Relevant — arch is load-bearing here: the CI ban, workspace placement of the invocation, the persisted-record contracts W3 asserts from, and the no-new-listener / env-namespace discipline all bind this chunk.

## Constraints
- **The live suite may never become a CI gate, and no live leg may sit on a default path.** arch §Established Decisions [CI/CD] and §Infrastructure Patterns (CI/CD approach) require GitHub Actions to run `cargo build` / nextest / clippy only, with dynamic end-to-end scenario proof (live Pulse + `mcp-server` feature + `ANDROMEDA_PULSE_MCP_ENABLED`) as an explicit operator/local gate. This binds W1's shape boundary directly: whichever of the four admissible forms is chosen, it must not attach to `nextest` / `clippy` / release.
- **Headless is the source of truth; the invocation composes the core, it does not fork it.** arch §Design Philosophy (headless-drivable core, thin shells), §Established Decisions [Deployment] and §Cross-cutting Patterns (Development Style: agent-driven) require `scripts/agent-run.sh` to be the release gate and both shells + the GUI to call the same core identically. A live-suite entry point that reimplements leg ordering outside the shared core would violate this.
- **Code placement is fixed by the workspace registry.** arch §Occupied Resources (Crate names) registers `conductor-run` as the run composition root (preflight + `execute_scenario` + `persist` + the live-counter driver) shared by both bins, sitting above the seams and below `conductor-cli` / `conductor-tauri`. arch §Project Intent requires a new module seam to be a new workspace crate with explicit `Cargo.toml` edges — so a new crate is registrable but never implicit, and arch §Established Decisions [Module Boundaries] governs the edges.
- **`CONDUCTOR_*` is the reserved handle namespace; `ANDROMEDA_PULSE_*` is read-only to Conductor.** arch §Occupied Resources (Environment variables) enumerates every handle and pins three distinct control models (operator-supplied host dev-tool paths validated at the harness edge; harness-set repo-relative paths read by no shipped binary; Conductor's own artifact handles). It further requires the `ANDROMEDA_PULSE_*` handles be asserted **not set** by Conductor and only READ, and records the `CONDUCTOR_AGENT_MODE` precedent — `flag || env-set`, main never WRITES, avoiding edition-2024 `unsafe std::env::set_var`. A composed invocation must therefore refuse an unmet env rather than materialize one.
- **`PATH` is a spawn-resolution input, and a miss is indistinguishable from a SUT gate failure.** arch §Occupied Resources (Service/process names) records the sidecar as a fixed NAME resolved through the inherited `PATH`, and that a `PATH` miss returns BLOCKED in ~2ms with all four tools `absent` — "at row level indistinguishable from a genuine SUT-side gate failure" — which is why an operator-driven live leg carries a `PATH` prefix **as part of its firing form, not as an optional extra**. This is precisely the silent-`[BLOCKED]` class W1 must refuse.
- **No new inbound listener; the deliberate-bind set is closed.** arch §Occupied Resources (Ports) + §Cross-cutting Patterns (Trust boundary) hold `:4317` (the port-occupier fault, the only shipped-binary bind) plus the dev-only harness-lifetime `4444`/`4445` as the whole set, with `:4318` unused.
- **Scheduling-time refusal is a reported precondition, never an `Err` and never a verdict.** arch §Standard Contracts (Liveness equivalent) requires the `:4317` connectability primitive to carry two dispositions — a `Result::Err` inside the timeline engine, a reported unmet precondition + non-zero exit at `observe_preconditions`, "because it runs before any scenario exists to carry one" — under the §Cross-cutting Patterns verdict/error wall.

## Patterns to follow
- **The precondition probe as the refuse-a-partial-env primitive.** arch §Standard Contracts (Liveness equivalent) specifies `conductor_run::observe_preconditions` grading THREE subjects (`egress-reachable` · `sidecar-resolvable` · `handles-declared`), each graded by the KIND of value its handle carries via `conductor_core::handle_declared` / `flag_declared`, with `agent-run boot` short-circuiting only on a genuinely unmet subject. It is the existing shape for W1's "refuse rather than degrade"; whether the shipped composition already routes every leg through it is research's question.
- **The two shared artifact shapes are the persisted-record surface.** arch §Standard Contracts registers the eleven-field run envelope and the nine-key `CheckRecord`, riding three surfaces (the per-run JSONL journal, the `runs.db` `run_check` table, the Markdown per-check detail line), with §Occupied Resources fixing `runs.db` at three tables. W3's "from persisted records" must land on these.
- **The self-obs stream, and its truncation semantics.** arch §Occupied Resources (On-disk artifacts) registers `logs/agent-latest.jsonl` as a separate artifact and schema from the emission journal, written as a sibling of the runs dir (moves with `CONDUCTOR_RUNS_DIR`) and **truncated per invocation** (the `-latest` name). W2's capture/grade split and W3's observable #3 both read it; the truncation is load-bearing for a two-leg present/absent assertion.
- **Fixed-path resolution with a deliberately absent override.** arch §Occupied Resources records each `contracts/*` manifest resolved from a fixed `default_path()` through `resolve_under` with deliberately NO `CONDUCTOR_*` handle — the precedent if this chunk lands a committed suite descriptor rather than a handle.
- **The readiness-gate result shape and its precondition ordering.** arch §Standard Contracts (Readiness gate) pins the `ReadyState` shape (`ready` · `negotiated_protocol_version` · per-tool presence · `canary_round_trip` · `blocked_precondition` · `checked_at`), the FIVE named preconditions, the rule that the run-contract-terms arm sits BEFORE the canary arms and skips the poll rather than paying it, and that every precondition string is host-path-free with `data_dir` redacted.

## Anti-patterns to avoid
- **Minting a second automation stack, or automating PULSE's UI.** arch §Cross-cutting Patterns (Scope law) permits driving Conductor's OWN webview as THREE suite families (four `wdio` suites) over ONE WebdriverIO + tauri-driver stack — "never a second automation stack" — and bans PULSE UI automation and Pulse process management outright.
- **Gating shipped behaviour on a feature declared only in `[dev-dependencies]`.** arch §Established Decisions [Module Boundaries] qualifies the standalone per-seam build as an intent, not a guarantee, and names the measured trap (workspace feature unification masking a `[dev-dependencies]`-only feature). A `live-pulse`-gated target must declare what it uses where a `-p` build can see it.
- **Composing the env by writing it.** arch §Occupied Resources (`CONDUCTOR_AGENT_MODE`, `ANDROMEDA_PULSE_*`) requires Conductor to READ these handles and never write them; a suite that exports the missing half of a partial env would both violate the read-only assertion and destroy the refusal W1 exists to provide.

## Contract bindings
- **arch §Standard Contracts (envelope + `CheckRecord`) ↔ tests (W3).** Neither shape carries a `degraded` key — the envelope's eleven fields and `CheckRecord`'s nine keys are enumerated closed — and arch requires a declare-only scenario to emit **zero** `run_check` rows. So whether `Observation.degraded == true` reaches ANY persisted surface today (versus only `state: "KnownResidual"` / `verdict: null` / `fingerprints: []` in the envelope, or a self-obs line) is research's question; if it does not, W3's observable #1 either rides a proxy or requires a shape change arch must register.
- **arch §Standard Contracts (Timestamp formats) + §Conventions (Data model conventions) ↔ tests (W3 observable #2).** The two instants are TEXT **second-precision** RFC-3339 while `latency_ms` is a separate INTEGER-ms column (2026-06-21 amendment: "the envelope carries only second-precision RFC-3339 instants + a precomputed `latency_ms`"). A persisted-record equality check is therefore bounded by that encoding's precision — the assertion form must account for it, or read a finer-grained source.
- **arch §Established Decisions [CI/CD] ↔ test-plan §9.** The live-leg CI ban has two homes stating one rule; this chunk must not weaken either.
- **arch §Occupied Resources (Ports `4444`/`4445`; `CONDUCTOR_MSEDGEDRIVER` / `CONDUCTOR_NVDA` / `CONDUCTOR_E2E_SEED_DIR`) ↔ a11y + security.** If the invocation composes the driven or `sr*` arms, it inherits their skip-at-exit-0 guards, their edge validation (existence + `isFile` + shell-metacharacter rejection, array-form spawn), and the per-suite `conductor-tauri.jsonl` landing site keyed off `CONDUCTOR_RUNS_DIR`.
- **arch §Infrastructure Patterns (Build system) ↔ any webview leg.** `npm run build` must precede any cargo compile of `conductor-tauri`, and the `custom-protocol` FEATURE (not the profile) decides whether the binary serves the bundle or `devUrl` — a composed invocation touching the webview inherits both.

- (arch) Every string in the chunk's evidence artifact and precondition output is host-path-free with `data_dir` redacted (per architecture.md §Standard Contracts — Readiness gate).
