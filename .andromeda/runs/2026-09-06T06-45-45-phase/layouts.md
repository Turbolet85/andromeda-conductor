- The per-P-ID lamp/bracket set is **closed at six** (`[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`); a run-level statement rides in the non-lamp qualifier SET **outside** the lamp column, and the chunk must mint no seventh label, no new `ReportState`, no new ANSI or token entry (per §Component — Primary content block 2 (verdict / report-state lines)).
- If the invocation is operator-gated on a TTY, the signature is mandated: the `indicatif` heartbeat **STOPS in place at the exact value** (never hides, never animates to 100%) and a bold ANSI 179 `HOLD — operator pause` line carrying the frozen count as text prints **above** the `inquire` confirm (per §Signature placement (cli); §Component — Hero / signature output (Paused-count hold-point — CLI mirror)).
- The headless invariant is absolute: `inquire` prompts check `isatty` first, and the agent-driven source-of-truth path is **never** gated on a prompt — the decision is recorded to the artifact instead (per §IA notes — Headless invariant; §Component — Hero / signature output). Whether the current live-proof firing forms already honour this on every arm is research's question.
- If W1 lands as an `agent-run` verb/stage, it ships in `scripts/agent-run.{sh,ps1}` at **identical semantics**, and a stage gated on a Conductor-owned handle whose absence skips at exit 0 with a host-path-free `error:`/`hint:` precondition — never a hard failure (per §Surface: cli — Primary screens, the `scripts/agent-run.{sh,ps1}` bullet).
- Output structure is a parsed contract: raw artifact data on stdout, human messages on stderr, ANSI auto-stripped when piped, `NO_COLOR`/`TERM=dumb` honoured, no emoji in machine-parseable output, and adding a `comfy-table` column without a `--format` flag is a breaking change (per §IA notes — Pipe discipline; Command model).

## Patterns to follow
- The `conductor preconditions [--json]` screen shape — a non-mutating probe that exits 0 iff every subject is satisfied, prints both caption arms, **mints no `Verdict`, no `ReportState`, no per-P-ID row, and fires no canary** (per §Surface: cli — Primary screens). W1's precondition refusal should compose this rather than mint a second precondition report shape; W4's canary-identity fork sits directly against its "fires no canary, primes no SUT state" property.
- The `conductor run <scenario>` output spine (per §Output structure — `conductor run <scenario>`): header printed once per command → readiness line → `→ phase` lines → `indicatif` heartbeat → hold → per-P-ID verdict lines → summary table → terminator naming the artifact path (ANSI 146 dim, un-colorized when piped). Any new invocation reuses this order.
- The **indented-detail-line precedent** — extra grain (a `Blocked` precondition string, a `KnownResidual` note, the per-check detail region under `runs/<run_id>.md`) rides as an indented plain-text line beneath its P-ID verdict line, with no new column, bracket label, ANSI or token (per §Component — Primary content block 2, per-check detail region). This is the shape available to W3's three CARRY-2 observables if they surface in the run report.
- The `[ENVIRONMENT-SUSPECT]` run-level qualifier: printed once per run, above the verdict lines, ASCII bracket label always rendered, **omitted entirely** when not applicable, adapted per surface (cli bracket / Markdown banner / webview banner) never forked (per §Component — Primary content block 2; §Output structure — `conductor run`).
- Terminal-width detection for any table, never hardcoded; two distinct `comfy-table` shapes exist (6-column results/SLO vs 4-column coverage) and must not be conflated (per §Component — Primary content block 1 (results / SLO table)).

## Anti-patterns to avoid
- Do not mint a live-proof-specific bracket label, lamp, `ReportState` or ANSI/token entry for the suite's own state — the lamp set stays six and run-level statements ride outside the lamp column (per §Component — Primary content block 2).
- Do not put an interactive gate on the headless source-of-truth path; an `inquire` prompt reached without an `isatty` check silently breaks the release gate (per §IA notes — Headless invariant).
- Do not express the hold as a hide, an animate-to-100%, a full-screen redraw or cursor manipulation — the stop in place IS the signature, at the 0.3 expression budget (per §Expression level (cli); §Component — Hero / signature output).

## Contract bindings
- **cli status labels ↔ a11y / `NO_COLOR`**: layouts states the requirement (every status paired with an ASCII text prefix so the signal is never color-alone and survives piping / screen readers); a11y and NO_COLOR conformance derive from it (per §Signature placement (cli), closing paragraph).
- **cli tints ↔ design tokens**: any color used must reuse the existing by-name mapping (`count-nominal` ↔ ANSI 114, `count-hold` ↔ 179, `status-fail` ↔ 203, `count-blocked` ↔ 60, `color-id-cyan` ↔ 117, journal-text ↔ 146) — adapted, never forked; design owns the values (per §IA notes — Multi-surface coordination).
- **terminator artifact line ↔ tests/obs evidence convention**: W2's evidence artifact needs a destination line in the terminator form (`run report → runs/<run_id>.md`, dim, un-colorized when piped); the capture/grade split and frozen-leg-line grading are the tests harness's contract, layouts only owns how the destination is announced (per §Component — Footer / terminator + error output).
- **desktop HOLD dialog ↔ a11y** (only if a webview-driven arm is part of the invocation): the Channel-opened `AlertDialog` gets trap + Escape from Radix but **not** focus restoration — restoration is contract-borne via a `restoreFocusTo` accessor in `onCloseAutoFocus`, and the invoking control conveys unavailability with `aria-disabled`, never the native `disabled` attribute (per §Component — Hero / signature section).
