# a11y extract

## Relevance
Partial — no rendered-UI surface is touched (the journal + CLI are not-assertable per a11y-plan §1), but the chunk gates the exact envelope schema a11y-plan §3 reproduces verbatim for its own violation artifacts, and the CARRY's `run_envelope` cleanup delete meets the routine-arm seed subject a11y-plan §4 depends on.

## Constraints
- The eleven-field Run-report envelope is a11y's violation-artifact carrier: a11y-plan §3 (Structured violation JSON schema) requires a11y emissions to align to the obs §6 envelope reproduced verbatim, with axe rule-id + WCAG-SC tag + node selector folded into `fingerprints[]` and **no new top-level fields**. Whatever shape this gate asserts is therefore also the shape a11y's §1 + §3 reproductions must continue to match; a gate that forces a field change obliges an amendment to both reproduction sites (precedent: the 2026-06-16 amendment below).
- Nullability is part of "schema-complete", not an exemption: a11y-plan §3's reproduction declares `read_back_observed_at` "null until read-back; null for blocked rows" and `latency_ms` "integer or null (null for blocked rows)". A completeness assertion that treats a present-but-null field as missing would false-fail rows a11y's own artifacts emit in the same shape.
- The `verdict` / `state` enums are join keys, not free strings: a11y-plan §6 (State color tokens — state-naming crosswalk) declares the crosswalk **binding** for the obs join and states downstream MUST use it to join a failing lamp back to its journal row. Governed co-occurrences it depends on — `verdict == CalibrationRegion` with `state == ManualCheck`, and `CalibrationRegion` with `KnownResidual` (verdict-first precedence) — must survive the gate; a combination-validity check narrower than the crosswalk would reject rows the lamp join requires.
- Host-path freedom is already an a11y requirement over the same envelope: a11y-plan §11 (SLO) bans letting a11y artifacts leak absolute host paths or internal seam-crate struct names into the obs §6 envelope, and §3 requires node `target` selectors be stored DOM-relative / `data-testid`, never filesystem paths. Mirroring one source (`conductor-core::redact`) rather than minting a second notion keeps a11y's inherited constraint single-sourced; whether a11y artifacts are today covered by any such gate is out of this chunk's boundary and not asserted here.
- The routine a11y arm's subject is a seeded `run_envelope` row: a11y-plan §4 (load-envelope banner row) records the unattended arm seeding an over-envelope `run_envelope` row through the production writer under `CONDUCTOR_E2E_SEED_DIR`, which is what makes the banner's label spec + rendered-DOM axe assertable. The CARRY adds a `DELETE FROM run_envelope` to both `cleanup` shells — whether that delete's run-id targeting can reach the seeded fixture row is research's question, and if it can, a11y-plan §9's rule applies (below).
- No a11y assertion is owed on the journal-producing surface itself: a11y-plan §11 (Universal) bans treating the cli surface as accessibility-assertable, and §1 flags the whole `conductor` verb surface not-assertable. A hermetic Blocked-run producer or CLI-invoked gate step adds no WCAG obligation.

## Patterns to follow
- Fold new machine-readable assertions into the existing envelope rather than extending it — a11y-plan §3 does exactly this for axe `violations[]`, colorjs.io ratio JSON and keyboard PASS/FAIL (all ride `fingerprints[]`, `state` = `Fail` when violations exist).
- Fail-fast, non-zero exit, no soft mode: a11y-plan §10 (Build / deploy failure conditions) and §9 (`violations.length &gt; 0` → non-zero exit) are the established "a violation is red" shape the chunk's build-failing requirement parallels.
- A spec with no producible subject context-skips, never passes green — a11y-plan §9 (E2E row) keeps this rule even after the routine arm gained its seeded subject. If the gate's journal producer is a fixture, the same discipline applies to a gate run with no journal.
- Artifacts tag `service.name` / `deployment.environment` for cross-correlation with the `runs.db` row and the JSONL journal, per a11y-plan §9 (CI-specific resource attributes) and §10 (Cross-input parallel).

## Anti-patterns to avoid
- Never let artifacts leak absolute host paths or internal seam-crate struct names into the obs §6 envelope (a11y-plan §11 SLO) — the gate must not itself embed host paths in its failure output.
- Never define a soft gate: a warning-only or retry-once disposition is banned for a11y's parallel invariant (a11y-plan §11 SLO / §11 CI, "FAIL-fast gate, not a warning").
- Never treat a second notion of a shared constraint as acceptable — a11y-plan §11 CI's one-stack ban is the same principle applied to tooling; the host-path notion should stay single-sourced.

## Contract bindings
- **a11y ↔ obs §6:** a11y-plan §3 reproduces the eleven-field envelope verbatim as the carrier for violation JSON; any envelope shape finding from this gate cascades to a11y-plan §1 (harness spec) and §3 (violation schema), both of which hold a full reproduction.
- **a11y ↔ tests (Status JSON constraint):** a11y-plan §3 + §9 inherit "no absolute host paths / no internal seam-crate struct names" from tests' Status JSON shape constraint — the same notion this gate mirrors from `conductor-core::redact`.
- **a11y ↔ tests §6 wdio routine arm:** a11y-plan §4 + §9 bind the load-envelope banner's assertability to the arm's seeded `run_envelope` row (production writer, `CONDUCTOR_E2E_SEED_DIR`), which the CARRY's cleanup change touches.
- **a11y ↔ obs verdict/state enums:** a11y-plan §6 crosswalk is the binding lamp↔journal join; the gate's enum handling is its upstream.

## Acceptance criteria contributions
- (a11y) The gate's asserted envelope field set matches the eleven-field shape reproduced verbatim in a11y-plan §1 and §3; if the gate requires any field added, renamed or removed, both a11y reproduction sites are flagged for amendment rather than silently diverging (per a11y-plan §3 Structured violation JSON schema).
- (a11y) A row with `read_back_observed_at: null` and/or `latency_ms: null` (blocked / not-yet-read-back rows) is judged schema-COMPLETE, not missing-field (per a11y-plan §3 Structured violation JSON schema).
- (a11y) The gate accepts the crosswalk's governed co-occurrences — `verdict == CalibrationRegion` with `state == ManualCheck`, and `CalibrationRegion` with `KnownResidual` — so the lamp→journal join stays valid (per a11y-plan §6 State color tokens, state-naming crosswalk).
- (a11y) If the CARRY's new `run_envelope` delete can reach the routine arm's seeded over-envelope row, the banner's label spec + rendered-DOM axe either keep a producible subject or context-skip; they never pass green without one (per a11y-plan §9 CI Integration E2E row + §4 load-envelope banner row).
