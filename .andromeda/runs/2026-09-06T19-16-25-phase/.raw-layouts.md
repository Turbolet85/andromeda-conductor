- Do **not** add a column to the 6-column `comfy-table` results/SLO table (e.g. to surface the delegated hue duration) — output structure is a parsed contract and a new column without a `--format` flag is a breaking change (per §cli IA notes — Command model · §cli Component — Primary content block 1).
