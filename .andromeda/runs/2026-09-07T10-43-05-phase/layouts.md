## Constraints
- The `indicatif` heartbeat must, on the operator-pause, **STOP in place at the exact value** — not hide, not clear, not animate-to-100%; the stop IS the signature (per layout-templates.md §Surface: cli — Signature placement #1, and §Component — Hero / signature output). A bump that changes the finish/abandon API must be resolved in favour of a stopped-in-place bar. Whether the shipped `conductor-cli` presentation code already stops in place (vs. finishing or clearing) is research's question.
- The bold ANSI-179 `HOLD — operator pause` phase line must print **above** the `inquire` proceed/abort confirm, carrying the frozen count as text — the held number stays legible at the decision point independently of the stopped spinner (per layout-templates.md §Surface: cli — Signature placement #2 · §Component — Hero / signature output).
- Progress rendering must stay honest and line-oriented: spinner appears only after ~200ms, no cursor manipulation, no full-screen redraw, no animate-to-100% (per layout-templates.md §Surface: cli — Expression level). A major-series indicatif move must not import a redraw/TUI-style draw target.
- Pipe + headless discipline is a layout invariant, not a nicety: styling TTY-gated per stream, ANSI auto-stripped when piped, `NO_COLOR`/`TERM=dumb` honored, `inquire` gated on `isatty`, and the agent-driven path **never** blocked on a prompt (per layout-templates.md §Surface: cli — IA notes, Pipe discipline + Headless invariant). A progress-crate bump must not leak draw-target writes into piped stdout.
- The per-P-ID label set is **closed at six** (`[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`) plus the run-level non-lamp qualifier SET (`[ENVIRONMENT-SUSPECT]`, `[PRECONDITION]`) — no chunk work here may mint a seventh label, a sixth `ReportState`, or a new ANSI/token entry (per layout-templates.md §Surface: cli — Component Primary content block 2). This binds B7: an eighth `PiiCategory` is corpus data, not a rendered state; the `P-035 pii-scrub` row stays a `[MANUAL]` operator-checklist line.
- `layout-templates.md` states `indicatif` 0.17 as this surface's stated tooling at exactly one site (§Surface: cli — Tooling context). If A1 moves the resolved series, that line becomes drift; the chunk's own boundaries reserve the master edit for wrap, so this domain's product is the *shape* of the correction, not the write.
- This plan carries `Tauri ≥ 2.10.3` in **floor form at three sites** — §Surface: desktop-webview Tooling context, §desktop-webview IA notes (Security guardrails), §Decisions Log Notes — all inside layout-level security-guardrail statements. B1b's sweep names only one of the three and classes floor statements as not-stale; none of the three is a version claim (`v2.10.x` / `latest 2.10.1` form appears nowhere in this doc).

## Patterns to follow
- **SET-naming over baked literals** for anything derived: the `conductor coverage` roll-up caption renders `(N unbacked)` placeholder form rather than a number, and the verb enumeration names whatever `Commands` declares (per layout-templates.md §Surface: cli — Primary screens · §Component — Primary navigation). If the indicatif tooling-context literal must move, prefer naming what pins it over substituting a fresh version literal.
- **Adapted, never forked, across surfaces**: the cli spinner-stop is the named mirror of the desktop-webview titlebar count freeze, bound token-by-name (`count-nominal` ↔ ANSI 114, `count-hold` ↔ ANSI 179) (per layout-templates.md §Surface: cli — IA notes Multi-surface coordination · §Decisions Log Signature placement strategy). An indicatif API delta must not shift the cli arm out of shape with the webview arm.
- **Colour always paired with an ASCII prefix** so signal survives `NO_COLOR`, piping and screen readers (per layout-templates.md §Surface: cli — Signature placement closing rule · §Component Primary content block 2). Applies to any HOLD/phase line the bump forces to be re-emitted.
- **Build-dependency changes register no surface here**: this plan enumerates rendered regions, cli verbs and stage flags — not Cargo features or npm devDependencies. A2, B3, B4, B5 and B6 add no verb, no stage flag, no column, no bracket label, so they touch no region this plan owns (per layout-templates.md §Surface: cli — Primary screens · §Decisions Log).

## Anti-patterns to avoid
- Resolving an indicatif API rename by **finishing / clearing / completing** the bar at the hold — the freeze is the event; a `finish_and_clear`-shaped fix silently deletes the signature (per layout-templates.md §Surface: cli — Signature placement #1).
- Adopting any full-screen-redraw or cursor-manipulating progress mode the newer crate offers — ratatui-style TUI is a standing omission (per layout-templates.md §Surface: cli — Expression level · §IA notes Command model).
- Sweeping `Tauri ≥ 2.10.3` floor statements as stale version claims during B1b (per layout-templates.md §desktop-webview IA notes — Security guardrails).
