## Patterns to follow
- Per-seam isolation loop: crate-local `#[cfg(test)]` modules plus crate-local `tests/`, driven by `cargo nextest run -p conductor-<seam>` — the fast verification shape for B3/B4/B7's per-crate edits (per test-plan.md §2 Test directory conventions, §4 Conventions).
- The OTLP-egress loopback gRPC stub: a tonic `TraceService` server over `tokio-stream::wrappers::TcpListenerStream` on an ephemeral `127.0.0.1:0`, never binding the real `:4317` — the dev-tree consumer of the `opentelemetry-proto`/`tonic` dev-dep pair that the A2/B3 trim must leave compiling (per test-plan.md §2 Integration row, §8 Mocking libraries).
- The two golden families: envelope/journal goldens (redacting `run_id`/`journal_emitted_at`/`read_back_observed_at`) and seeded stream goldens under `<crate>/tests/snapshots/`, one file per family × seed (`replay__*` · `pacing__*` · `dispatch_wire__*`) — the artifacts a dep trim or a corpus change would move (per test-plan.md §7 Golden artifacts).
- Committed-fixture round-trip: every committed fixture is asserted through the production reader/writer so a change leaving it parseable-but-inert fails at `cargo nextest` rather than silently weakening a downstream assertion — the model for any expectation the eighth `PiiCategory` touches (per test-plan.md §7 Self-bootstrapping requirement).
- cli assertion shape: assert_cmd + predicates on exit code plus the NO_COLOR-stable bracket-label set (the six lamps plus the non-lamp `[ENVIRONMENT-SUSPECT]`/`[PRECONDITION]` captions), stdin closed — the leg an indicatif bump is most likely to perturb (per test-plan.md §1 Surfaces under test / cli, §6 Drivers per surface).

## Anti-patterns to avoid
- Never skip a quality gate "just this once" or lower `--fail-under-lines` to absorb a dependency move; audit-green + coverage + clippy are binding (per test-plan.md §11 Quality, §11 CI).
- Never absorb a bump-induced flake with nextest `retries` or a quarantine-by-retry; a flake or a runner-dependent result indicates a real determinism break (per test-plan.md §11 Quality, §10 Zero-flakiness budget).
- Never force-fit wiremock-rs onto the gRPC OTLP egress if the trim disturbs the tonic stub — the sanctioned substitutes are an in-process tonic server or turmoil (per test-plan.md §11 Mocking).
