## Constraints
- **One webview-automation stack.** The gate must inject axe via `@axe-core/webdriverio` into the tests-owned `@crabnebula/tauri-driver` + WebdriverIO session; a parallel puppeteer/CDP stack is banned (per a11y-plan.md §3 A11y testing tool pick and §11 Anti-Patterns → CI). The scope's own boundary at `:565` is this ban's site.
- **The gate is runner-agnostic by mandate, not by exception.** §3 Bootstrap `a11y-ci-gate-wire` requires "not Linux-bound": Linux+`xvfb` and headfully on the Windows WebView2 host under `CONDUCTOR_MSEDGEDRIVER`; §9 Platform states `ubuntu-latest`+`xvfb` as the CI *arrangement*, not a capability bound; macOS alone lacks a WebDriver (per a11y-plan.md §3, §9 Platform).
- **Fail-fast, no soft edges.** `violations.length &gt; 0` must exit non-zero; no retry-once policy; no warning-only mode; a per-PR diff against base for new WCAG AA violations is required, not optional (per a11y-plan.md §9 Pipeline integration, §10 SLO Invariants, §11 Anti-Patterns → SLO). §11 CI's "NEVER skip a11y on CI/operator-gate failure — a FAIL-fast gate, not a warning" is the domain rule that bears directly on the scope's open question 2 (skip-at-exit-0 on a runner with no `CONDUCTOR_MSEDGEDRIVER`).
- **Violation JSON is obs's envelope, narrowed — never extended.** The artifact must reproduce the obs §6 envelope verbatim with envelope `state` = `Fail` when violations exist; axe rule-id + WCAG-SC tag + node selector fold into `fingerprints[]` so **no new top-level fields** appear; selectors are DOM-relative / `data-testid`, never filesystem paths; artifacts carry `service.name` (`conductor-tauri` / `conductor-ui`) + `deployment.environment` (+ `ci.run.id` / `git.commit.sha` in CI) (per a11y-plan.md §3 Structured violation JSON schema, §9 CI-specific resource attributes). This is the exact-field answer the scope's open question 3 asks for.
- **axe tag scope is fixed at the Minimal baseline.** `withTags(['wcag2a','wcag2aa','wcag21aa'])`; `wcag22aa` stays unset (so `target-size` does not run); any partial configuration (`runOnly` excluding defaults such as `color-contrast`) requires an explicit Decisions Log entry (per a11y-plan.md §3 Configuration, §6 Target size tokens, §11 Anti-Patterns → Strategy).
- **Arm eligibility for a without-Pulse gate is spec-determined.** §9's E2E row requires the routine `--e2e` arm to run with **no live Pulse** (it seeds its own committed fixture through the production writer), while the `driven` arm requires a live Pulse plus its full firing form and the `sr*` leg requires `CONDUCTOR_NVDA` and is supplemental-never-sole; §9 records all three as not CI-wired (per a11y-plan.md §9 CI Integration, §3 Screen reader test pattern). Whether the shipped suites actually match that arm split today is research's question.
- **POUR coverage may not be partial.** §11 Anti-Patterns → Strategy requires *both* axe-core `color-contrast` and WebdriverIO-keyboard on every must-be-accessible path — yet §9/§3 place the keyboard/focus/restoration half on the operator-only driven arm. A without-Pulse CI gate therefore cannot carry the Operable half without either a plan amendment or an explicit recorded carve-out; resolving that is P3/P5's, and phase is read-only on the plan.

## Patterns to follow
- **Ride the existing job, don't create a stack.** §3 CI integration → Command specifies the a11y JSON step rides the tests' `wdio run` webview-E2E job, with axe + colorjs.io token pairs + not-color-alone + the compiled reduced-motion rule on the routine `--e2e` arm and keyboard/focus-trap/restoration on `a11y:driven`.
- **Emit through the tests 5-command contract.** Results surface via the `logs` command of tests' boot / run / status / cleanup / logs harness surface — the binding command surface a11y reuses (per a11y-plan.md §1 CI integration, §3 CI integration, §9 Pipeline integration).
- **Host-tool handle guard.** `CONDUCTOR_MSEDGEDRIVER` (and `CONDUCTOR_NVDA` for the SR leg) unset ⇒ skip at exit 0 is the plan's own recorded local-host shape (per a11y-plan.md §3 Bootstrap `a11y-ci-gate-wire` and `screen-reader-test-spec-setup`) — the shape whose CI-side behavior this chunk must decide against §11 CI's no-skipping-gate ban.
- **Uniform result folding.** colorjs.io `{ token_fg, token_bg, ratio, required, pass }`, keyboard PASS/FAIL, and reduced-motion `{ element, prop, value, reduced_motion_respected }` all fold into the same obs §6 envelope as axe's `violations[]` (per a11y-plan.md §3 Contrast verification harness, §6 Verification, §6 Motion tokens).
- **Artifact handling.** `actions/upload-artifact` + per-PR diff vs base; GitHub Actions default retention (per a11y-plan.md §3 Artifact, §9 Artifact retention).

## Anti-patterns to avoid
- **A gate that can pass by skipping, warning, or retrying.** §11 Anti-Patterns → CI ("FAIL-fast gate, not a warning") and → SLO ("NEVER define a soft a11y SLO", "NEVER use a retry-once policy", "NEVER skip the per-PR diff"). CARRY 3's measured `sr*` run-to-run variance cannot be absorbed by a retry — the plan's remedy is arm selection, not tolerance.
- **Deleting or unpinning the harness devDeps on a static-analysis report.** `@axe-core/webdriverio`, `axe-core@4.12.0`, `colorjs.io@0.6.1`, `lighthouse@13.0.3` are §3-mandated by name and pin (Bootstrap `a11y-tooling-install` + `contrast-verification-harness-setup`), and §11 CI requires the runtime axe-core step to run — so CARRY 5's 20 knip false positives are non-actionable against the harness; a `knip.json` entry-point config is the sanctioned shape.
- **Leaking host paths or internal names into the artifact.** §11 Anti-Patterns → SLO bans absolute host paths and internal seam-crate struct names in the obs §6 envelope (inherited from tests' Status JSON constraint) — this is the scope's "redacted" half.

## Acceptance criteria contributions
- (a11y) The a11y job exits non-zero when `violations.length &gt; 0`, with no retry, no warning-only mode, and a per-PR diff against base for new WCAG AA violations (per a11y-plan.md §9 Pipeline integration + §10 Build / deploy failure conditions).
- (a11y) The CI arm cannot report success by skipping: an absent host-tool handle (`CONDUCTOR_MSEDGEDRIVER`) must not yield a green gate, since a skipping gate is banned (per a11y-plan.md §11 Anti-Patterns → CI).
- (a11y) Emitted violation JSON validates against the obs §6 envelope with zero new top-level fields, axe rule-id + WCAG-SC tag + selector inside `fingerprints[]`, `service.name` + `deployment.environment` set, and no absolute host paths or internal seam-crate struct names (per a11y-plan.md §3 Structured violation JSON schema + §11 Anti-Patterns → SLO).
- (a11y) The gated run executes the full routine-arm assertion set — axe under `wcag2a`/`wcag2aa`/`wcag21aa`, colorjs.io token-pair ratios, not-color-alone, and the compiled `@media (prefers-reduced-motion: reduce)` rule — not axe alone, within the axe-core &lt; 30s budget (per a11y-plan.md §9 E2E row + §3 Configuration + §10 Performance budget).
