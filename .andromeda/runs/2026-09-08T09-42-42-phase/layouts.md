## Constraints
- The `--e2e` stage is the CROSS-SURFACE leg (release Tauri bundle → desktop-webview console via the tauri-driver webview leg), gated on a Conductor-owned driver handle; its handle-absence outcome is an ARM SET, not one verdict — default arm SKIPS at exit 0 with a host-path-free `error:`/`hint:` precondition, affirmative `CONDUCTOR_A11Y_STRICT` exits non-zero instead (per layout-templates §Surface: cli — Primary screens, `scripts/agent-run.{sh,ps1}` bullet). Any remedy must leave all three outcomes standing rather than collapsing them.
- §Surface: cli — Primary screens requires the `--e2e` leg to assert the runner's **PRINTED verdict** rather than its exit code: the `Spec Files:` failed count, the per-spec skip markers against the expected-skip set, and the `[webview2 … windows]` driven-session banner — "because the exit code alone cannot tell a full pass from a total skip." Whether the shipped `.ps1` leg already performs all three assertions is research's question; the plan states it as a mandate.
- cli error output must be sanitized: `error: <short>` + contextual detail + `hint: <fix>`, on stderr, **no absolute host paths / internal struct names / stack traces**, never colorized when piped (per §Surface: cli — Component — Footer / terminator + error output). Any diagnostic printing added while working the four hypotheses is bound by this, and it aligns with the chunk's probe-ref hygiene constraint.
- The per-P-ID bracket-label set is **closed at six**, and the run-level non-lamp qualifier SET on cli is exactly `[ENVIRONMENT-SUSPECT]` + `[PRECONDITION]` (per §Surface: cli — Component — Primary content block 2). A session-creation diagnostic or remedy must mint no seventh label, no new `ReportState`, no new ANSI entry and no new token.
- Headless invariant: the agent-driven source-of-truth path is **never** gated on an interactive prompt, and prompts check `isatty` first (per §Surface: cli — IA notes). No hosted-runner remedy may introduce a prompt or a TTY assumption on the CI path.
- Shell parity is conditioned: "both shells ship at identical semantics" is a property of the SCRIPTS **together with the invoking environment** — a caller preempting native-command exits diverges the `.ps1` leg with zero script delta (per §Surface: cli — Primary screens, `agent-run.{sh,ps1}` bullet). The CI job runs the `.ps1` leg, so a runner-environment difference is inside this stated envelope, not a script bug.
- The surface a created session lands on is a single frameless window with **no routes, no breakpoints, no deep links** — the operator/driver moves through run state (`idle` · `live` · `hold` · `aborted`), not pages (per §Surface: desktop-webview — Primary screens · IA notes). Specs address run states; there is no navigation surface for a driver to address.

## Patterns to follow
- **Refuse-vs-skip two-class placement** (per §Surface: cli — Primary screens, the `--live` / `--e2e` contrast): an incomplete live-Pulse environment REFUSES at exit 1; an absent HOST-TOOL handle SKIPS its own leg. A WebView2 session-creation failure should be classified into one of the existing classes (host-tool-class skip vs environment refusal) rather than introducing a third outcome shape.
- **Host-path-free `error:` / `hint:` precondition pair** is the established shape for an unresolved host-tool handle (per §Surface: cli — Primary screens). If hypothesis 2's `WEBVIEW2_USER_DATA_FOLDER` (or any new handle) becomes a guard, it reuses that shape rather than inventing a new message form.
- **Adapted per surface, never forked** (per §Surface: cli — IA notes Multi-surface coordination · §Component — Primary content block 2 qualifier SET): a fact that must appear on more than one surface reuses the existing token/label mapping by name.
- **Record the measured gap, keep the target** — layout-templates carries UNBUILT / "DESIGNED, NOT SHIPPED" regions with their measurement date instead of deleting the design intent (per §Component — Footer (status strip) · §Component — Operator-checklist). A `deferred` v2-24 disposition with the measured cause in `notes` follows the same habit.

## Anti-patterns to avoid
- Minting a new bracket label, lamp state, `ReportState`, ANSI entry or token to represent the session-creation failure (per §Surface: cli — Component — Primary content block 2; the lamp set is closed at six and the `not-conductors` Mode-cell precedent governs non-lamp qualifiers).
- Printing an absolute host path, an internal struct name or a raw stack trace in any new probe/remedy diagnostic, or emitting it on stdout (stdout stays reserved for raw artifact data) (per §Surface: cli — Component — Footer / terminator + error output · IA notes Pipe discipline).
- Treating exit 0 alone as the green signal for the `--e2e` leg, or adding an interactive gate anywhere on the headless path (per §Surface: cli — Primary screens · IA notes Headless invariant).

- (layouts) A "green a11y job" claim is judged on the leg's PRINTED verdict — `Spec Files:` failed count, per-spec skip markers checked against the expected-skip set, and the `[webview2 … windows]` driven-session banner present — never on exit 0 alone (per layout-templates §Surface: cli — Primary screens, `scripts/agent-run.{sh,ps1}` bullet).
- (layouts) Any handle-absence or precondition outcome added/changed by the remedy preserves the three-arm set: default-arm skip at exit 0 with a host-path-free `error:`/`hint:` precondition, non-zero under an affirmative `CONDUCTOR_A11Y_STRICT` (per §Surface: cli — Primary screens).
- (layouts) The remedy and every probe diagnostic mint no new cli bracket label, lamp state, `ReportState`, ANSI entry or design token (per §Surface: cli — Component — Primary content block 2).
- (layouts) Every new line the probe/remedy prints routes to stderr in the `error:` / `hint:` shape, carries no absolute host path, and blocks on no prompt (per §Surface: cli — Component — Footer / terminator + error output · §Surface: cli — IA notes Headless invariant).
