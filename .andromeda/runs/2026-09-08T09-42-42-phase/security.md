## Patterns to follow
- The handle-NAME + boolean precondition print (`[precondition] CONDUCTOR_MSEDGEDRIVER: resolved`) is the plan's sanctioned way to report a path handle's state in CI — reproduce that shape for any new handle or version probe rather than echoing a resolved path (per security-plan §Input Validation, `CONDUCTOR_MSEDGEDRIVER` row).
- Array-form spawn with a fixed/repo-derived program and every operator-supplied value as a separate argv element after metacharacter rejection — the shape all five governed forms share (per security-plan §Security Anti-Patterns → Code Patterns rule (b)).
- Harness-owned constants travel to a child through the spawn's **env map**, never argv and never a shell (the `CONDUCTOR_E2E_SEED_DIR` model) — the fit for a harness-chosen `WEBVIEW2_USER_DATA_FOLDER` (per security-plan §Input Validation, `CONDUCTOR_E2E_SEED_DIR` row).
- Path-scrubbing third-party tool output before it becomes a committed record — the speech-log ingest scrubs drive-letter / `%APPDATA%` / `/Users` / `/home` tokens to `<host-path>`; the already-committed `ci-msedgedriver-verbose.log` is described as path-scrubbed, and the same treatment governs any new msedgedriver verbose capture (per security-plan §Input Validation, speech-log ingest row; §Security Anti-Patterns → Logging).
- Recording a residual explicitly when a control model does not apply, instead of silently omitting the boundary — the pattern used for both test-binary readers and the harness-constant handle (per security-plan §Input Validation, `CONDUCTOR_E2E_SEED_DIR` row; §Security Anti-Patterns → Input).

## Anti-patterns to avoid
- NEVER weaken the wdio-edge guard set to obtain a session: no removal of existence / `isFile` / shell-metacharacter rejection, no operator-chosen or bare-`PATH` driver program, no value assembled into a shell string, and no operator value as the spawn program except through the guarded host-tool form (per security-plan §Security Anti-Patterns → Code Patterns rule (b); §Security Anti-Patterns → Input).
- NEVER let an absolute host path or internal seam-crate struct name reach a probe branch on the public repo, a committed evidence capture, the workflow file, or the `v2-24` `notes` (per security-plan §Security Anti-Patterns → Logging).
- NEVER land the driver dependency swap with `Cargo.lock` drift, an uncommitted `package-lock.json`, or an unrun/red `npm audit --omit=dev` (per security-plan §Security Anti-Patterns → Universal; §Dependency Security, Frontend (npm) supply chain).
