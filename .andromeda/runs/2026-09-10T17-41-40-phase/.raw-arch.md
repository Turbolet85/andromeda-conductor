## Constraints
- **The headless binary is the release gate; the bundle is convenience.** `architecture.md` §Established Decisions [Deployment] + §Design Philosophy ("Headless-drivable core, thin shells") require that `cargo build --release` + `scripts/agent-run.{sh,ps1}` be the release gate and that the Tauri 2 bundler (2.11.3) artifact be produced as convenience, **not** as a gate. This bears directly on the scope's open question about unproduced bundle targets on a Windows-only host: arch already denies the bundle gate status, so whether `v2-27`'s acceptance nonetheless makes a specific target load-bearing is research's question.
- **The `custom-protocol` FEATURE, not the profile, decides bundle embedding.** §Infrastructure Patterns — Build system (restated at §Occupied Resources — Ports) requires that a binary which must serve the embedded webview be built `cargo build --release -p conductor-tauri --features tauri/custom-protocol`; a bare `--release` build emits `cargo:rustc-cfg=dev` and loads `devUrl`. Whether the shipped-artifact SLO subject is built in that form is research's question.
- **Frontend-before-cargo build order is a hard coupling.** §Infrastructure Patterns — Build system requires `npm run build` (the `ensure_frontend` step) before *any* workspace cargo compile of `conductor-tauri`, because `tauri::generate_context!` resolves `build.frontendDist` (`ui/dist`) at COMPILE time and a bare `cargo build` never runs `beforeBuildCommand`.
- **The standing supply-chain gate is two cargo runners plus the npm one, over an un-drifted lock.** §Infrastructure Patterns — Build system requires `cargo deny check advisories bans licenses sources` exit 0 AND `cargo audit` exit 0 with every allowed warning `deny.toml`-adjudicated and each exception naming its crate + dependency path inline; §Inherited Defaults (Frontend) requires `npm audit --omit=dev` clean with `package-lock.json` committed. The same section requires that a red `cargo audit` be diagnosed by reading the advisory-db clone's `git status --porcelain` BEFORE any parse failure is classified as external.
- **The artifact must honour the registered toolchain/dependency pins, and arch mandates no package-version stamp.** §Stack and Technologies + §Inherited Defaults pin Rust 2024 / cargo 1.85 / MSRV 1.94.1, tokio 1.52.3, Tauri bundler 2.11.3, Vite ≥8.0.16 — these are dependency and toolchain versions only. Arch registers **no** workspace package-version or `tauri.conf.json` `version` policy anywhere, so the scope's version-stamp question has no arch mandate to satisfy; whether another spec requires the 0.2.0 bump is research's question.
- **CARRY A's remedy may not widen a seam crate's public surface.** §Established Decisions [Module Boundaries] requires crates to stay compiler-enforced visibility boundaries; the entry's own recorded remedy of relocating the two `obs.rs` tests into their own test binary would widen `conductor-core`'s public API for tests alone and is therefore constrained. The same entry requires the standalone per-member sweep to run each member on its OWN targets (`--lib` for library crates, `--bins` for the two bin-only crates) and bans `--all-targets`, which re-unifies dev-dependencies; it also records the property as measured-at-a-chunk, not gate-enforced.
- **Occupied resources are closed for this chunk.** §Occupied Resources (Ports · Environment variables · Crate names) and §Cross-cutting Patterns — Trust boundary require that shipped binaries open no inbound listener, with the `:4317` port-occupier fault the sole deliberate bind, and that any new configuration handle live in the reserved `CONDUCTOR_*` namespace — matching the scope's own "no new capability surface" boundary. CARRY C work rides the existing `CONDUCTOR_NVDA` / `CONDUCTOR_MSEDGEDRIVER` / `CONDUCTOR_A11Y_STRICT` handles rather than adding one.

## Patterns to follow
- **The harness shells' existing `--e2e` build form** — both `scripts/agent-run.{sh,ps1}` already build `conductor-tauri` with `--features tauri/custom-protocol` after `ensure_frontend` (§Infrastructure Patterns — Build system); a release/bundle pass should reuse that shape rather than invent a second build invocation.
- **Gate-correctness LF discipline on the Windows host** — the sole `.gitattributes` rule (`coverage-matrix.md text eol=lf`) exists because the coverage-completeness gate byte-compares a `writeln!`-built render (§Infrastructure Patterns — Build system); any pass touching committed generated artifacts inherits it.
- **Handle-guard pattern for operator dev tools** — validate at the harness edge (existence + `isFile` + shell-metacharacter rejection), pass as a separate argv element of an array-form spawn, skip-at-exit-0 as the lax arm, non-zero under an affirmative `CONDUCTOR_A11Y_STRICT`, value never logged or committed (§Occupied Resources — Environment variables). CARRY C changes must sit inside this shape.
- **Reuse one schema assertion, never a second copy** — `runs/a11y/&lt;run_id&gt;.jsonl` is asserted by the same `journal_conformance` test the run journal uses, under a redirected `CONDUCTOR_RUNS_DIR` (§Occupied Resources — On-disk artifacts).
- **Run-artifact naming** — `run_id`-stemmed journals/reports that are never overwritten (the `runs/live-suite/{leg}.jsonl` leg-stemmed captures are the one registered exception), kebab-case Markdown filenames, filesystem-safe hyphen `run_id` stamps (§Conventions — Naming patterns; §Standard Contracts — Timestamp formats).

## Anti-patterns to avoid
- **No cloud / container / serverless packaging** — no Docker/Compose/Kubernetes artifact, no remote or containerized execution target (§Established Decisions [Deployment]; §Infrastructure Patterns — Deployment model).
- **Never treat a bare `cargo build --release` as producing a bundle-serving GUI binary** — the profile does not decide embedding, and §Occupied Resources — Ports records the `devUrl` fallback explicitly.
- **No `--all-targets` in the per-member standalone build check, and no public-API widening to host a test-only fix** (§Established Decisions [Module Boundaries]).

## Contract bindings
- **arch ↔ tests** — arch supplies the crate-boundary constraint on CARRY A's remedy and the zero-retry nextest `ci` profile / `cargo test --doc` gate shape (§Infrastructure Patterns — Build system); testing.md §Quality gates owns the shared-state-defect bar and the zero-flake rule the scope cites for CARRY C.
- **arch ↔ security** — `deny.toml` adjudication of the 16 `unmaintained` + 1 `unsound` allowed warnings, the accepted-license set (including the non-Tauri `BSD-2-Clause` via `blake3`→`arrayref`), and the CI-only Evergreen egress boundary widening are security-plan §Dependency Security's authority; arch only registers them (§Infrastructure Patterns — Build system; §Occupied Resources — Ports).
- **arch ↔ obs** — the SLO pass's self-observation stream lands at `logs/agent-latest.jsonl` and, for the `run --live` suite, the per-leg `runs/live-suite/{leg}.jsonl` freezes; arch registers the sites and their handle-following behaviour, obs-plan §3 owns schema + redaction (§Occupied Resources — On-disk artifacts).
- **arch ↔ a11y** — the SR/driven arms are operator-local and never CI, over ONE WebdriverIO + tauri-driver stack binding `4444`/`4445` for the harness lifetime; a11y-plan owns the announcement expectations CARRY C disputes (§Established Decisions [CI/CD]; §Occupied Resources — Ports; §Cross-cutting Patterns — Scope law).
- **arch ↔ report/tests fixtures** — the 11-field run-report envelope and 9-key `CheckRecord` are the shared shapes three surfaces depend on (JSONL journal · `run_check` table · Markdown report) and are byte-fixed (§Standard Contracts — Run report envelope).

## Acceptance criteria contributions
- (arch) The release build runs `cargo build --release` over the workspace with `Cargo.lock` committed and un-drifted, and both supply-chain runners exit 0 (`cargo deny check advisories bans licenses sources`; `cargo audit` with every allowed warning `deny.toml`-adjudicated), with any red audit first checked against the advisory-db clone's `git status --porcelain` (per architecture.md §Infrastructure Patterns — Build system).
- (arch) Any `conductor-tauri` artifact required to serve the embedded webview is built `--features tauri/custom-protocol` after `npm run build`; a bare `--release` build is not accepted as bundle-serving (per architecture.md §Infrastructure Patterns — Build system).
- (arch) The final SLO verification pass is driven through the headless `scripts/agent-run.{sh,ps1}` path and records journal-relative latency (`read_back_observed_at − journal_emitted_at`) into the byte-unchanged 11-field run-report envelope plus 9-key `CheckRecord` (per architecture.md §Standard Contracts — Run report envelope and §Established Decisions [Timing-Tolerance Model]).
- (arch) The chunk lands no new workspace crate, port, or `CONDUCTOR_*` handle, and no shipped binary opens an inbound listener beyond the `:4317` port-occupier fault (per architecture.md §Occupied Resources and §Cross-cutting Patterns — Trust boundary).
