# design extract

## Relevance
Partial — design applies to what the shipped Tauri bundle and release CLI binary must contain (tokens, fonts, motion override, artifact discipline, TTY/prompt gating); cargo-audit/deny, the version stamp, and CARRY A's panic-hook race are outside the domain.

## Constraints
- The 34-token `:root` contract is binding by NAME AND VALUE, including the `@media (prefers-color-scheme: light)` override block; a release/minified stylesheet must still emit all of them (per design-system §Surface: desktop-webview / Tokens — the block is declared on plain `:root`, never `@theme`, precisely because `@theme` tree-shakes 11 of the 34). Whether the release-mode Vite build already emits 34/34 is research's question.
- Fonts must be self-hosted WOFF2 vendored INTO the Tauri bundle — no Google Fonts / CDN at runtime (Minimal-tier offline hardening), with JetBrains Mono as the reserved status tier and IBM Plex Sans for prose (per design-system §Typography → Loading).
- Depth is borders-only and explicitly tied to the "~3 MB Tauri artifact + performance discipline": no drop shadows, no `backdrop-filter`, `box-shadow` permitted only as the focus ring (per design-system §Depth Strategy; §Anti-Patterns → Per-Surface Bans / desktop-webview).
- Motion at expression `0.3` requires ZERO animation library in the shipped bundle (CSS transitions only, no framer-motion/spring/parallax), and every transition must be dropped under `@media (prefers-reduced-motion: reduce)` (per design-system §Motion → Hard limits).
- The release-gate verification pass runs the headless `agent-run` path, which design-system §Surface: cli requires never be blocked on an interactive `inquire` prompt (isatty-gated; non-interactive policy records the decision instead) — a prompt there silently breaks the release gate (per §Surface: cli Component Pattern 2 + Platform-Specific Notes).
- CLI color is gated per stream by `std::io::IsTerminal` AND `NO_COLOR` unset AND `TERM != dumb`, so piped/agent-captured artifacts must carry no ANSI, with the closed ASCII prefix set (`[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`) always standing and no emoji in machine-parseable output (per design-system §Surface: cli Tokens + Per-Surface Bans / cli).
- The bundled webview must honor the Tauri guardrails design-system restates: Tauri ≥ 2.10.3, deny-by-default capabilities file, no remote-origin iframes, no `shell-open` with derived strings (per design-system §Surface: desktop-webview → Platform-Specific Notes).

## Patterns to follow
- The shipped `tokens.css` shape: dark defaults on `:root`, light variants inside a `@media (prefers-color-scheme: light)` block, plus the blanket reduce-motion rule — the exact structure the token contract is written against (design-system §Surface: desktop-webview / Tokens).
- Fontsource vendoring (`@fontsource/jetbrains-mono`, `@fontsource/ibm-plex-sans`) with the `"JetBrains Mono", ui-monospace, monospace` / `"IBM Plex Sans", ui-sans-serif, sans-serif` fallback stacks (design-system §Typography → Loading).
- CLI verification-pass output shape: ANSI-stripped when piped, `✓`/`✗`/`?`/`~`/`•` only on TTY, per-P-ID lines carrying P-ID · state · `slo_tier` (closed `&lt;5s`/`&lt;20s`/`&lt;90s` set) · `latency_ms`, with `comfy-table` width detected dynamically (design-system §Surface: cli Component Patterns 3–4).
- `indicatif` spinner STOPS in place (never hides, never animates-to-100%) at an operator-pause, TTY-gated so agent-captured artifacts stay clean — the SLO pass's captured output must not contain spinner churn (design-system §Surface: cli Component Pattern 1).
- For CARRY C's S3-04 subject: the operator-pause is a Radix/shadcn `AlertDialog` with `role="alertdialog"`, trapped focus, visible `--color-focus` ring and a 150ms `--motion-micro` fade — any remedy stays inside that primitive rather than substituting one (design-system §Component Patterns 2).

## Anti-patterns to avoid
- Shipping an animation library or any raw ms/curve literal in place of `var(--motion-micro)` / `var(--ease-quiet)`; and shipping CSS whose reduce-motion override was stripped (design-system §Motion → Hard limits).
- Shipping `backdrop-filter` or elevation `box-shadow` in the bundled stylesheet (design-system §Anti-Patterns → Per-Surface Bans / desktop-webview).
- Shipping Inter / Roboto / Arial / Helvetica / system-ui as a primary face, or any runtime CDN font fetch (design-system §Anti-Patterns → Universal Bans; §Typography Loading).

## Contract bindings
- Motion tokens ↔ a11y §Animation SC 2.3.3 — the reduce-motion override surviving into the SHIPPED bundle is the binding artifact, not just the source file.
- Token contrast ↔ a11y §Contrast SC 1.4.3 — the amended `--text-tertiary` / `--text-muted` values are the ones that must be present in the released stylesheet; a stale value re-fires the measured axe violation.
- CLI headless never-prompt ↔ testing/release-gate contract — `agent-run.{sh,ps1}` is both the design-mandated never-blocked path and this chunk's verification driver.
- CARRY C SR leg ↔ a11y announcement contract — design supplies only the mandate that status/lamp and dialog state changes are paired with text + `aria-live`; the SR row set, expected-announcement semantics and the variance verdict belong to a11y/tests.

## Acceptance criteria contributions
- The release-built webview stylesheet emits all 34 tokens by name, in both the dark `:root` block and the light `@media` block, after minification (per design-system §Surface: desktop-webview / Tokens).
- The produced bundle carries both WOFF2 faces locally and issues zero font network requests at runtime; no banned generic face is primary (per design-system §Typography → Loading; §Anti-Patterns Universal Bans).
- The shipped CSS retains the `@media (prefers-reduced-motion: reduce)` blanket override and contains no `backdrop-filter` and no elevation `box-shadow` (focus ring excepted); the bundle contains no animation library (per design-system §Motion → Hard limits; §Depth Strategy).
- The final verification pass runs headless with no interactive `inquire` prompt reached, and its captured artifacts are ANSI-free with the ASCII status prefixes intact (per design-system §Surface: cli Platform-Specific Notes + Component Pattern 2).
