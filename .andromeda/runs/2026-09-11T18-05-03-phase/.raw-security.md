- The sixth governed form's shape is the in-repo model for a PowerShell-side invocation inside `ci.yml`: `Start-Process -FilePath &lt;fixed program&gt; -ArgumentList '&lt;literal&gt;','&lt;literal&gt;' -Wait -PassThru` — array-form, no shell string, nothing operator-supplied in the vector (per security-plan.md §Security Anti-Patterns → Code Patterns rule (b)).
- The `a11y` job's existing handle precondition: print the handle NAME plus a boolean resolution result, never the resolved value, and exit non-zero on the CI arm where the dev host skips at exit 0 (per security-plan.md §Input Validation, `CONDUCTOR_MSEDGEDRIVER` row).
- The speech-log ingest grading pattern is the established model for turning untrusted host-derived text into a committed record: closed enum sets, a bounded text field, a mandatory host-path scrub to `&lt;host-path&gt;` with the row gaining a `security_finding`, raw log left under gitignored `runs/` (per security-plan.md §Input Validation, screen-reader speech-log ingest row). The module-version reading and the elevation capture are the same class of host-derived text.
- `&lt;redacted&gt;` rendering for a path-valued field inside a gate/evidence record, as the readiness gate renders `data_dir` (per security-plan.md §Security Anti-Patterns → Universal; §Input Validation, `ANDROMEDA_PULSE_*` declaration-only READ SET row).
- ADDED-arm-never-a-relaxation: `CONDUCTOR_A11Y_STRICT` inverts what an unresolved host-tool handle costs while leaving `nativeDriver()` / `nvdaExe()` and their `UNSAFE_PATH` checks byte-unchanged (per security-plan.md §Input Validation, `CONDUCTOR_A11Y_STRICT` row). Any strictness/verdict interaction the placement touches must follow that shape.

## Anti-patterns to avoid
- NEVER let a committed evidence record, `&lt;run_id&gt;.md`, `runs.db` row or JSONL journal carry an absolute host path or an internal seam-crate struct name — including via a probe's error text or a `FileName`-class field (per security-plan.md §Security Anti-Patterns → Logging).
- NEVER spawn a child through a shell / `eval`-equivalent, or interpolate any value into a command string, on any of the three spawn loci; an operator-supplied VALUE may appear only as a separate array-form argv element after metacharacter rejection, and never as the program except through the guarded host-tool form (per security-plan.md §Security Anti-Patterns → Code Patterns rule (b)).
- NEVER weaken an existing admitting control as collateral of a diagnostic placement — the Authenticode check, the ≥ 152 floor, the non-`continue-on-error` posture of the fetch/install steps, and the wdio-edge `isFile` + metacharacter guard all stand unchanged (per security-plan.md §Dependency Security, third dependency class; §Input Validation, `CONDUCTOR_MSEDGEDRIVER` row).
