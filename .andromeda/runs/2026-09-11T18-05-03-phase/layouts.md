## Constraints
- Any bracket-labeled line the split probe emits (including the `[probe] complete: N/N sections` marker) must mint **no new bracket label, lamp, `ReportState`, ANSI entry or token** — the per-P-ID lamp set stays closed at six and run-level signals ride OUTSIDE the lamp column as non-lamp qualifiers (per layout-templates.md §Surface: cli — Component — Primary content block 2). Whether the existing `[probe]` marker already conforms is research's question.
- Probe and error output must be **sanitized**: no absolute host paths, internal struct names or stack traces; human messages to stderr in the `error: <short>` + detail + `hint: <fix>` shape, stdout reserved for parseable artifact data (per layout-templates.md §Surface: cli — Component — Footer / terminator + error output). This is the layout-level rule the scope's `ModuleName`/`FileVersion`-never-`FileName` choice must satisfy.
- Grading of the elevated dev-host routine arm is by the **PRINTED verdict**, not the exit code — the `Spec Files:` failed count, the per-spec skip markers against the expected-skip set, and the `[webview2 … windows]` driven-session banner (per layout-templates.md §Surface: cli — Primary screens, the `scripts/agent-run.{sh,ps1}` bullet).
- Nothing added inside the isolation step or the probe step may introduce an interactive prompt: the agent-driven path is **never** gated on a prompt, and `inquire`-class prompts are `isatty`-gated (per layout-templates.md §Surface: cli — IA notes, Headless invariant).
- Every status signal must be **paired with an ASCII text prefix** so it survives `NO_COLOR` / piping / screen readers; ANSI auto-strips when piped and styling is decided per stream via `IsTerminal` (per layout-templates.md §Surface: cli — signature-placement preamble and §Component — Header / banner).
- Shell parity (`.sh` ↔ `.ps1`) is a property of the scripts **together with the invoking environment**, not of the scripts alone — directly load-bearing here because arm B changes only the invoking environment (elevation) with zero script delta (per layout-templates.md §Surface: cli — Primary screens, `agent-run.{sh,ps1}` bullet).
- If any measured literal (banner version, pass/skip counts, section totals) is carried into layout-templates prose at wrap, the plan's standing rule is **set-naming / de-literalization**, never a fresh pinned literal (per layout-templates.md §Surface: cli — Primary screens, `conductor coverage` "every number manifest-derived (never a literal)").

## Patterns to follow
- **`conductor preconditions` probe shape** (per layout-templates.md §Surface: cli — Primary screens): a non-mutating diagnostic that mints no `Verdict`, no `ReportState` and no per-P-ID row, fires no canary, and prints one host-path-free line per subject naming its statement and candidate causes — the closest existing precedent for arm A's relocated section.
- **Run-level non-lamp qualifier SET** (`[ENVIRONMENT-SUSPECT]` / `[PRECONDITION]`) per layout-templates.md §Surface: cli — Component — Primary content block 2: diagnostic captions ride outside the lamp column and are printed once per run with an always-rendered ASCII label.
- **`conductor cleanup` precedent** (per layout-templates.md §Surface: cli — Primary screens): a shipped mechanism that adds a plain confirmation line, mints no bracket label/lamp/token, and never prompts so the headless path stays unblocked.
- **`--e2e` / `--live` arm set** (per layout-templates.md §Surface: cli — Primary screens): refuse (exit 1, `[PRECONDITION]` lines, no leg fires) vs skip (exit 0 with a fetch recipe) vs the `CONDUCTOR_A11Y_STRICT` non-zero arm — the existing vocabulary for any new gate posture the probe placement touches.
- **Guard-shape-over-command-literal authoring** (per layout-templates.md §Surface: cli — Primary screens, `agent-run` bullet as amended 2026-09-01): name the stage's TARGET and GUARD SHAPE so a later harness edit cannot re-stale the doc.

## Anti-patterns to avoid
- Reusing ANY lamp-set token / bracket label for a diagnostic signal — a probe reading is REMIT/diagnostic, not an outcome, and reusing a lamp token reads as a verdict (per layout-templates.md §Component — Primary content block 1, the `not-conductors` Mode-cell ruling, and §cli Primary content block 2).
- Printing absolute host paths, internal struct names or stack traces in probe/error output (per layout-templates.md §Surface: cli — Component — Footer / terminator + error output).
- Adding any interactive gate on the headless/agent path — "an interactive gate there would silently break the release gate" (per layout-templates.md §Surface: cli — IA notes, Headless invariant).
