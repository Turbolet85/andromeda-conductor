## Constraints
- The delegated-timing budgets grade **at the harvest tier over Pulse's own tracing lines**, each read from its OWN exact allowlist leaf, and **never** through `budget_ms` / `effective_deadline_ms` — the contract's "which observable" element must name a Pulse leaf + field, not a Conductor-side measurement (per obs-plan.md §4 Known-residual classification path → Delegated-timing family).
- `latency_ms` = `read_back_observed_at − journal_emitted_at` is Conductor's **journal-relative span over the whole scenario emission window** — not an MCP round-trip and not a Pulse-internal duration (measured 18169/35120/30212 ms against sidecar tool calls of 0–22 ms). The hard-grade predicate may not bind the ≤2 s hue bound to it (per obs-plan.md §4 Delegated-timing family; §5 Metric Coverage; §10 Performance budgets).
- Leaf field names in this family are **not uniform** — `duration_ms` on `metric.constellation.hue_update_ms` / `.discovery_ms` / `metric.findings.counter_refresh_ms`, but `value` on `metric.report.render_ms`. Any observable the contract names must state its field literally rather than assume `duration_ms` (per obs-plan.md §4 Delegated-timing family).
- Pulse runs a **default-deny field allowlist** on its own lines: fields added after the allowlist arrive as `"<redacted>"` on the wire (the `triage.cue.tick` and `triage.incident.auto_resolve.tick` counters are the measured precedent). A contract that asks Pulse for a new field or attribute must also require that leaf's allowlist admit it, or the field is unreadable when it lands (per obs-plan.md §4 Restart-suppression + §4 Severity-lifecycle Required log fields).
- The delegated-timing family adds **no critical path of its own** and reaches KnownResidual by the existing Known-residual classification path; the fixed 7-path set is an input to the Minimal-tier justification, so this chunk must not mint an eighth path, a new span, or an envelope extra (per obs-plan.md §4 Delegated-timing family; §1 Obs Scope Summary critical-paths table).
- `slo_tier` is a **closed enum** (`<5s` | `<20s` | `<90s`) bounding Conductor's journal-relative span; a 2 000 ms Pulse-internal bound is not an `slo_tier` value and must not be mapped into one (per obs-plan.md §3 Log format JSON schema; §5 Metric Coverage; §10).
- The committed artifact must carry no absolute host paths and no internal struct names — SUT coordinates are cited repo-relative (per obs-plan.md §11 Logs; §11 PII Scrubbing).

## Patterns to follow
- **Harvest-tier grading** (`conductor-run/tests/delegated_timing_harvest.rs`): a delegated budget is asserted by reading Pulse's own tracing line from its exact leaf. The hard-grade predicate should be written to be assertable there directly; whether that file's current readers already parse the leaf/field the contract will name is research's question (per obs-plan.md §4 Delegated-timing family).
- **The shape-witness pattern** (§6 Boundary-call wrappers): Conductor's readers degrade to empty on an unrecognized shape rather than erroring, so the observed KEY SET is logged — names only, never values. A contract specifying "which fields" should be written so an absent field is distinguishable from an empty corpus, which is exactly the ambiguity this pattern exists to close (per obs-plan.md §6 Boundary-call wrappers).
- **The `message`-field escape hatch**: evidence with no allowlisted attribute rides the allowlisted `message` field, because `conductor-core::redact::ALLOWLISTED_FIELDS` drops any other field name at the processor stage. This is the standing carriage route if Conductor ever needs to record the contracted value on its own line (per obs-plan.md §6 Boundary-call wrappers; §4 Coverage-matrix completeness gate).
- **Mechanism-pin recording**: obs-plan.md §4 records P-025 as a MECHANISM PIN with no pass arm, SCOPED to this leaf at Pulse HEAD `83d4060`, with the SUT writer change (stamp `last_seen` from span arrival, or copy the activity floor's `last_observed_unix_nanos`) already named as Pulse intake rather than Conductor work — the contract restates that ask, it does not reopen the finding (per obs-plan.md §4 Delegated-timing family).

## Anti-patterns to avoid
- NEVER define a **soft SLO budget** with no enforcement — a formal SLO assertion must be an evaluable predicate at a stated assertion point, not prose (per obs-plan.md §11 SLO).
- NEVER add an OTel metrics backend, meter provider, or histogram instrument to satisfy the "resolution" element — Minimal tier has no metrics backend and an SDK re-introduces the banned background tasks (per obs-plan.md §11 Metrics; §11 Telemetry Strategy).
- NEVER widen the bounded span-name set or add a span/envelope field for this chunk — a name outside `ALLOWLISTED_FIELDS` emits nothing, and the envelope stays the eleven fields (per obs-plan.md §11 Spans / Traces; §6 Required fields).
