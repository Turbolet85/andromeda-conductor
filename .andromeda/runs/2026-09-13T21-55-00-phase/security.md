## Relevance
**Partial** — a spec-authoring chunk with no auth/crypto/network surface; security binds conditionally on the P4 form/location decision (whether the contract artifact gains a Conductor reader) and unconditionally on committed-artifact hygiene for the cross-project coordinates it cites.

## Constraints
- If the contract ships as a parseable manifest under `contracts/` with any Rust reader, security-plan.md §Input Validation ("Committed SUT-facing manifests read at a fixed path") requires it join that row's regime: serde deserialize plus an explicit `validate()`, resolution by every SHIPPED reader from a fixed `default_path()` through `resolve_under`, **deliberately no `CONDUCTOR_*` override handle** so the path is not operator-steerable, and absent/malformed as a hard harness fault — never defaulted, never silently widened. Whether this chunk adds a reader at all is research's question (the scope marks form/location `[inferred]`).
- The same §Input Validation row requires read faults carry `e.kind()` only, never the path (artifact hygiene); §Error Handling requires load faults stay a typed harness fault (`CoreError::Config` class), collapsing to `anyhow` only at the `conductor-cli` / `#[tauri::command]` edges.
- The committed artifact is an agent-parseable record shared across hosts: security-plan.md §Security Anti-Patterns → Logging requires committed artifacts and the per-chunk `evidence/` tree carry no absolute host paths and no internal seam-crate struct names. This chunk re-verifies coordinates against a SUT **working copy**, which is the live route by which an absolute checkout path can enter a committed file (§Input Validation's speech-log row records a real host path arriving that way, 2026-09-02).
- security-plan.md §Threat Model Summary § Attack surface enumerates Conductor's ingest channels exhaustively (CLI/env, on-disk config, MCP child stdout, loopback OTLP egress). A contract whose hard-grade predicate would require a NEW ingest channel — anything other than the sanctioned MCP tool surface or Conductor's own journal/read-back path — is a boundary widening owing a new §Input Validation row, which the amendment history treats as never-routine and escalate-class.
- security-plan.md §Security Anti-Patterns → Data Protection forbids Conductor production code directly opening, copying, or exfiltrating Pulse-owned state (`corpus.db` is plaintext SQLite; access is via the MCP TOOL SURFACE only, never the file). A contract that names direct file/DB access as the measurement route would prescribe the banned route.
- If a pointer lands in `scenarios/halo-hue-encoding.toml` as a new KEY rather than a comment, §Security Anti-Patterns → Input binds: no scenario deserialize without validation at load, garde `range`/`dive` (never `#[garde(skip)]` on a nested spec field), and any sibling-reading rule as a load-path `Scenario::check_*()` from `from_toml_str`, never `#[garde(custom)]`. Whether the pointer is a comment or a key is research's question.
- If any dependency lands (e.g. a parser for a new manifest shape), §Dependency Security + §Security Anti-Patterns → Universal require `cargo audit` and `cargo deny check advisories bans licenses sources` green over an un-drifted, committed `Cargo.lock`; the red-audit admission regime is recorded CLOSED as of 2026-09-05.

## Patterns to follow
- The three existing committed SUT-facing manifest loaders (`CapabilityManifest::load` / `LoadEnvelope::load` / `RunContract::load`) as the shape any new parsed contract should copy — fixed `default_path()` → `resolve_under`, explicit `validate()`, no override handle, `e.kind()`-only read faults (security-plan.md §Input Validation).
- Per-READER scoping rather than per-handle: a reader outside `conductor-core` (e.g. a test binary resolving from `CARGO_MANIFEST_DIR`) is RECORDED with its own resolution basis, not assumed to inherit the shipped one (§Input Validation, restated 2026-09-06).
- The `<host-path>` scrub + closed-set + bounded-length pattern from the speech-log ingest row as the hygiene model for any committed record carrying externally-sourced text (§Input Validation, screen-reader speech-log row).
- Module-internal `thiserror` typed enums collapsing to type-erased `anyhow` only at the CLI/IPC edges, with verification outcomes as typed `Ok(...)` VALUES and `Result::Err` reserved for harness faults (§Error Handling) — relevant if the hard-grade predicate becomes assertable code in `v3-08`.

## Anti-patterns to avoid
- Committing a contract artifact (or its evidence) containing an absolute host path — including the SUT working-copy path — or an internal seam-crate struct name (§Security Anti-Patterns → Logging).
- Specifying direct file or DB access to Pulse-owned state as the way the contracted observable is produced or verified; corpus access is MCP tool surface only, never the file (§Security Anti-Patterns → Data Protection).
- Introducing a `CONDUCTOR_*` override handle for the new artifact's path, or adding an unvalidated scenario-config key for the pointer (§Input Validation committed-manifests row; §Security Anti-Patterns → Input).

## Contract bindings
- **Committed-artifact host-path hygiene** binds to obs (artifact scrubbing of run-report/journal fields) and to tests (the gate-1 hygiene grep used for `evidence/` records — the same check applies to this contract file).
- **Contract form/location** binds to arch (whether a reader exists and where it lives) and to tests (a load/validate test pinning the never-defaulted rule) — security's duties attach only once arch answers "is there a reader".
- **Hard-grade predicate** binds to obs-plan §Delegated-timing family (which owns the unmeasurable finding); security's stake is only that the predicate be gradeable through already-sanctioned boundaries.

## Acceptance criteria contributions
- The committed contract artifact and any evidence it carries contain zero absolute host paths (drive-letter / `%APPDATA%` / `/Users` / `/home` tokens) and no internal seam-crate struct names — grep verifies (per security-plan.md §Security Anti-Patterns → Logging).
- IF the artifact ships parseable with a Rust reader: it resolves from a fixed `default_path()` through `resolve_under` with **no** `CONDUCTOR_*` override handle, an explicit `validate()` faults hard on absent/malformed rather than defaulting, and read faults render `e.kind()` only — grep/test verifies; whether a reader is added at all is research's question (per security-plan.md §Input Validation, committed SUT-facing manifests row).
- The contract specifies no measurement route requiring a new Conductor ingest channel or direct access to a Pulse-owned file/DB (per security-plan.md §Threat Model Summary § Attack surface; §Security Anti-Patterns → Data Protection).
- If any dependency or `Cargo.lock` delta lands: `cargo audit` exit 0 and `cargo deny check advisories bans licenses sources` exit 0 over the committed, un-drifted lock (per security-plan.md §Security Anti-Patterns → Universal).
