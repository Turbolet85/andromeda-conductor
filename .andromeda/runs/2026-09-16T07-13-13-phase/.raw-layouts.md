## Relevance
Partial — no desktop-webview surface is touched; layouts binds only if the check's registration surface is a `conductor` cli verb, an `agent-run` stage flag, or anything printing on a Conductor-owned stream.

## Constraints
- The cli **verb enumeration is layout-templates' own surface**: if the check registers as a `conductor &lt;verb&gt;`, the verb SET is whatever `Commands` (`crates/conductor-cli/src/cli.rs`) declares and must be enumerated in §Surface: cli — Primary screens, never baked as a sample elsewhere (per layout-templates §Surface: cli — Primary screens · §cli Component — Primary navigation). Whether the check needs a verb at all is the P4 registration fork the scope leaves open.
- Every status the check prints must pair its color with an **always-printed ASCII text prefix** so the signal survives `NO_COLOR` / piping / screen readers — this is stated as a requirement, not a preference (per layout-templates §Surface: cli — signature placement / status pairing).
- The per-P-ID **lamp/bracket set is closed at six**; a new run-level label may only exist as a non-lamp qualifier riding OUTSIDE the lamp column, on the `[ENVIRONMENT-SUSPECT]` / `[PRECONDITION]` precedent, and must not mint a seventh lamp, a sixth `ReportState`, or a new ANSI/token entry (per layout-templates §cli Component — Primary content block 2).
- **Headless invariant**: the check may never block on an interactive prompt — `inquire` prompts always isatty-gate first and the agent-driven source-of-truth path is never gated on a prompt, since an interactive gate there would silently break the release gate (per layout-templates §cli IA notes — Headless invariant). A CI-registered check is squarely in that path.
- **Pipe discipline + sanitized errors**: raw parseable data on stdout, human messages on stderr, ANSI auto-stripped when piped, no emoji in machine-parseable output; error output is `error: &lt;short&gt;` + detail + `hint: &lt;fix&gt;` with no absolute host paths, internal struct names, or stack traces (per layout-templates §cli IA notes — Pipe discipline · §cli Component — Footer / terminator + error output).
- **Output structure is a parsed contract**: adding a `comfy-table` column without a `--format` flag is a breaking change, and the two table shapes are fixed and must not be conflated — the 6-column results/SLO table (`run`/`suite`) and the 4-column coverage table (`coverage`) (per layout-templates §cli IA notes — Command model · §cli Component — Primary content block 1).
- If registration lands as an **`agent-run` stage flag** instead, the stage set (`--unit`/`--integration`/`--e2e`/`--live`, default = the full bundled gate) is enumerated on that bullet and a new stage must be a **sibling flag, never a sixth command**, with its refuse / skip / strict outcome class stated (per layout-templates §Surface: cli — Primary screens, `scripts/agent-run.{sh,ps1}` bullet).

## Patterns to follow
- **`conductor cleanup &lt;run_id&gt;`** — the minimal-surface verb precedent: plain confirmation line carrying a count, the id in the ID-cyan mapping, idempotent, never prompts, mints no bracket label / lamp / `ReportState` / token / ANSI entry (per layout-templates §cli Primary screens). The closest existing shape for a check that should add a verb without expanding the label vocabulary.
- **`conductor preconditions [--json]`** — the both-arms gate-caption shape: one `[PRECONDITION]` line per unmet subject naming its statement and candidate causes, PLUS a single satisfied line when none is unmet, so a reader keying on the bracket label cannot read it as failure-only; exits 0 iff every subject is satisfied (the documented go/no-go exception to the scenario-verdict rule) (per layout-templates §cli Primary screens · §cli Component — Primary content block 2). Directly analogous to this chunk's "establishes both outcomes, demonstrated able to fail as well as to pass".
- **`conductor preflight [--json]`** — the exit-rule + machine-readable companion shape: a `ReadyState` JSON payload or a `[PASS]`/`[BLOCKED]` line, exit 0 iff ready (per layout-templates §cli Primary screens). If the audit needs machine-readable output, `--json` on the verb is the established form, not a new stream or file.
- **Header / banner**: printed once per command (never an always-on banner), `CONDUCTOR` + verb + subject, bold ID-cyan title with dimmed metadata, all styling routed through `owo-colors` gated by per-stream `std::io::IsTerminal` (per layout-templates §cli Component — Header / banner).
- **Terminator line**: a single closing line naming the artifact destination in the dimmed mapping, path left un-colorized when piped (per layout-templates §cli Component — Footer / terminator + error output). Relevant if the check writes a ledger/report artifact in place of `tier-ledger.md`.

## Anti-patterns to avoid
- Do **not** mint a new per-P-ID bracket label, a seventh lamp, or a new ANSI/token entry for the audit's verdicts — reuse the closed set or ride outside the lamp column as a run-level qualifier (per layout-templates §cli Component — Primary content block 2).
- Do **not** add a column to the 6-column results/SLO table, nor render the audit as something conflatable with the 4-column coverage table (per layout-templates §cli Component — Primary content block 1 · §cli IA notes — Command model).
- Do **not** bake derived counts as literals in any surface copy or documented sample — `82 capabilities … (N unbacked)` is the placeholder form precisely because re-pinning a fresh literal re-stales (per layout-templates §cli Primary screens, `conductor coverage` roll-up). This chunk's facts are counts (36 scenarios · 2 live `[[expected]]`), the exact re-staling class.

## Contract bindings
- **layouts ↔ tests harness**: the `agent-run.{sh,ps1}` stage-flag enumeration and its refuse / skip / `CONDUCTOR_A11Y_STRICT` outcome classes are layouts-owned surface text that cites test-plan §3 for shell parity — parity is a property of the scripts together with the invoking environment, so any new stage registered here must carry its outcome class on both shells (per layout-templates §cli Primary screens, agent-run bullet).
- **layouts ↔ a11y / NO_COLOR**: layouts states the ASCII-prefix pairing and `NO_COLOR` / `TERM=dumb` honoring as the requirement; a11y derives the concrete conformance downstream (per layout-templates §Decisions Log — Notes).
- **layouts ↔ architecture**: layout-templates is the enumerating home for the cli verb set; architecture explicitly refuses that role, so a new verb's registration amendment lands here, not there (per layout-templates §cli Primary screens; established at amendment `2026-09-06-run-report-envelope-conformance-gate`).
- **layouts ↔ obs/verification**: if the check emits any per-P-ID row it would collide with the closed lamp set; the `preconditions` precedent requires a probe of this kind to mint no `Verdict`, no `ReportState` and no per-P-ID row (per layout-templates §cli Primary screens). Whether the three existing `v3-05` probes already print anything on a Conductor-owned stream is research's question.

## Acceptance criteria contributions
- (layouts) If the check ships as a `conductor` verb, it is present in the `Commands` set and enumerated in the cli Primary-screens verb list — no verb ships undocumented on that surface (per layout-templates §Surface: cli — Primary screens).
- (layouts) Both outcomes of the check read correctly with color stripped: every status pairs its tint with an always-printed ASCII prefix, and the satisfied arm prints its own line rather than being silence (per layout-templates §Surface: cli — signature placement / status pairing · §cli Primary screens `conductor preconditions` both-arms rule).
- (layouts) The check mints no new per-P-ID bracket label, no seventh lamp, no sixth `ReportState`, and no new ANSI or token entry; any run-level label it prints sits outside the lamp column (per layout-templates §cli Component — Primary content block 2).
- (layouts) The check never blocks on an interactive prompt, keeps parseable data on stdout with human messages sanitized and host-path-free on stderr (per layout-templates §cli IA notes — Headless invariant / Pipe discipline · §cli Component — Footer / terminator + error output).
