## Constraints
- The a11y/`--e2e` leg is a **stage flag on the harness**, never a sixth command, and its gating is a host-tool-handle concern — any new limited-token launch handle inherits that class rather than minting a new verb or command surface (per layout-templates §Surface: cli — Primary screens, `scripts/agent-run.{sh,ps1}` bullet).
- That bullet requires a **three-outcome arm set** for an unresolved host-tool handle: the LAX arm skips its own leg at exit 0 with a host-path-free `error:`/`hint:` precondition, and an affirmative `CONDUCTOR_A11Y_STRICT` (the CI posture) exits non-zero instead — CI adds a third outcome rather than replacing either (per layout-templates §Surface: cli — Primary screens, `scripts/agent-run.{sh,ps1}` bullet). Whether the shipped job already preserves both arms is research's question.
- The leg must assert the runner's **PRINTED verdict** — the `Spec Files:` failed count, the per-spec skip markers against the expected-skip set, and the `[webview2 … windows]` driven-session banner — because the exit code alone cannot distinguish a full pass from a total skip (per layout-templates §Surface: cli — Primary screens, `scripts/agent-run.{sh,ps1}` bullet). This is the layouts-side statement of this chunk's "honest terminal".
- The per-P-ID lamp set is **closed at six** and run-level qualifiers ride OUTSIDE the lamp column as ASCII-bracket-labelled lines with no new ANSI or token entry; a CI gate or a ratified exclusion must therefore mint no seventh lamp, no new bracket label and no new token (per layout-templates §Surface: cli — Component — Primary content block 2; the `not-conductors` Mode-cell precedent in §Primary content block 1).
- Error output goes to **stderr, sanitized** — no absolute host paths, no internal struct names, no stack traces — in `error: &lt;short&gt;` + detail + `hint: &lt;fix&gt;` form, never colorized when piped (per layout-templates §Surface: cli — Component — Footer / terminator + error output).
- The **headless invariant**: the agent-driven source-of-truth path is never gated on an interactive prompt — a limited-token launch mechanism must not introduce one (a `runas`-class credential prompt would silently break the release gate) (per layout-templates §Surface: cli — IA notes, Headless invariant).
- Status is never colour-alone: every state pairs its colour with an ASCII text prefix so it survives `NO_COLOR` / piping / a non-TTY CI log (per layout-templates §Surface: cli — Signature placement, text-prefix requirement; §IA notes Pipe discipline).

## Patterns to follow
- The **handle-absence ARM SET** already templated for `CONDUCTOR_MSEDGEDRIVER` / `CONDUCTOR_NVDA` (lax skip at exit 0 with a fetch recipe ↔ strict non-zero under `CONDUCTOR_A11Y_STRICT`) — the shape a new launch handle should reuse rather than invent (per layout-templates §Surface: cli — Primary screens).
- The `--live` **refuse-vs-skip two-class contrast**: one host-path-free `[PRECONDITION]` line per unsatisfied subject naming its statement and candidate causes, fired before any leg runs — the existing shape for recording a *measured* cause without a lamp (per layout-templates §Surface: cli — Primary screens, `--live`).
- The **run-level non-lamp qualifier** precedent (`[ENVIRONMENT-SUSPECT]`, `[PRECONDITION]`): printed once, outside the lamp column, label always rendered, omitted entirely when not applicable — the template for an outcome-(B) exclusion notice if one must surface on a cli/report surface (per layout-templates §Surface: cli — Component — Primary content block 2).
- **Set-naming over literals** when documenting stage flags, verbs or counts — name the target and guard shape, not a command literal or a derived number, so a later harness edit cannot re-stale it (per layout-templates §Surface: cli — Primary screens; the de-literalization rule applied throughout that section).
- The surface the e2e leg drives is a **single frameless window, no routes / no URLs / no breakpoints** — one surface in run states (`idle` · `live` · `hold` · `aborted`) — so the driven session targets one window with no navigation step (per layout-templates §Surface: desktop-webview — IA notes, Global model).

## Anti-patterns to avoid
- Do not mint a new bracket label, lamp state, `ReportState`, ANSI entry or design token for the CI gate or its exclusion — the lamp set stays closed at six (per layout-templates §Surface: cli — Component — Primary content block 2).
- Do not collapse the arm set into a single unconditional verdict (the "never a hard failure" / unconditional-skip wording this section already retired once) — each arm must stay separately reachable (per layout-templates §Surface: cli — Primary screens, `scripts/agent-run.{sh,ps1}` bullet).
- Do not emit absolute host paths, stack traces or colour-only signal in the gate's CI output, and never place an interactive prompt on the headless path (per layout-templates §Surface: cli — Component — Footer / error output; §IA notes Headless invariant).
