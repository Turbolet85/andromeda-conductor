- Arm-split invocation: routine = `agent-run run --e2e` (no live Pulse; seeds its own committed fixture through the production writer), driven = `npm run a11y:driven`, SR = `npm run a11y:sr*` with `CONDUCTOR_NVDA` unset ⇒ skip at exit 0 (per a11y-plan §9 artifacts E2E row).
- Host-tool-handle gating as the skip idiom (`CONDUCTOR_MSEDGEDRIVER` / `CONDUCTOR_NVDA` unset ⇒ skip at exit 0), paired with the strict-mode override in CI — a new launcher should extend this idiom rather than invent a second one (per a11y-plan §3 Bootstrap `a11y-ci-gate-wire` + §11 Anti-Patterns → CI).
- Identify CI jobs BY NAME (`a11y`, `runs-on: windows-2025`), never by `ci.yml` line coordinates, which move as the workflow grows (per a11y-plan §3 Configuration).
- Context-skip discipline: a routine-arm spec whose DOM state the seeded subject cannot produce context-skips and never passes green; the expected-skip SET is the asserted baseline (per a11y-plan §9 artifacts E2E row + §11 Anti-Patterns → CI).
