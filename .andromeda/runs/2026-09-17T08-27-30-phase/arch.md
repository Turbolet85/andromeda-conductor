## Patterns to follow
- **The gate IS the assertion, never a shell re-statement** — arch's static-gate pattern records that re-listing a gate's assertion in shell would be a second copy that drifts from the production source (per §Established Decisions [CI/CD]). The counting-basis correction therefore belongs in the e2e assertion, not in `Assert-A11yVerdict`'s reader.
- **Presence-guarded step shape** — every named CI gate opens with a presence guard on its subject that emits a `::error::` annotation and exits 1, so an absent subject fails loudly rather than passing vacuously (per §Established Decisions [CI/CD]). The same posture governs an assertion that must not silently stop asserting.
- **One shared basis so two surfaces cannot diverge** — the load-envelope gate/caption pair is arch's worked example (`phase_rate_exceeds` has exactly one caller by construction) (per §Occupied Resources — `contracts/pulse-load-envelope.toml`). Applies directly to a value producer (`tabCycleNames()`) feeding both sides of the expectation.
- **Strict arm as an ADDED arm, never a relaxation of the guard beneath it** (per §Occupied Resources — Environment variables `CONDUCTOR_A11Y_STRICT`).
- **Measured-and-scoped claim discipline** — arch records CI verdicts against a named run id with the configuration bounded, and retires a claim only on the measurement its own sentence names as precondition (per §Established Decisions [CI/CD]).

## Anti-patterns to avoid
- A gate that reports success by skipping — and by extension a "corrected" assertion that passes because it asserts nothing (per §Occupied Resources — Environment variables `CONDUCTOR_A11Y_STRICT` · §Established Decisions [CI/CD]).
- Widening the outbound surface (a new registry/CDN egress, a changed image label, a bypassed install floor) inside this chunk without the operator ruling the registration; boundary widening is stated as always a human's call (per §Occupied Resources — Ports · §Cross-cutting Patterns — Trust boundary).
- Growing the harness surface — a sixth `agent-run` command, or wiring a CI-only script into `agent-run.{sh,ps1}` (per §Infrastructure Patterns — Directory structure · §Stack and Technologies — Operator instruments row).
