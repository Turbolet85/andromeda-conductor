## Patterns to follow
- Handle-NAME-only precondition text: the CI arm's producer of `CONDUCTOR_MSEDGEDRIVER` gates on a printed handle-named `Test-Path` precondition emitting the handle name + a boolean, never the resolved path, and exits non-zero rather than skipping (per security-plan.md §Input Validation, `CONDUCTOR_MSEDGEDRIVER` row).
- Single-reader/single-guard discipline: `crates/conductor-tauri/ui/wdio.conf.ts` remains the sole READER and sole site applying the `isFile` + shell-metacharacter guard for the host-tool handle set; a CI-side arm validates upstream without becoming a second reader (per security-plan.md §Input Validation, `CONDUCTOR_MSEDGEDRIVER` row).
- Floor-conditional acquisition: a conditional guards the fetch while the floor assertion runs unconditionally and exits non-zero, so a silent no-op cannot pass (per security-plan.md §Dependency Security, third dependency class).
- Composed-form argv guard: where an API forces a command string instead of an array, the substitute control is per-element whitespace/metacharacter rejection before composition, surfaced as a named precondition at a fixed exit code (per security-plan.md §Security Anti-Patterns → Code Patterns rule (b), seventh form).
- Plain `run:` steps invoking a fixed toolchain binary with fixed argv are NOT counted among the governed spawn forms (per security-plan.md §Security Anti-Patterns → Code Patterns rule (b); precedent recorded in the amendment history for the fmt gate).

## Anti-patterns to avoid
- NEVER compose a child launch through a shell / `eval`-equivalent (`-Command`, `Invoke-Expression`, a shell string) or place an operator-supplied value in a spawn's program slot (per security-plan.md §Security Anti-Patterns → Code Patterns rule (b)).
- NEVER execute a job-time-fetched third-party binary without the pre-execution signature verification, and never add `continue-on-error` to the fetching or installing step (per security-plan.md §Dependency Security, third dependency class).
- NEVER let committed evidence records, run-report artifacts or CI-captured verdict text leak absolute host paths or internal seam-crate struct names (per security-plan.md §Security Anti-Patterns → Logging; §Error Handling, run-report artifact sanitization).
