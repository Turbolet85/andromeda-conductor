# design extract

## Relevance
**partial** — no webview surface is built here (tokens / typography / spacing / motion / iconography do not apply), but the chunk's grading rule fixes which `Verdict`/`ReportState` a real-model leg's outcome maps to, and any CLI/contract text it emits lands on the `cli` surface whose status vocabulary design-system owns.

## Constraints
- The grading rule may only assign values from the **closed** machine-verdict triad (`Pass` / `CalibrationRegion` / `Fail`) and the closed 5-valued `ReportState`; design-system §Color Palette (Verdict-vs-ReportState note) requires six visually distinct treatments precisely so no outcome silently reads as another — the rule must not invent a seventh state for "the model missed" (per design-system §Color Palette).
- Amber `Verdict::CalibrationRegion` is defined there as the **model-interpretive, report-for-human** verdict; a non-deterministic top-hypothesis outcome is the case that tier exists for, so routing a miss to `Fail` vs `CalibrationRegion` vs `ReportState::KnownResidual` is a design-bounded choice the posture must state explicitly, not leave implicit (per design-system §Color Palette).
- A leg that was **never measured** (quiet window unmet, model unavailable, precondition short-circuit) must render `Blocked` carrying the named precondition string — design-system bans collapsing "no result yet" into a red `Fail`, and requires `Blocked`'s measurement columns to render `—`/null rather than an error (per design-system §Anti-Patterns → Rejected Defaults, and §Surface: cli Component Patterns 3).
- Any CLI line the real-model arm emits must pair color with its ASCII bracket prefix from the closed set `[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`, colored only through the shipped ANSI map behind the per-stream `IsTerminal` + `NO_COLOR` + `TERM != dumb` gate — never color alone, never a new ANSI entry (per design-system §Surface: cli → Tokens).
- A **run-level qualifier** that is not a per-P-ID lamp state (e.g. "this leg ran under a real model / outside the canned envelope") must join the existing non-lamp caption set (`[ENVIRONMENT-SUSPECT]`, `[PRECONDITION]`) in the recessive ANSI 246 ↔ `var(--status-residual)` tier, printed outside the lamp column — never a seventh lamp nor a sixth `ReportState` (per design-system §Surface: cli → Tokens).
- The operator gate must be `isatty`-checked and the headless agent-driven path must **never** be blocked on an interactive prompt — the prompt is skipped per the configured non-interactive policy and the decision recorded to the artifact (per design-system §Surface: cli Component Patterns 2 + §Anti-Patterns → Per-Surface Bans: cli). Whether `agent-run.{sh,ps1}`'s existing `--live` path already satisfies this is research's question.
- Committed posture/contract prose in Markdown has **no color channel**; design-system's surface-adapted counterpart is emphasis or the bracket label in a blockquote, with the always-rendered text label carrying the signal (per design-system §Surface: cli → Tokens, Residual-mute entry).

## Patterns to follow
- §Surface: cli Component Patterns 4 — the per-P-ID verdict/report-state line shape (`✓`/`✗`/`?`/`~`/`•` glyph + bracket prefix + mono P-ID in ANSI 117 + `slo_tier` drawn from the declared closed `&lt;5s`/`&lt;20s`/`&lt;90s` set, never a baked literal + `latency_ms`). A real-model leg's result line should be an instance of this, not a new format.
- §Surface: cli Component Patterns 2 — the existing `inquire` operator-pause prompt (TTY-gated confirm, headless skip with the decision logged to the run report) as the precedent for "operator-invoked, never a CI gate".
- §Surface: cli Tokens — the non-lamp caption precedent set by `[ENVIRONMENT-SUSPECT]` (load envelope) and `[PRECONDITION]` (preconditions probe): a run-level condition gets a recessive-tier caption above the lamp lines, reusing shipped tokens.
- §Component Patterns 6 (Run-report view) — `KnownResidual` rows render the muted dashed lamp plus an "expected to fail until {named fix}" note; if the grading rule routes any pre-accepted real-model gap there, that note string is required, and it must stay consistent with `.andromeda/residuals.md`.
- §Brand Identity / §Signature — the CLI mirror of the paused-count hold-point requires the `indicatif` spinner to **stop in place** (not hide, not animate to 100%) at any operator hold; a serialized quiet window that touches live-run output inherits this.

## Anti-patterns to avoid
- Introducing a new color, ANSI code, or palette row for the real-model leg — the palette is closed; new surfaces reuse shipped tokens by name (per design-system §Anti-Patterns → Universal Bans, and the standing amendment precedent that a "new" label reuses an existing tier).
- Any alarm treatment on a graded miss — no flashing/pulsing/blinking, no emoji in machine-parseable piped output, `Fail` red held muted (per design-system §Anti-Patterns → Rejected Defaults + Per-Surface Bans: cli).
- Letting a miss, an unmeasured leg, or an unconfirmed manual item all present identically — design-system requires `Fail`, `Blocked`, `ManualCheck` and `KnownResidual` to stay visually and lexically distinct (per design-system §Color Palette, Verdict-vs-ReportState note).

## Contract bindings
- **Verdict/ReportState vocabulary ↔ architecture's run-report envelope** — §Color Palette states the report row carries BOTH "per arch's run-report envelope"; whatever state the grading rule names must be representable there. Arch/data domain owns the envelope shape; design owns the closed value set.
- **Color + ASCII prefix ↔ a11y not-color-alone (SC 1.4.1)** and the NO_COLOR / piped-output rule (§Surface: cli Platform-Specific Notes) — the same pairing satisfies both.
- **Operator gate ↔ tests/harness domain** (`scripts/agent-run.{sh,ps1}`) — §Surface: cli Platform-Specific Notes states the headless source-of-truth path must never be gated on a prompt, which design-system flags as also a security-plan rule; the posture statement and the harness must not disagree.
- **`KnownResidual` note ↔ `.andromeda/residuals.md`** — the "expected until {named fix}" string required by §Component Patterns 6 is the same claim the residuals pin carries.

## Acceptance criteria contributions
- Every verdict/report-state the posture and grading rule name is drawn from the closed `Verdict` (3) / `ReportState` (5) sets, with no new or seventh state introduced (per design-system §Color Palette).
- A leg that is not measured (quiet window unmet / precondition unsatisfied) grades `Blocked` with its named precondition string and null measurement columns, never a red `Fail`; a graded miss states its mapped state explicitly (per design-system §Anti-Patterns → Rejected Defaults).
- Any CLI output added for the real-model arm carries its closed-set ASCII bracket prefix and uses only the shipped ANSI map behind the per-stream TTY/`NO_COLOR`/`TERM` gate — zero new colors, never color-alone (per design-system §Surface: cli → Tokens).
- The operator gate is `isatty`-checked and the headless path completes without blocking on a prompt, with the decision recorded to the artifact (per design-system §Surface: cli Component Patterns 2).
