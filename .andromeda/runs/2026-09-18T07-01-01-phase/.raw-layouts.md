## Constraints
- A real-model arm on the harness must be a **sibling stage flag, never a sixth command**, and must stay **reachable from no default or CI path**; its exit rule must be stated where the flag is registered (per layout-templates §Surface: cli — Primary screens, the `scripts/agent-run.{sh,ps1}` entry, which registers the `--unit`/`--integration`/`--e2e`/`--live` set with default = the full bundled gate). The chunk's own scope names the operator gate and "never a CI gate" as posture properties — whether the code already shapes the invocation path that way is research's question.
- The **refuse-vs-skip two-class contrast must hold**: an unmet live-Pulse precondition REFUSES the suite at exit 1 with one host-path-free `[PRECONDITION]` line per unsatisfied subject and fires no leg, while an absent HOST-TOOL handle SKIPS its own leg at exit 0 with a fetch recipe — the LAX arm, which an affirmative `CONDUCTOR_A11Y_STRICT` turns non-zero as a **third** outcome rather than replacing either (per §Surface: cli — Primary screens, `agent-run.{sh,ps1}` entry). A real-model arm's quiet-window / posture refusal must land in one of these classes, not a fourth.
- The **per-P-ID lamp/bracket set is closed at six** (`[PASS]`/`[HOLD]`/`[FAIL]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`); a run-level qualifier rides **outside** the lamp column and is neither a seventh lamp nor a sixth `ReportState` (per §Surface: cli — Component — Primary content block 2, and the `not-conductors` Mode-cell precedent in §Primary content block 1). The grading rule's miss outcome must map into the existing `Verdict`/`ReportState` set or ride outside the column — no new bracket label, ANSI entry or token.
- **Every status is paired with an ASCII text prefix** so the signal is never colour-alone and survives `NO_COLOR` / piping / screen readers, and raw artifact data stays on stdout while human messages route to stderr (per §Surface: cli signature-placement pairing requirement + §cli IA notes — Pipe discipline).
- **Headless invariant**: interactive `inquire` prompts always check `isatty` first and the agent-driven source-of-truth path is **never** gated on a prompt — an interactive gate there would silently break the release gate (per §cli IA notes — Headless invariant; §Component — Hero / signature output, CLI mirror). "Operator-gated" must be expressed as flag reachability, not as a prompt in the default path.
- **Error output is sanitized**: `error: &lt;short&gt;` + contextual detail + `hint: &lt;fix&gt;` on stderr, no absolute host paths / internal struct names / stack traces (per §cli Component — Footer / terminator + error output). Any refusal a real-model arm prints inherits this shape.
- **Output structure is a parsed contract**: verb-noun flat, and adding a `comfy-table` column without a `--format` flag is a breaking change (per §cli IA notes — Command model). The 6-column results/SLO table and the 4-column coverage table are distinct shapes that must not be conflated (per §cli Component — Primary content block 1).

## Patterns to follow
- **The `--live` registration shape** (§cli Primary screens, `agent-run.{sh,ps1}` bullet): an operator-gated arm is documented as flag + exit rule + which probe leads it + what it refuses vs skips. A real-model arm added beside `--live` should follow the same anatomy rather than inventing a new documentation form.
- **The leading non-priming `conductor preconditions` probe** (§cli Primary screens, `conductor preconditions [--json]`): fires no canary, mints no `Verdict`/`ReportState`/per-P-ID row, exits 0 iff every subject satisfied, and prints **both** caption arms — one line per unmet subject with candidate causes, or the single satisfied line. This is the precedent for any additional pre-leg gate the posture requires (e.g. a quiet-window subject).
- **The run-level non-lamp qualifier** (`[ENVIRONMENT-SUSPECT]`, §cli Output structure `conductor run` + §cli Primary content block 2): printed once per run, above the verdict lines it qualifies, reusing ANSI 246 with no new entry, ASCII bracket always printed, **omitted entirely** when not applicable, adapted across cli / Markdown / webview and never forked. If the real-model posture surfaces a run-level statement, this is its template.
- **The per-check detail region** in `runs/&lt;run_id&gt;.md` (§cli Component — Primary content block 2): one indented plain-text line per expected check under its P-ID verdict line — no new column, no new bracket label, no new ANSI/token. The precedent for recording grading detail in the artifact without touching stdout or the tables.
- **Name the SET / target / guard shape, never a literal**: the doc's standing de-literalization discipline (`&lt;slo_tier&gt;`, `(N unbacked)`, "whichever `Commands` declares"). Posture numbers (quiet-window seconds, budget arithmetic) stated for layout purposes should name their source rather than bake a value that re-stales.

## Anti-patterns to avoid
- **Do not mint a seventh lamp, a new bracket label, a new ANSI code or a new token** for a real-model grading outcome — the lamp set is closed at six and run-level facts ride outside the lamp column (§cli Component — Primary content block 2; §desktop Primary content block 1, `not-conductors` precedent).
- **Do not add a column to either `comfy-table` shape** (6-column results/SLO, 4-column coverage) and do not conflate them; a column added without a `--format` flag is a breaking change for downstream agent parsers (§cli Component — Primary content block 1; §cli IA notes — Command model).
- **Do not introduce an interactive prompt, or any CI-reachable path, for the operator-gated leg** — the headless source-of-truth path must never block on a prompt, and the operator-gated arm must be unreachable from default/CI (§cli IA notes — Headless invariant; §cli Primary screens, `--live`).
