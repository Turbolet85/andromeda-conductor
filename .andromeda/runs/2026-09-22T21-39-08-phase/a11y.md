## Patterns to follow
- **Skip ≠ pass, enforced by the shell** (per a11y-plan §11 CI; §3 Bootstrap phases → a11y-ci-gate-wire / screen-reader-test-spec-setup). An unset host-tool handle skips at exit 0, strict mode turns that into a non-zero exit, and the shell checks the printed verdict against an expected-skip SET. This is the existing model for stopping a leg whose subject never formed (a degraded report with no `## Hypotheses`) from reading as green.
- **Specs with no subject skip visibly, and subjects come through the production writer** (per a11y-plan §9 E2E row; §4 load-envelope banner row). This is the a11y arms' version of the scope's "through the emission path, never a staged corpus row".
- **Substitute-gate statement for an operator-only claim** (per a11y-plan §11 Strategy, OWNER clause). It names the owner, gives the reason CI cannot run the claim, and lists the CI gates that run instead as non-substitutes. The posture's "Operator-invoked, never a CI gate" clause already follows this form when it names the routine a11y arm.
- **Text-paired cli status** (per a11y-plan §1 `conductor-cli` entity; §11 Universal). Any new terminal line reporting the leg's grade carries an ASCII status word, never colour alone.

## Anti-patterns to avoid
- **An a11y arm that passes by skipping or by retrying.** No shell edit may let an unresolved handle, a missing subject or a changed expected-skip SET exit 0 as a pass. No retry wrapper added for the real-model leg may reach the a11y arms (per a11y-plan §11 CI; §11 SLO; §10 Always-required SLO invariant).
- **A seventh lamp state, a new state colour, or state shown by colour alone.** The six-label set is closed, and the posture mints no verdict word, report-state or colour (per a11y-plan §11 Visual; §6 State color tokens).
- **Claiming a11y coverage or WCAG conformance from the headless drive.** Its a11y disposition is §1's not-assertable exclusion, never a pass (per a11y-plan §11 Universal; §11 Strategy).
