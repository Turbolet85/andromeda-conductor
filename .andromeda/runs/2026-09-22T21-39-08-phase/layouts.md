## Patterns to follow
- **Name the set or mechanism, never a literal.** The plan's samples use `<slo_tier>`, `(N unbacked)` and "the verb set `Commands` declares" (layout-templates §cli Primary screens; §cli Component — Primary navigation). An amendment that registers the real-model reach path should name its target and guard shape. The confirmed ~110 s formation figure is a measurement record, not a layout literal.
- **Extra per-P-ID text goes on an indented line under the verdict line.** This is where the plan puts the Blocked precondition, the KnownResidual note and the per-check detail, without a new column or label (layout-templates §cli Component — Primary content block 2).
- **Refuse and skip messages.** Unmet live-Pulse subjects print `[PRECONDITION]` lines. Handle absence prints `error:` and `hint:` on stderr, with no host paths. stdout is kept for artifact data (layout-templates §cli Primary screens agent-run bullet; §cli Component — Footer / terminator + error output).
- **Run-level qualifiers sit outside the lamp column and adapt per surface.** The load-envelope caption or banner prints once per run, above the verdict lines, and is omitted when the run is in-envelope or pinned exempt (layout-templates §cli Output structure — `conductor run`; §desktop-webview Component — Primary content block 2).

## Anti-patterns to avoid
- A sixth harness command, or any route to the real-model leg from the default stage, the bundled gate or CI (layout-templates §cli Primary screens, agent-run bullet).
- A seventh lamp, a sixth ReportState, a new bracket label (for example a hypothesis or interpretation label) or a seventh results-table column to carry the grade (layout-templates §cli Component — Primary content block 1 and 2; §cli IA notes).
- Pinning a derived value as a literal, such as the `(N unbacked)` count, a tier or the formation figure, in this doc or in TypeScript (layout-templates §cli Primary screens, `conductor coverage [--write]`).
