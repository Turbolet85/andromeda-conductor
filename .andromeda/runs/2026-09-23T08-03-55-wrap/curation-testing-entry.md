- 2026-09-23: **A capture test that prints under `cargo test -q … -- --nocapture` must buffer its output and write it ONCE** — libtest's `-q` progress marks (an `i` for each ignored test in the same binary) land on the same stdout the test prints to, so an unbuffered first line arrives prefixed with the mark and can split a line a downstream grammar parses; collect into a buffer and flush it from a drop guard, leading with a newline.
