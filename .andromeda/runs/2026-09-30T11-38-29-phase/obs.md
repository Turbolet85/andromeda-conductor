## Anti-patterns to avoid
- NEVER add an OTel SDK, a browser OTLP exporter or network export as a diagnostic aid for the focus-event investigation. Self-obs stays stderr, file or console JSON on every surface, including the webview (per obs-plan §11 Universal "NEVER export any self-observation OTLP"; §11 Telemetry Strategy).
- NEVER leak absolute host paths into committed evidence, logs or reports, including paths spoken by NVDA or captured from runtime or driver version probes (per obs-plan §11 Logs "NEVER leak absolute host paths"; §11 PII Scrubbing).
- NEVER add retry-once masking. A silent row regraded on a second attempt without a named cause is the retry pattern §11 bans in spirit (per obs-plan §11 SLO "NEVER add retry-once policies … masks real failures", which parallels tests' zero-flakiness).
