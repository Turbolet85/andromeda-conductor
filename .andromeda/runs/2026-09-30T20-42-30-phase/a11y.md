## Constraints
- **Minimal tier, WCAG baseline.** The tier is Minimal. The baseline is SC 2.1.1 / 1.4.3 / 2.4.3. The token- and pattern-bound SCs are added on top (1.4.11, 1.4.1, 2.3.3, 4.1.2, 4.1.3, 2.1.2, 1.3.1, 2.4.7, 3.3.2). SC 2.3.3 is included only as a design-token binding and does not escalate the tier. The axe scope is `wcag2a`/`wcag2aa`/`wcag21aa` with no `wcag22aa` (per a11y-plan §1 A11y Scope Summary; §3 WCAG criteria mapping; §3 A11y testing tool pick).
- **Fail-fast gate with a fixed skip set.** The routine arm is a fail-fast CI gate. Under `CONDUCTOR_A11Y_STRICT`:
  - An unresolved handle must exit non-zero instead of skipping.
  - Both harness shells must assert the runner's PRINTED verdict: the `Spec Files:` failed count, the per-spec skip tally against the expected-skip SET, and the driven-session banner.
  - The expected-skip SET is held at exactly two. A third skip, or a skipped-green run, fails the gate.
  - A "green under both runners" claim for the a11y job therefore has to read the printed verdict and the skip set, not only the exit code.

  (per a11y-plan §11 CI; §11 Strategy)
- **Moved surfaces keep their routine-arm assertions.** The plan requires each of these as TARGET state:
  - Exactly one `main` and one `contentinfo`. The `contentinfo` footer is not focusable and is not a live region. The phase line is the single level-1 heading (per a11y-plan §4 Per-surface landmark roles inventory).
  - Each coverage row is named by its OWN four cells through `aria-labelledby` (P-ID · Capability · Mode · Status), never by a composed `aria-label` (per a11y-plan §4 Per-component pattern catalog, Coverage matrix).
  - The SC 2.4.7 ring, idle-with-report row navigation and the key-map declaration specs all ride the routine arm (per a11y-plan §9 Per-pipeline-stage a11y artifacts; §5 Focus order per layout).
  - Whether those specs are green at HEAD under both runners is research's question.
- **Claim-ownership checker.** `npm run a11y:ownership` must stay green. The enumeration reads 11 claims · 9 owned · 2 n/a · 0 gaps. Every carve-out row whose owner CI does not run must carry an `inPlace` text. Any C2 knip disposition that touches `test/a11y/**` must not remove a symbol that this checker, or an owner spec it names, depends on (per a11y-plan §11 Strategy).
- **SR verdicts are bound and supplemental.** A screen-reader verdict is bound to its CONFIGURATION and INPUT PATH. It is stated with the full tuple: runtime × driver × NVDA × Windows build × input path. Each row records its arm and its input path (`os` · `webdriver` · `mixed` · `none`). A row the agent arm cannot reach is a recorded finding, never a pass. The SR pass stays supplemental and is never the sole verification (per a11y-plan §3 Screen reader test pattern).
- **What E0-10 is graded against (C5).** The load-envelope banner is:
  - a non-interactive `<p>` with no lamp role;
  - carrying its `label`, always rendered, plus an optional `cause`;
  - tinted `--status-residual`, a tint that is never the sole signal;
  - omitted entirely when the run stayed in-envelope.

  So E0-10's expected content is the banner's TEXT label, not a colour (per a11y-plan §4 Per-component pattern catalog, Run-level load-envelope banner; §1 A11y triggers, non-lamp reuse; §6 State color tokens).

  The routine arm produces the banner's state by seeding an over-envelope `run_envelope` row through the production writer. Two questions are research's to measure:
  - whether `runs/e2e-fixture`, which sr-empty reads, carries that row;
  - whether the banner therefore legitimately renders in the sr-empty subject.
- **Zero violations, no retries.** The target is zero WCAG AA violations on the four must-be-accessible paths. There is no retry-once, no soft SLO, and no mocha or nextest `retries` (per a11y-plan §10 Always-required SLO invariant; §11 SLO).

## Patterns to follow
- **Readiness wait before axe.** Before every `analyze()`, wait until the readiness probe answers `true` in under `RESPONSIVE_MS = 250` ms, with a 30 s bound and a 250 ms interval. Then analyze ONCE. The standing 1.5 s stall arm must fail whenever the wait stops covering it (per a11y-plan §9 Pipeline integration, Readiness before every axe analysis).
- **The SR harness shape.** It uses:
  - NVDA's own speech log;
  - Tab, Shift+Tab and the browse keys sent on the OS path through `send-keys.ps1` (a closed key set; this chunk does not change it);
  - browse rows walked FORWARD from a start position before their node;
  - T-01 driven as a second, un-stopped run after a 170 s quiet window;
  - NVDA's log clock calibrated per session.

  `operator_review` is transcribed into `evidence/nvda-pass.json` (per a11y-plan §3 Screen reader test pattern; §3 Pass spec format).
- **One stack, per-arm ownership.** There is one webview-automation stack (`@crabnebula/tauri-driver` + WebdriverIO, with axe via `@axe-core/webdriverio`).
  - The routine arm runs as `agent-run.ps1 run --e2e`, invoked directly through `scripts/a11y-token-witness.ps1` at native High integrity.
  - The `driven` and `sr*` arms stay operator-local.

  (per a11y-plan §3 CI integration; §9 Pipeline integration)
- **Stating a CI green.** A CI green is stated with its configuration: image, driver/runtime pair and integrity level. It is never a bare verdict, because the next image bump can move any of those terms (per a11y-plan §11 Strategy; §9 Platform).
- **Two-part contrast and not-color-alone coverage.** axe `color-contrast` checks the rendered DOM. The colorjs.io token-name pairs are checked in both declared themes, including the two `--status-residual` 4.5:1 rows. The not-color-alone assertion is keyed on the LAMP display labels, never on the token-tinted Mode cell (per a11y-plan §6 Color contrast pairs; §1 A11y triggers).

## Anti-patterns to avoid
- **Hiding the readiness race.** Never answer `Page/Frame is not ready` with any of:
  - a retry of `analyze()`, a `sleep` or a skip;
  - `continue-on-error`, or mocha/nextest `retries`;
  - a vendored patch of `FRAME_LOAD_TIMEOUT`.

  Never schedule a witness stall by timer (per a11y-plan §11 CI).
- **Letting a regression hide.** Never accept a skipped-green run as a pass. Never use partial axe configuration (a `runOnly` that excludes `color-contrast`) without a Decisions Log entry. Never let a11y artifacts leak absolute host paths or internal seam-crate struct names (per a11y-plan §11 CI; §11 Strategy; §11 SLO).
- **Breaking the moved landmarks and names.** Never set `role="presentation"` or `aria-hidden` on the `main`/`contentinfo` landmarks or on the live-region nodes. Never replace the cell-derived row name with a composed or redundant `aria-label` (per a11y-plan §11 ARIA; §11 Screen Reader).
