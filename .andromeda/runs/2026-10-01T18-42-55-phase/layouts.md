## Constraints
- `--live real-model` is a SELECTOR of `--live`. layout-templates §Surface: cli → §Primary screens (commands) (the `scripts/agent-run.{sh,ps1}` bullet) says it is neither a sixth command nor a new stage flag. It must lead with `conductor preconditions --for real-model-interpretation`, and when a subject is unmet it must REFUSE at exit 1 with one host-path-free `[PRECONDITION]` line per subject. An unknown selector prints `usage: <script> run --live [real-model]` and exits 2 before any probe. The series drives through this path as specified and does not wrap or re-shape it.
- `conductor preconditions --for` takes a scenario NAME. The same section (the `conductor preconditions` bullet) requires it to refuse a `P-NNN`-shaped value at argument parsing (exit 2). Under the `real-model` posture it grades the L4 handle by ABSENCE: the flag is unmet when either side's truthiness rule declares it. Exit 0 is reachable, and `[PRECONDITION]` has two arms. Read the satisfied line (`[PRECONDITION] every live-Pulse precondition is satisfied`) as a pass. Never read it as a failure. This matters when the attempt ledger records each drive's pre-gate.
- The lamp / ReportState set is CLOSED at six. layout-templates §cli → §Component — Primary content block 2 (verdict / report-state lines) requires that the series verdict test and the optional `Identified` ref test mint no new bracket label, lamp, ANSI entry or token. A graded `NotIdentified` or a dismissed drive is recorded in the ledger and the harvest, never rendered as a new cli or report state.
- layout-templates §cli → §Component — Primary content block 2 (the "Per-check detail region (`runs/<run_id>.md`)" paragraph) leaves the per-check detail region of `runs/<run_id>.md` and the 6-column results/SLO table unchanged. The report gains no column and no label. Whether Pulse's surfacing fix (`a2addb3`) moves anything the report renders is research's question, not a layout change.
- The headless path never blocks on a prompt. layout-templates §cli → §IA notes (Headless invariant) and §Component — Hero / signature output require `inquire` to be isatty-gated. On the agent-driven `agent-run.sh` path an operator-pause is skipped by the non-interactive policy, and the decision is recorded in the artifact. The operator's slots (model runs, `:4317`, the Pulse build) are scheduling stops in implement, never in-run interactive prompts.
- Pipe discipline. layout-templates §cli → §Component — Footer / terminator + error output and §IA notes (Pipe discipline) require raw artifact data on stdout and human messages on stderr, with errors as `error:` + `hint:` and no absolute host paths. ANSI is stripped when piped. Any drive output quoted into `evidence/attempt-ledger.md` must be the stripped, host-path-free rendering.

## Patterns to follow
- A run-level qualifier rides OUTSIDE the lamp column (layout-templates §cli → §Component — Primary content block 2, the non-lamp qualifier SET: `[ENVIRONMENT-SUSPECT]` · `[PRECONDITION]`). If a drive's report carries one, the ledger records it as a run-level qualifier, not as a per-check state.
- The cli terminator is `run report → runs/<run_id>.md` (layout-templates §cli → §Component — Footer / terminator + error output). It is the stable, parseable pointer a drive's ledger row can cite for that drive's report artifact.
- Two outcomes stay distinct (layout-templates §cli → §Primary screens, the `agent-run` bullet). An incomplete live-Pulse environment is a refusal (exit 1). A missing host-tool handle is a skip (exit 0). Neither is a graded drive. Record a refused pre-gate as "no drive fired", never as a drive outcome.

## Anti-patterns to avoid
- Do not read a `[PRECONDITION]` line as failure-only (layout-templates §cli → §Primary screens, the `conductor preconditions` bullet: "a reader keying on the bracket label must not read it as failure-only").
- Do not add a `comfy-table` column, verb or bracket label to carry series or verdict data (layout-templates §cli → §IA notes, Command model: "adding a `comfy-table` column without a `--format` flag would be a breaking change"). The series verdict belongs in the harvest test and the attempt ledger only.
