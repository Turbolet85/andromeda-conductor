## Anti-patterns to avoid
- Never run the live-Pulse leg as a CI gate, and never reach it from a default path — test-plan §11 Test Anti-Patterns (CI). The chunk plans no drive; a proof that only a live drive can give is not converted into a default-suite claim.
- Never fake Pulse's reaction as a CI verdict — test-plan §11 Test Anti-Patterns (Test Strategy). A test over recorded log shapes proves the capture's own reading of those lines, never that Pulse surfaced a digest; it claims no capability and re-grades no drive.
- Never copy capture text into test source or into a fixture elsewhere — test-plan §7 Test Data & Fixtures (Self-bootstrapping requirement) and the source arm of test-plan §6 Scenario: Fingerprint-storm (Real-model interpretation leg).
