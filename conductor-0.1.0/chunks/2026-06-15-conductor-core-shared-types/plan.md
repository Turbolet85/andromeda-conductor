## Goal
Fill `conductor-core` — today a bare `//!` placeholder (per `api-surface.md`: "no public items yet … land in the next chunk") — with the foundational type vocabulary every seam crate matches on. Three things land: the **`Verdict`** triad (`Pass`/`Fail`/`CalibrationRegion`) and the **`ReportState`** quintet (`Pass`/`Fail`/`ManualCheck`/`KnownResidual`/`Blocked`) as serde-serializable value enums; the **verdict/error wall** as a compile-enforced shape (a `conductor-core` `thiserror` error type for harness faults, with `Verdict`/`ReportState` deliberately NOT among its variants); and the **core `Scenario` identity skeleton** (`name`, a required `p_ids`, `seed`, `SloTier`). This is pure runtime-agnostic data — no tokio/async/I/O — per arch §Design Philosophy "Outcomes are values, errors are harness faults" + §Standard Contracts.

The serialized names are fixed by the run-report envelope (arch §Standard Contracts: `"verdict": "Pass"`, `"state": "Pass"`) and the obs JSONL schema (obs-plan §6). Research established that `Verdict`/`ReportState` variant names are **already** canonical PascalCase, so serde's default variant serialization is correct with **no `rename_all`**; only `SloTier`'s wire forms (`<5s`/`<20s`/`<90s`) are non-identifiers and need per-variant `#[serde(rename)]`. Beyond the wire contract, every state carries the CLAUDE.md "status is never color-alone" obligation as a **type property**: `label()` (human text) + `status_prefix()` (cli ASCII `[PASS]`/`[FAIL]`/`[HOLD]`/`[BLOCKED]`/`[MANUAL]`/`[RESIDUAL]`) accessors, so no call site can render a status by color alone (per design-system §Component Patterns #4 + a11y-plan §2 + layout-templates §CLI).

Scope is deliberately narrow at both edges. **No garde** — `#[derive(Validate)]`, range rules, the p50≤p95≤p99 / severity-mix cross-field invariants, and `CONDUCTOR_*` path canonicalization are the NEXT Foundation chunk ("Config-validation surface"); here the structs derive serde only and the `PId` newtype carries no format check yet. **No per-phase emission body** — the declarative timeline-phase spec is Epoch 2 ("Scenario-config model"); this chunk owns scenario *identity*, not its emission detail. **No run-report envelope struct / `runs.db` rows** — Epoch 6 embeds these enums; here we define only the enums it will embed.
