## Implementation Steps
1. **Confirm audit tooling is available + capture versions.** `cargo audit --version` and `cargo deny
   --version` (both already on PATH per `research.md`). Record the `cargo-deny` version — it selects the
   `deny.toml` schema shape (0.18+ uses the v2 `[advisories]`/`[bans]` field layout; no `vulnerability`/
   `unmaintained` severity keys).
2. **Author `deny.toml`** at the repo root (new file) with the four check families (per security-plan
   §Dependency Security):
   - `[advisories]` — RustSec DB; deny on any open vulnerability (and unmaintained, at policy's discretion).
   - `[bans]` — deny multiple-versions/duplicate crates where avoidable, deny yanked, empty disallowed list
     to start (extend as the tree grows).
   - `[licenses]` — an **allowlist** of permissive licenses appropriate for a local-only personal tool
     (e.g. MIT / Apache-2.0 / BSD-2/3-Clause / ISC / Unicode-3.0 / Zlib); confirm it covers everything in
     today's lock; deny unknown/copyleft.
   - `[sources]` — `crates.io` as the sole allowed registry; deny unknown registries + git sources.
3. **Run `cargo audit --deny warnings`** over the committed lock; it must be **green** (no open RustSec
   advisory). Triage any hit (per security-plan §Dependency Security): a real advisory ⇒ fix/bump; an accepted
   non-actionable advisory ⇒ explicit `[advisories.ignore]` entry in `deny.toml` with a comment, never a
   silent skip.
4. **Run `cargo deny check advisories bans sources licenses`**; it must be **green** against the new
   `deny.toml`. Resolve license-allowlist gaps by adding the genuinely-present license to the allowlist
   (not by loosening to "allow all").
5. **Assert `Cargo.lock` is committed + un-drifted.** It is already git-tracked (`research.md`); run an audit/
   build with `--locked` and confirm no regeneration occurs. If drift appears, regenerate with `--locked` and
   commit the lock — never hand-edit.
6. **Document the gate on the commands surface.** `.claude/docs/commands.md` already lists `cargo audit`; add
   the `cargo deny check` invocation alongside it so the documented gate matches what /implement runs. (The
   CLAUDE.md Workflow block already names `cargo audit` — no CLAUDE.md edit needed.)
7. **Do NOT wire CI here.** There is no `.github/workflows/` yet (`research.md`); CI invocation of the gate
   belongs to the later Epoch-1 chunk _"Base CI + agent-run harness skeleton"_. This chunk makes the gate
   runnable + green **locally**.
