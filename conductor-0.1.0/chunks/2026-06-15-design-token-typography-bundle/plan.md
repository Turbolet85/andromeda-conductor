## Goal
Stand up Conductor's frontend design-system foundation: a Tailwind CSS v4.1 `@theme` design-token layer plus
the self-hosted JetBrains Mono / IBM Plex Sans typography stack, compiled by a Vite + React 19 SPA scaffold
under `crates/conductor-tauri/ui/`. This is the first frontend chunk (Epoch 1 — Foundation): it makes the
authoritative palette / type / spacing / motion tokens literal **once**, so every later UI chunk (the Epoch 9
desktop control panel) binds `var(--…)` against a single, stable, audited source instead of reinventing them
(per design-system.md §Surface: desktop-webview §Tokens + §Color Palette + §Typography; arch §Inherited
Defaults workspace placement).

The token set is carried **verbatim** from design-system.md §Tokens (lines 196-241) — surfaces, the functional
status tier (`--count-nominal`/`-hold`/`-blocked`, `--status-fail`/`-manual`/`-residual`), the reserved mono
ID-cyan tier + `--color-focus`, text hierarchy, border progression, the 4px-base spacing scale, radii, and the
expression-level-0.3 motion tokens (`--motion-micro`/`--ease-quiet`). Auto mode (`@media
prefers-color-scheme: light`) and the global `@media prefers-reduced-motion: reduce` reset are included now
because both are design contracts the Epoch 9 a11y harness will assert (a11y-plan §6/§9 + design-system §Motion;
binds WCAG SC 2.3.3). Fonts are vendored WOFF2 via Fontsource — **zero runtime CDN** — satisfying Minimal-tier
offline hardening (security-plan §Threat Model Summary + §Dependency Security; design-system §Typography Loading).

Boundaries (unchanged from scope.md): **no** Tauri window/frameless config, **no** shadcn/ui / Radix / Lucide /
status-lamp components, **no** IPC / live-counter `Channel`, **no** CLI surface, **no** a11y verification runner
— all Epoch 9. The React `App.tsx` is a **token smoke-test view only** (raw elements binding `var(--…)`), present
solely to prove the bundle compiles and both fonts resolve. No Rust changes: `conductor-tauri/Cargo.toml` and
`src/main.rs` stay as-is; `tauri` is NOT added to the crate yet (Epoch 9), and the GUI bundle remains
convenience-only — the headless CLI stays the release gate (arch §Design Philosophy + §Deployment).

- **Token-name fidelity is the highest-value invariant** — copy the `@theme` block from design-system.md lines 196-241 character-for-character; a rename silently breaks every Epoch 9 `var(--…)` binding with no compile error.
- **Lean font set** — import only the 5 weights design-system §Typography actually uses (JetBrains Mono 400/500; IBM Plex Sans 400/500/600) via Fontsource per-weight CSS imports, not the whole family, to keep the vendored WOFF2 set (and the eventual ~3 MB Tauri bundle) small.
