## Goal
This chunk realizes Conductor's **artifact-hygiene invariant** — "never leak absolute host paths or internal
struct names into logs / run-report / `runs.db` — sanitize at the `anyhow` edge + the tracing-subscriber
field-allowlist" (CLAUDE.md Critical Warnings; security-plan §Error Handling; obs-plan §11, where it is the
`pii-scrubbing-wire` bootstrap phase deferred to this chunk by the prior session's user-confirmed sequencing).
It composes a **redaction layer** onto the existing self-obs `tracing` JSON stack (built in
`2026-06-15-structured-logging-stack`) and builds the **reusable sanitizer** the cli/tauri error edges and the
future Epoch-6 run-report writers (`runs.db` / JSONL journal / Markdown report) will call.

Per the two P4 decisions (user-confirmed): **(1) lean anyhow-edge** — build + fully test the primitive now;
**defer** rewiring the cli/tauri `main()`s to a sanitizing reporter until Epoch 8 (the CLI surface that owns
error rendering), mirroring the prior chunk's lean split. **(2) scrub-first redaction** — value-masking of
host-path / `module::` / backtrace shapes is the hard guarantee applied to every string value, with a bounded
field-name allowlist that drops only *unexpected* names (so existing `message`/`phase`/`count` lines stay
intact). Redaction runs at the **processor stage** inside our custom `JsonObsLayer` (obs-plan §11: "apply at
the processor, not just the sink") — which automatically covers the `std::panic` hook line too.

A consequence of arch §Error handling ("`anyhow` only at the `conductor-cli` / `#[tauri::command]` edges"):
the core sanitizer is **anyhow-free** — it takes `&dyn std::error::Error` / `impl Display`, so **no new direct
dependency is added to any crate this chunk** (the scrubber is std-only; no `regex`). The Epoch-8 edge feeds
its `anyhow::Error` into the same function later.

## Implementation Steps
1. **Add the redaction primitive** as a new reusable module `conductor-core::redact` (top-level, sibling to
   `obs` — reusable beyond logging per the scope's Epoch-6 reuse requirement). Hardcode the rules in this
   single location (obs-plan §11):
   - `redact_value(&str) -> Cow<str>` — mask, with std string ops only (no `regex`; follows obs.rs's
     hand-rolled-std convention): absolute host-path runs (Windows drive-letter `C:\Users\…` / backslash
     paths; POSIX `/home/<user>/…`, `/Users/…`; `%APPDATA%`-style expansions) and Rust `module::path::` /
     struct-name `::` chains and backtrace file-path shapes → the visible placeholder `<redacted>`. Mask only
     the offending substring; preserve the surrounding message text. **Borrow-on-clean:** return `Cow::Borrowed`
     when nothing matches (no needless alloc on the hot log path).
   - `sanitize_error(err: &dyn std::error::Error) -> String` (and/or `impl Display`) — render the
     operator-facing `error: <short, scrubbed>` (+ optional `hint:`) with NO stack trace, `.backtrace()`,
     `.source()`-chain dump, host path, or struct name; scrub the message via `redact_value`. anyhow-free.
2. **Add the bounded field-name allowlist** — `is_allowlisted(name: &str) -> bool` over a hardcoded set: the 7
   identity fields (always) + `message` + the bounded self-obs event/span field names (`phase`, `count`,
   `panic`, `location`, and the verdict/state/envelope names reserved for Epoch-6 records, per obs-plan §6).
   Non-allowlisted event field NAMES are dropped; allowlisted fields still have their VALUES scrubbed.
3. **Wire both into `JsonObsLayer` at the processor stage** (`crates/conductor-core/src/obs.rs`): in
   `JsonVisitor::record_str` / `record_debug` / `record_error` route the value through `redact::redact_value`
   and gate the insert on `redact::is_allowlisted(field.name())`; scrub the constant `target` value on insert
   in `on_event`. The panic line (`panic` payload + `location`) flows through this path, so it is covered with
   no separate panic-path edit.
4. **Re-export from `lib.rs`** — `mod redact;` + `pub use redact::{redact_value, sanitize_error};` so the
   binaries (Epoch 8) and Epoch-6 writers can call the primitive; keep `is_allowlisted` private to the crate
   unless a caller needs it.
5. **Do NOT touch the cli/tauri `main()`s or their `Cargo.toml`s this chunk** (lean decision). Leave a short
   forward note in the chunk report that Epoch 8 wires `sanitize_error` into the `error:` / `hint:` cli reporter.
6. **Tests** (extend `obs.rs` `#[cfg(test)] mod tests`, reusing the `SharedBuf` MakeWriter harness; add a
   `redact` test module): value-scrub unit cases (host paths / `module::` / backtrace → `<redacted>`; benign
   values and repo-relative source paths untouched); allowlist (an unexpected field name is dropped while
   `phase`/`count`/`message`/identity survive — the existing `every_line_is_flat_json_…` test stays green);
   panic-line redaction (a panic payload carrying a host path is `<redacted>` in the single ERROR line);
   `sanitize_error` over a synthetic error chain carrying a stack-trace-ish string + struct name + host path →
   only the scrubbed `error:` / `hint:` shape.
7. **Hold the gate green** — `cargo nextest run -p conductor-core` + `--workspace`, clippy `-D warnings`,
   `cargo audit` + `cargo deny check`, `Cargo.lock` un-drifted. No new direct deps.

## Implementation notes
- **Processor-stage, not sink-stage** (obs-plan §11): redact inside `JsonObsLayer`'s field handling so an
  upstream failure can never leak a raw value via stderr before the sink.
- **The key correctness edge — absolute host path vs repo-relative source path.** The `location` field carries
  `file():line` and `target` carries a module target; a Rust `#[track_caller]`/panic source path may be
  repo-relative (`crates/conductor-core/src/obs.rs` — KEEP) or an absolute host path (`C:\Users\turbo\…` —
  REDACT). The scrubber must distinguish these so it does not gut the useful `location`/`target` (over-redaction
  is a real failure mode). Anchor host-path detection on absolute markers (drive-letter `X:\`, leading `/home/`
  `/Users/`, `%APPDATA%`/`%USERPROFILE%`), not on the mere presence of a slash.
- **std-only scrubber** — no `regex` (keeps the dep tree + audit/deny green; matches obs.rs's `civil_from_unix`
  hand-rolled-std precedent). Return `Cow::Borrowed` on the clean path to avoid allocating on every log line.
- **anyhow stays out of `conductor-core`** — the sanitizer signature is `&dyn std::error::Error` / `impl
  Display`; `anyhow::Error` derefs to `&dyn Error`, so the Epoch-8 cli/tauri edge plugs in without core ever
  depending on anyhow (preserves the arch convention + the verdict/error wall).
- **Lean scope reminder** — cli/tauri `main()`s + their Cargo.tomls are untouched; the wiring (and any
  `anyhow.workspace = true` addition) lands in the Epoch-8 CLI surface chunk, which owns the sanitized-stderr +
  agent-mode rendering.
