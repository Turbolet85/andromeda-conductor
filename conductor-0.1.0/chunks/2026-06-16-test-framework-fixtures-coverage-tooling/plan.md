## Goal
Stand up the workspace-wide test runner + fixture + coverage toolchain so every later epoch inherits one
deterministic, machine-parseable harness. This is the 8th of 9 Epoch-1 (Foundation) chunks. The gating
deliverable is `.config/nextest.toml` with a `ci` profile, so `cargo nextest run --workspace --profile ci`
stops erroring on a missing profile (the active forward gotcha) — per test-plan §3 (5-command harness) +
arch §Standard Contracts.

Five test crates enter the workspace through the established `[workspace.dependencies]` → per-crate
`.workspace = true` inheritance idiom (research, `crates/conductor-core/Cargo.toml:9-14`): rstest, proptest,
insta, assert_cmd, assert_fs (+ a `predicates` companion). cargo-nextest and cargo-llvm-cov are external
`cargo` subcommands, **not** Cargo dependencies, so "wiring" them means the nextest config plus adding
`llvm-tools-preview` to the toolchain. Each tool gets ONE exemplar that exercises a *real* `conductor-core`
public fn (Verdict labels, `redact_value`, `resolve_under`) or the `conductor` bin — proving the wiring
compiles and runs green without throwaway code, and without disturbing the 36 existing `#[test]`s (all in
`conductor-core`, per research).

Three invariants gate the work. The `ci` profile MUST set `retries = 0` explicitly — retries mask flakes and
break "same scenario+seed ⇒ same stream shape" (arch §Established Decisions [Async Runtime Flavor] + test-plan
§2 + obs-plan §1; security-plan §Threat Model Summary). insta runs in assert/CI mode (fail, don't write,
test-plan §2). All new deps must keep `cargo audit` + `cargo deny check` green with `Cargo.lock` committed +
un-drifted (security-plan §Dependency Security). Out of scope: CI wiring (the next chunk), the frontend test
stack (Epoch 9 per test-plan §4 amendment), and all domain tests (their own epochs).

     host path round-trips unchanged) or `resolve_under` (any candidate with a `..` component is rejected).

   - **assert_cmd + assert_fs** in `crates/conductor-cli/tests/cli_smoke.rs` — run bin `conductor` via

6. **Refresh + verify the supply chain** — the dep add regenerates `Cargo.lock`; run `cargo audit` +
   `cargo deny check advisories bans sources licenses`. If `licenses` flags a new license from a transitive

   duplicate versions — that warns, it does not fail.
7. **Green every gate** — `cargo nextest run --workspace --profile ci` (36 existing + ~5 exemplars),
   `cargo test --workspace --doc`, `cargo clippy --workspace --all-targets -- -D warnings`, and a
   `cargo llvm-cov nextest` coverage report.
