## Goal
Ship the second `conductor-faults` helper: a self-contained value type that represents an **exact-length
emission gap that resumes** — the P-015 restart-detection lever. Pulse treats a service whose emission stops
for longer than its restart threshold (>20s) and then resumes as a *restart*, emitting a `RestartEvent` ≤2s
(restart-suppression family uses a 25s gap). This chunk produces the fault *structure* only; it does not emit
OTLP, schedule anything, or read back via MCP — exactly as the port-occupier shipped a standalone primitive
with its live wiring deferred (per scope.md boundaries; arch §Inherited Defaults "headless-drivable core").

The defining property is **exactness**. The timeline's phase gaps are perturbed by seeded jitter
(`phase.rs` `PhaseTimeline.jitter`), and a jittered gap could drop below 20s and silently fail to trigger
restart detection. So this helper owns an *un-jittered, exact* `Duration` with a hard **>20s floor guard** —
its value-add over a raw `PhaseSpec` gap (whose `MAX_GAP_MS` ceiling already anticipates Epoch-4 timings but
has no floor). The gap is a fixed value by definition, so it is **deterministic by construction and
seed-independent** — mirroring the exception-fingerprint primitive's seed-independent derived value, and
unlike `rate.rs`'s seeded `RateCurve` (whose `different_seeds_diverge` test does not apply here). An invalid
gap (≤ the 20s floor, or above a sanity ceiling) surfaces as a typed `FaultError` VALUE, never a panic — the
verdict/error wall (arch §Established Decisions [Error Handling]; security-plan §Error Handling).

This refines scope.md's "deterministic under seed" to "deterministic by construction (exact)" — same intent
("exact gap lengths"), no scope divergence; the seed simply is not a driver of an exact value.

## Implementation Steps
1. **New helper module `gap.rs`** (sibling to `port_occupier.rs`). Define a small public value type — name
   `EmissionGap` — that wraps an exact gap `std::time::Duration` and carries the "silence-then-**resume**"
   semantic in its contract doc (the contrast with the P-014 *permanent* silence chunk that follows). Keep it
   `#[derive(Debug, Clone, Copy, PartialEq, Eq)]` (mirrors `RateCurve` rate.rs:29).
2. **Validating constructor** `EmissionGap::new(gap: Duration) -> Result<Self, FaultError>` (the port_occupier
   `Result<Self, FaultError>` idiom, port_occupier.rs:29):
   - Enforce the **>20s floor**: the gap must strictly exceed the restart-detection threshold. Define one
     named constant (e.g. `pub const MIN_GAP: Duration = Duration::from_secs(20)`) referenced in the check +
     docs — no magic number duplicated (security-plan §Security Anti-Patterns "single named constant").
   - Enforce a **sanity ceiling** (parity with core `MAX_GAP_MS = 3_600_000`, phase_spec.rs:15) so an absurd
     gap is rejected too.
   - On violation, return the typed `FaultError` variant(s) from step 4; never panic, never `unwrap`.
3. **Exact-value accessor** `gap(&self) -> Duration` returning the stored value verbatim (no rounding, no

4. **Extend `FaultError`** (error.rs:13) with a typed validation variant for the floor violation — e.g.

5. **Register in `lib.rs`** — add `mod gap;` + `pub use gap::EmissionGap;` (and `MIN_GAP` if public) alongside

6. **Tests** (in-module `#[cfg(test)]`, rate.rs/port_occupier style):

## Implementation notes
- **Key design decisions (surfaced for approval — both decided from precedent):**
  1. `Result<Self, FaultError>` over `Option<Self>` (rate.rs's idiom) — a named sub-floor error is clearer
     for the P-015-critical 20s threshold, and `FaultError` is the `#[non_exhaustive]` seam error *designed*
     to extend (error.rs:6).
  2. **Seed-independent / exact** (no `seed` param) — "exact gap lengths" means the value is fixed; adding an
     unused seed would be the "computed-but-never-applied" anti-pattern. Determinism is by construction.
- **Boundary sense:** "gap >20s" is strictly greater than the 20s threshold (so `20s` rejects, `25s` accepts);
  document the chosen `>`/`≥` sense on `MIN_GAP` and assert it in the boundary test.
- **Resume is intrinsic:** `EmissionGap` is a temporary silence that resumes after `gap`; the contrast with
  P-014 (permanent silence, no resume) is carried by the type's contract — no separate "resume" field is
  needed. Do not invent a `MalformedGapResume` ordering error (an extract over-spec) unless a structure with
  orderable parts actually exists.
- **Deferred (NOT this chunk):** the `fault.silence` obs span, the timeline/emit gap execution, scenario-
  config (garde) wiring, and the P-015/P-016/P-057 restart-suppression read-back verification — Epochs 7/8.
