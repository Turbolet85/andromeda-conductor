## Goal
Give `conductor-faults` its first real primitive: a **`PortOccupier`** that binds and holds Pulse's OTLP
ingest port (`127.0.0.1:4317`), denying it to Pulse so Pulse surfaces its **P-003 "ReceiverFailed"** state,
then releases it deterministically on cleanup. This is the **sole deliberate inbound bind** in all of
Conductor — every other surface is a pure client — so the chunk is as much about the bind→hold→release
discipline (loopback-only, RAII release) as the bind (per architecture §Occupied Resources + §Cross-cutting
Patterns "Trust boundary"; the one documented exception in the Critical Warnings).

Research shows `conductor-faults` is a **cold-start crate** (only the crate node exists; zero dependents — purely
additive) with rich, directly-applicable precedent next door in `conductor-emit`: module-per-primitive with
`pub use` re-exports, a seam-local thiserror error (`EmitError`), and an ephemeral-`:0` loopback test idiom
(`tests/egress.rs`, whose doc already *reserves* `:4317` for "the Epoch-4 port-occupier fault" — this chunk).
A key simplification falls out: because the occupier only **binds + holds + drops** (it never `accept()`s and
never speaks OTLP), it is a **synchronous `std::net::TcpListener`** — no `tokio` dependency and a plain sync
`#[test]`, keeping the seam minimal and dep-light (per test-plan §10 zero-flakiness; the verification-harness
rule's `cleanup` contract: release the bind, idempotently).

Bind-failure (the port already held — e.g. a live Pulse is up) is a **typed `FaultError` value** (`Result::Err`),
never a panic — the verdict/error wall, mirroring `EmitError` (per architecture §Conventions error-handling +
security-plan §Error Handling). Verification of Pulse's actual ReceiverFailed reaction and any scenario/harness
orchestration are **deferred** (Epoch 7 connection-lifecycle scenarios; Epoch 8 `cleanup` wiring); this chunk
ships the standalone primitive exercised in isolation, exactly as the Epoch-3 emission primitives were.

## Implementation notes (optional)
- **Doctest must not bind `:4317`.** Any `///` doc example must use `occupy(0)` or be `no_run`/`ignore` — a runnable
  doctest binding the real port would collide with a live Pulse and break the zero-flakiness bar.
- **Exclusivity is empirical, not flag-reasoning.** `std::net::TcpListener::bind` does `bind`+`listen` (reserves the
  port) without needing `accept()`; never set `SO_REUSEPORT`. Plain `bind` is exclusive cross-platform (Windows
  exclusive by default; Unix std sets `SO_REUSEADDR`, which does **not** permit a second concurrent live bind
  without `SO_REUSEPORT`). The second-bind-fails test is the proof regardless of platform flag nuance.
- **Release shape.** `Option<TcpListener>` + `release(&mut self)` that `.take()`s the listener + `Drop` delegating to
  `release()` gives both RAII safety and the idempotent explicit release the Epoch-8 `cleanup` contract calls.
- **Deferred (not this chunk):** obs `fault.port_occupier` span + `warn!`-on-bind-fail (apply when driven under a
  timeline — Epoch 7); operator-facing error rendering (color+label, never color-alone — design §Color Palette /
  a11y SC 1.4.1) is Epoch 8/9; scenario-config/garde wiring is Epoch 7. This chunk surfaces the typed value only.
- **No CoreError bridge** — `FaultError` is seam-local like `EmitError`; the binary edge (`anyhow`) unifies later.
