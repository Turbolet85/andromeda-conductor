## Goal
Add `BurstyTrain`, a deterministic fault-helper **primitive** in `conductor-faults` describing the P-013
bursty-train activity pattern: a repeating duty cycle of an **active** emission window followed by a **quiet**
window (canonically 5 min / 10 min), looping indefinitely. It is the activity-floor **false-positive guard** —
a legitimately *periodic* service whose long quiet windows (10 min, up to a 60 min "lunch" variant) deliberately
exceed the ~30s naïve activity-floor death cue, so only a detector that recognises the *recurring train* avoids
flagging it dead. It is the healthy-but-intermittent third member of the activity-floor lever family alongside
`AbruptSilence` (P-014, permanent death) and `EmissionGap` (P-015, single restart gap).

Per the resolved P4 decision ("Helper shape" → **Parameterized + validated (Result)**), `BurstyTrain` mirrors
`EmissionGap`'s validated-constructor branch of the fault-constructor idiom: `new(active, quiet) ->
Result<Self, FaultError>` with bound validation, a `canonical()`/`Default` for the 5/10 values, and the `*_ms`
accessors + within-cycle phase query the Epoch-7 `PhaseSpec` boundary will consume. Parameterizing (vs a fixed
marker) lets the *same* helper express the Epoch-7 "lunch" duty cycle the activity-floor scenarios (P-013..P-016)
need — no second helper. Constructor shape per arch §Design Philosophy (Outcomes are values) + security-plan
§Error Handling; determinism per arch §Established Decisions (Determinism RNG reserved for the timeline alone).

This is a **pure descriptor** like its three siblings: it OWNS exact, un-jittered duty-cycle values (the
timeline applies seeded jitter when it later drives the pattern). Boundaries below restate scope.md: no timeline
wiring, no scenario config, no `fault.*` obs span, no OTLP emission — all route-sequenced to Epoch 7/8.

2. **Bound + canonical consts at module top** (pub, re-exported — mirrors `MIN_GAP`/`MAX_GAP` in `gap.rs:18,22`):
   - `MAX_WINDOW: Duration = Duration::from_secs(3_600)` — per-window sanity ceiling (1 h), parity with `MAX_GAP`;
     inclusive, so the Epoch-7 "lunch" 60-min quiet is valid.
   - `CANONICAL_ACTIVE: Duration = Duration::from_secs(300)` (5 min); `CANONICAL_QUIET: Duration =
     Duration::from_secs(600)` (10 min).
3. **The `BurstyTrain` type** — `#[derive(Debug, Clone, Copy, PartialEq, Eq)]` struct holding `active: Duration`
   + `quiet: Duration` (private fields; built only through the constructors), matching `EmissionGap`'s shape
   (`gap.rs:26-29`).
4. **`new(active: Duration, quiet: Duration) -> Result<Self, FaultError>`** — validate, in order:
   - `active.is_zero()` ⇒ `Err(FaultError::ActiveZero)` (a zero active window is permanent silence — P-014's domain).
   - `quiet.is_zero()` ⇒ `Err(FaultError::QuietZero)` (a zero quiet window is continuous emission — not bursty).
   - `active > MAX_WINDOW` or `quiet > MAX_WINDOW` ⇒ `Err(FaultError::WindowTooLong { window, max: MAX_WINDOW })`
     (carry the offending window). Ceiling is inclusive.
   - else `Ok(Self { active, quiet })`. Carries a doctest (happy path + one `is_err()`), per `gap.rs:35-43`.
5. **`canonical() -> Self`** (infallible — values are statically known-valid, so construct the struct literal
   directly from the consts; do NOT `unwrap` a `Result`) + **`impl Default`** delegating to `canonical()`
   (mirrors `AbruptSilence`'s `Default`, and `PortOccupier::occupy_default`'s convenience-constructor intent).
6. **Accessors** — `active()`/`quiet()`/`period()` returning `Duration` (`period = active + quiet`, never zero
   since `active > 0`), plus `active_ms()`/`quiet_ms()`/`period_ms()` returning `u64` for the Epoch-7
   `PhaseSpec`/timeline boundary. Reuse `gap.rs:61-64`'s documented-safe narrowing comment (each window
   ≤ `MAX_WINDOW` = 3_600_000 ms, period ≤ 7_200_000 ms, so `as_millis() as u64` never truncates).
7. **Phase query `is_active_at(offset: Duration) -> bool`** — the essence of *repeating*: emission is active
   when `offset` falls in the active sub-window of its cycle. Compute in `u128` nanos to avoid `Duration: !Rem`:
   `(offset.as_nanos() % self.period().as_nanos()) < self.active().as_nanos()`. Half-open convention: active is
   `[0, active)` within each cycle, quiet is `[active, period)` — so `is_active_at(active)` is `false` and
   `is_active_at(period)` is `true` (wraps to the next cycle). Document this. (No div-by-zero: period > 0.)
8. **In-module `#[cfg(test)]` tests** (see Acceptance) — valid cycle + accessors, canonical/Default, the three

## Implementation notes (optional)
- **Constructor-shape idiom:** this is the `Result`/validated branch (mirror `EmissionGap @ gap.rs:31`), the
  counterpoint to `AbruptSilence`'s infallible branch — completing the three-branch idiom across the crate's
  four helpers.
- **`canonical()` stays infallible** by constructing the struct literal from the known-valid consts — do not
  route it through `new(...).unwrap()/.expect()` (no panics on a known-good path; clippy-clean).
- **`is_active_at` arithmetic:** `Duration` does not implement `Rem`, so compute the cycle position in `u128`
  nanos. `period().as_nanos()` for the max case (7200 s) is ~7.2e12, far inside `u128`; `period > 0` always
  (since `active > 0`), so the modulo never divides by zero.
- **Forward bindings (NOT this chunk):** the Epoch-7 timeline consumes `*_ms()` + `is_active_at` via `PhaseSpec`
  (with seeded jitter); a `fault.*` bursty-train obs span (Epoch 7/8) will read the same accessors — exact span
  name is an Epoch-7 decision (obs-plan §4 bounded set is `fault.{silence,ramp,port_occupier}` today). The
  exact-asserted `*_ms` values here pre-stabilise those future span attributes (tests ↔ obs binding).
- **Float `duty_cycle()` deliberately omitted** — keeps the surface deterministic-test-friendly (no epsilon
  comparisons); add it in Epoch 7 only if a scenario needs the ratio.
