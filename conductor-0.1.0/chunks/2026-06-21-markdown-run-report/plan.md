## Goal
Build the per-run **Markdown run report** — the human-facing third consumer of the run-report envelope,
sibling to the JSONL `JournalWriter` and the `runs.db` `RunsDb` (all three render the same `RunRecord` shape,
per architecture §Standard Contracts). Given a run's `RunRecord`s it produces a deterministic Markdown
document at `runs/<run_id>.md` — `run_id`-stemmed, never overwritten — classifying every scenario check into
its lamp and showing the envelope fields, with **Blocked rows** reduced to identity + slo_tier (the blocked-row
null rule renders the five never-measured fields as an em-dash, never `null` or a struct name).

The defining new behavior is **verdict-first lamp precedence** (carried follow-up (c); arch
§Probabilistic-Assertion Policy; a11y-plan §6 state-naming crosswalk): a `CalibrationRegion` verdict renders
`[HOLD]`, **not** `[MANUAL]`, even though its default state is `ManualCheck`. This chunk is the **first**
surface to realize that rule, and every distiller (arch/design/layouts/obs/a11y/tests) agreed it must be a
**shared, reusable helper** rather than report-local — so it lands as a new `Lamp` type in `conductor-core`
(the dependency root) and is reused unchanged by coverage-matrix (Epoch 6 ch4), cli (Epoch 8), and desktop
(Epoch 9). Status is encoded by the ASCII prefix because Markdown has no color — the status-never-color-alone
invariant where the prefix *is* the encoding (design-system §Component Patterns §6; a11y-plan §11 SC 1.4.1).

The report is a pure renderer (per architecture §Cross-cutting Patterns verdict/error wall): verdicts/states
are rendered *values*; `Result::Err` is reserved for the harness fault of writing the file. No new dependency
is introduced (security extract); tests follow the crate's established exact-string `assert_eq!` golden pattern
(`run_record.rs:131`), not `insta`.

## Implementation Steps

1. **Add the shared `Lamp` type to `conductor-core`** (new `crates/conductor-core/src/lamp.rs`; `mod lamp;` +
   `pub use lamp::Lamp;` in `lib.rs`). Define `enum Lamp { Pass, Fail, Hold, Manual, Residual, Blocked }`
   (`Debug, Clone, Copy, PartialEq, Eq`). Provide:
   - `Lamp::for_record(record: &RunRecord) -> Lamp` — the verdict-first precedence resolver (table below).
   - `Lamp::status_prefix(&self) -> &'static str` → `[PASS]`/`[FAIL]`/`[HOLD]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]`.
   - `Lamp::label(&self) -> &'static str` → `Pass`/`Fail`/`HOLD`/`Manual`/`Residual`/`Blocked` (matches the
     existing `Verdict::label`/`ReportState::label` spellings — a11y-plan §6 crosswalk; keep them consistent).
   Module doc cites arch §Probabilistic-Assertion Policy. (The existing `Verdict`/`ReportState`
   `status_prefix`/`label` methods stay; `Lamp` is the unified lamp surface, not a refactor of those.)

   **Verdict-first precedence table** (`Lamp::for_record`) — evaluated top-down:
   | condition | lamp | why |
   |---|---|---|
   | `state == Blocked` | `Blocked` | never measured; verdict is `None` (the verdict can't express it) |
   | `state == KnownResidual` | `Residual` | deliberate producer override — the accepted-residual signal must win over the raw verdict, or KnownResidual's defined purpose (distinguish residual from real Fail) is lost |
   | `verdict == Some(Pass)` | `Pass` | verdict-first |
   | `verdict == Some(Fail)` | `Fail` | verdict-first |
   | `verdict == Some(CalibrationRegion)` | `Hold` | **the rule** — calibration renders HOLD, not Manual |
   | `verdict == None` (state `ManualCheck`) | `Manual` | operator-checklist claim, no programmatic verdict |
   | `verdict == None` (state `Pass`/`Fail`) | `Pass`/`Fail` | defensive fallback |

2. **Add the `ReportError` harness-fault enum** (in the new report module) — `#[non_exhaustive]` thiserror,
   `Io(#[from] std::io::Error)`, mirroring `JournalError` (`journal.rs:18`). Harness-fault only (verdict/error
   wall) — a write failure is `Err`, a verification outcome never is.

3. **Write the pure renderer** `render(run_id: &str, records: &[RunRecord]) -> String` (new
   `crates/conductor-report/src/report.rs`). No IO, no clock — a pure function of its inputs so it is
   exact-golden-able and deterministic by construction (resolves the "generated-at" latitude: the seam reads
   **no** wall-clock; `run_id` already embeds the run timestamp). Structure:
   - **Summary header:** `# Run report <run_id>`, the seed, and per-`Lamp` counts (e.g. `2 PASS · 1 HOLD ·
     1 BLOCKED`). run_id/seed rendered as the mono ID-tier data (design-system §Typography — Markdown carries
     no font, but keep them in inline-code spans).
   - **Per-scenario detail:** one row/section per `RunRecord` (in given order — caller controls ordering),
     leading with `Lamp::for_record(rec).status_prefix()` + label, then `scenario`, `p_ids` (bare `P-NNN`,
     comma-joined), `slo_tier` (`<5s`/`<20s`/`<90s` directly), and the measurement fields `verdict`, `state`,
     `latency_ms`, `journal_emitted_at`, `read_back_observed_at`, `fingerprints`.
   - **Blocked-row null rule:** when `Lamp == Blocked` (equivalently the measurement `Option`s are `None`),
     render those five fields as `—` (em-dash) — never the literal `null`, never a struct name (arch §Standard
     Contracts; security/obs/design/a11y extracts unanimous).
   - **Hygiene:** emit only owned envelope values; never interpolate a host path or a Rust type name. (Inputs
     are already-sanitized envelope strings; the renderer adds no path/struct text.)

4. **Write the file writer** `RunReport::write(runs_dir: &Path, run_id: &str, records: &[RunRecord]) ->
   Result<PathBuf, ReportError>` — `fs::create_dir_all(runs_dir)` then `OpenOptions::new().write(true)
   .create_new(true)` on `<run_id>.md`, write `render(...)`, return the path. `create_new` makes
   **never-overwrite** explicit and loud: a pre-existing `<run_id>.md` is an `Err` (AlreadyExists), never a
   silent clobber — the model of `RunsDb`'s loud duplicate-key error (`db.rs:72`). `runs_dir` is handed in
   already-resolved (cli edge owns `CONDUCTOR_RUNS_DIR`, Epoch 8; journal.rs:7 / db.rs:51 convention).

5. **Export from the report seam** — `mod report;` + `pub use report::{RunReport, ReportError};` in
   `crates/conductor-report/src/lib.rs` (alongside the existing `JournalWriter`/`RunsDb` exports).

6. **Tests** — exact-string `assert_eq!` goldens (crate convention, `run_record.rs:131`; **no `insta`**, no new
   dep). In `conductor-core` `lamp.rs`: the full precedence table (all six lamps incl. CalibrationRegion→`Hold`,
   KnownResidual-with-a-verdict→`Residual`, Blocked→`Blocked`) + `status_prefix`/`label` stability. In
   `conductor-report` `report.rs` (`#[cfg(test)]`, `assert_fs::TempDir`): see Acceptance Criteria.

## Implementation notes
- **`Lamp` lives in core, not report** — every distiller converged on this; core is the dependency root and
  owns `Verdict`/`ReportState`/`RunRecord`, so the lamp (a pure function of those) belongs beside them and is
  reachable by cli/tauri/coverage-matrix without making `conductor-report` a dependency. Adding to core is
  additive (research §Graph impact).
- **Precedence ordering matters** — `KnownResidual`/`Blocked` are checked *before* the verdict arms, because a
  `measured()` KnownResidual row carries `Some(verdict)`; a naive "verdict-first else state" would mis-render it
  as `[FAIL]`/`[PASS]`. The table in Step 1 is the authority. (Flagged in research §Open questions — confirm at
  review.)
- **No clock in the seam** — `render` reads no wall-clock (the determinism + exact-golden requirement). If a
  human-facing "generated at" is later wanted, the cli edge injects it as a parameter; the seam stays pure.
  (Flagged in research §Open questions — confirm at review.)
- **Blocked detection** — prefer driving the em-dash off `Lamp::Blocked` / the `Option::is_none()` of each
  measurement field, so the renderer never needs to match `ReportState` variants by name (keeps the blocked-row
  rule and the lamp in one source of truth).
