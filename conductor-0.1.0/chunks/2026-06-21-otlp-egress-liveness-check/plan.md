## Goal

Realize the architecture's **"Liveness equivalent (OTLP egress check)"** (architecture.md §Standard Contracts)
as a first-class, standalone preflight primitive in `conductor-emit`: before emission, the harness must be able
to confirm the gRPC channel to `127.0.0.1:4317` is connectable, and a refused/unreachable transport must surface
as `Result::Err` (a Conductor harness fault), **never** a verification verdict (architecture.md §Design Philosophy
verdict/error wall; security-plan §Error Handling).

P3 research found the liveness *behavior* already emerges from emitter construction: `TraceEmitter::connect()`
(`client.rs:30`) does `Endpoint::from_shared(...)?.connect().await?` and already returns `EmitError::Transport`
on refusal — `tests/egress.rs:73` `refused_transport_surfaces_emit_error` asserts exactly this. But that surface
is (a) **coupled to emitter construction** and (b) **unbounded in connect time** — a grep confirms there is no
`connect_timeout` anywhere in the seam, so an unreachable/black-hole host would hang on the OS default rather than
fail fast and deterministically.

This chunk therefore adds (1) a dedicated `probe_egress(endpoint) -> Result<(), EmitError>` (connect + drop) that
mirrors `conductor-verify::run_preflight` as a distinct pre-emission gate decoupled from emitter lifecycle, and
(2) a bounded `DEFAULT_CONNECT_TIMEOUT` (`std::time`, never tokio's virtual clock — arch + security + obs extracts)
threaded through the probe **and** both emitters so the connect is fail-fast everywhere. Emitter ownership and the
suite-start orchestration ("run the probe before the timeline emits; abort the run on `Err`") stay deferred to the
Epoch-8 CLI per scope.md §Boundaries — this chunk ships the reusable primitive + its typed-error contract only.
(Deliverable shape user-confirmed at P4: standalone probe + timeout.)

## Implementation Steps

1. **Centralize bounded-endpoint construction** in `client.rs`. Factor a private helper that builds the tonic
   `Endpoint` with the bounded connect timeout applied (`Endpoint::from_shared(addr)?` then `.connect_timeout(DEFAULT_CONNECT_TIMEOUT)`),
   returning `Result<Endpoint, EmitError>` (the `from_shared` error already rides `#[from] tonic::transport::Error`
   → `EmitError::Transport`). Add `pub const DEFAULT_CONNECT_TIMEOUT: std::time::Duration` — a small fail-fast bound
   (≈5s; this is a connect bound, NOT an SLO tier). Keep `DEFAULT_OTLP_ENDPOINT` as-is.
2. **Add the standalone probe.** `pub async fn probe_egress(endpoint: impl Into<String>) -> Result<(), EmitError>`:
   build the bounded endpoint, `.connect().await?`, drop the resulting `Channel`, return `Ok(())`. It exports **no**
   OTLP message and carries **no** `#[tracing::instrument]` span (matching the un-instrumented `connect()` and the
   obs bounded span-set — see step 6). Refused / invalid / timed-out transport rides `?` → `EmitError::Transport`.
3. **Thread the bound through the emitters.** Route `TraceEmitter::connect` (`client.rs:30`) and `LogsEmitter::connect`
   (`client.rs:67`) through the same private helper so emission connect is bounded too. This is behavior-preserving
   except unbounded→bounded; the code-graph shows no external callers to disturb (see Codebase touchpoints).
4. **Re-export** `probe_egress` and `DEFAULT_CONNECT_TIMEOUT` from `lib.rs` (the `pub use client::{...}` line at
   `lib.rs:23`), following the existing free-function/const export style (`trace_request`, `DEFAULT_OTLP_ENDPOINT`).
5. **Tests** (extend `tests/egress.rs`, reuse `start_stub()` at `egress.rs:34`; or a sibling `tests/liveness.rs`):
   - connectable: stub on ephemeral `127.0.0.1:0` ⇒ `probe_egress(format!("http://{addr}"))` returns `Ok(())`;
   - refused: `probe_egress("http://127.0.0.1:1")` ⇒ `Err(EmitError::Transport(_))` (instant RST — fast + deterministic);
   - bounded-timeout: assert the bound is applied and refusal returns promptly as `Err` (do NOT plan a real
     black-hole wait — see Implementation notes; a flaky timeout test violates the zero-retry bar).
   All under `#[tokio::test(flavor = "current_thread")]`; **never bind `:4317`** (reserved for the P-003
   port-occupier fault — testing.md / test-plan §8).
6. **Confirm no obs/dep drift.** No new span name is introduced (the obs bounded span-set — obs-plan §4/§11 — is
   unchanged; `emit.liveness_check` is intentionally NOT added, avoiding a forced obs-plan amendment); no OTel SDK
   is initialized. No new Cargo dependency (`std::time::Duration` + existing `tonic`; `tokio` stays dev-only).

## Implementation notes
- `EmitError::Transport` already covers a `connect_timeout` elapse (tonic returns `tonic::transport::Error`), so **no new error variant is required**; `EmitError` is `#[non_exhaustive]` if a distinct `Timeout` is later judged worth the diagnostics.
- **Connect-and-drop (Option A):** Epoch-8 re-connects when it builds the emitter; the second connect on loopback is negligible and keeps emitter ownership out of this chunk. (Option C — returning the live `Channel` — was rejected at P4 to avoid pulling Epoch-8 ownership forward.)
- **Determinism on the timeout test:** the refused case (`127.0.0.1:1`) returns an instant RST → `Err`, fast and deterministic; do NOT introduce a real black-hole wait or `sleep(N)` (zero-retry bar — testing.md). Assert the timeout is *applied* (the const is wired into the endpoint) rather than racing a wall-clock deadline.
- Threading the bound through both emitters' `connect` is behavior-preserving (unbounded→bounded only) and safe — grep confirms no external caller depends on the current unbounded behavior.
- `std::time::Duration` only; tonic's `connect_timeout` handles the bound internally — no `tokio/time` feature is pulled into the seam's non-dev deps.
