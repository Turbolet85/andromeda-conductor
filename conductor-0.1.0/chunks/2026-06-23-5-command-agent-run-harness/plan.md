## Goal
Turn the `scripts/agent-run.{sh,ps1}` **skeleton** into the real **5-command agent-driven harness** — the headless source-of-truth driver and release gate (arch §Headless-drivable core; test-plan §3 / `verification-harness.md`). The skeleton already sketches `boot/run/status/cleanup/logs`, but its `boot` shells out to **`conductor preflight --json`, a verb the CLI does not yet ship** (cli.rs has only `Run`/`Suite`/`Report`). So the load-bearing deliverable is the **`conductor preflight` verb**: a thin serialize-and-exit over the already-built readiness gate, plus the contract-hardening the five commands need to be agent-parseable, safe, and at `.sh`⇄`.ps1` parity.

The verb **reuses the hardened read-back infra unchanged** (the no-new-boundary rule from the ch1 session): `ReadbackClient::connect` (the fixed-path sidecar spawn whose single `Err` covers data-dir-rejected / spawn-fail / initialize-fail) + `run_preflight` → a `serde`-ready `ReadyState` that already *is* the arch readiness JSON shape (arch §Standard Contracts). `pipeline::preflight` currently discards that `ReadyState` (keeping only `.ready`); the one refactor is to surface it so the verb can serialize it and so the scenario path keeps deriving `ready` from the same code. No engine/seam model change (security-plan §Anti-Patterns — consume the hardened spawn, add no new boundary).

The shell side gains: `run` stage flags (`--unit/--integration/--e2e`, per test-plan §9; default = the full bundled gate CI dogfoods), `run_id` charset-validation before any `sqlite3`/path interpolation (security-plan §Input Validation — no string-concatenated SQL on unvalidated input), and `status`/`logs` defaulting to the latest run (mirroring `conductor report`'s `latest_run_id`, since `run` does not surface the minted run_id). Per the P4 decision, `conductor preflight` is a **go/no-go gate**: exit 0 iff `ready:true`, non-zero on a `ready:false` Blocked precondition (test-plan §3) — CI-safe because CI dogfoods `run`, not `boot`. Rich CLI rendering (owo-colors/indicatif), `isatty` operator-pause, and agent-mode JSON-to-file logging are **explicitly out of scope** (Epoch-8 ch3/ch4/ch5) — the harness stays a thin orchestrator that delegates to the `conductor` binary.
