## Goal
This chunk turns the `conductor` binary from an init-only stub into the **composition root** of the harness.
Research established that the five engine seams (core·timeline·emit·verify·report) are mutually independent —
each depends only on `conductor-core` — so the CLI is the first and only place the full run pipeline is wired
end-to-end (per arch §Headless-drivable core + [Module Boundaries]; research §Graph impact). It builds the
clap-derive verb surface (`run`/`suite`/`report`) over a `#[tokio::main(flavor="current_thread")]` bootstrap
(the determinism invariant — arch [Async Runtime Flavor]; arch-extract C1) with anyhow only at the binary edge
(arch §Conventions; security-extract C3).

`conductor run <scenario|P-ID> --seed <s>` resolves a scenario from `scenarios/` (`Scenario::from_toml_str`,
garde-validated — security-extract C2), drives the seeded `conductor-timeline`, runs the MCP preflight gate,
and persists the canonical eleven-field envelope through the report seam (JSONL journal + `runs.db` +
Markdown). The preflight gate is the pivot: when no live Pulse is reachable (CI / no `andromeda-pulse-mcp` at
the fixed path), `preflight_boot` degrades to a `Blocked` `ReadyState` (preflight.rs:180; never a silent
downgrade — arch §Read-Back Dependency Posture), the run short-circuits to a `RunRecord::blocked` envelope, and
the verb still exits 0 and persists. **This Blocked path is the fully-CI-testable spine.** When a live Pulse
*is* ready, the run additionally probes egress, coarse-emits per phase `Signal`, reads back, classifies via
`evaluate_check`, and persists a measured record — the live leg, operator-gated as always (verification-harness.md;
tests-extract C1/C6).

Per the exit-code discipline (test-plan §1; obs-extract C6; tests-extract): exit 0 = all `Pass`; non-zero ONLY
on a hard `Fail`; `Blocked`/`ManualCheck`/`KnownResidual`/`CalibrationRegion` are reported envelope states, not
non-zero exits. Output is plain ASCII-prefixed status lines via `Lamp::status_prefix()`
(`[PASS]`/`[FAIL]`/`[HOLD]`/`[MANUAL]`/`[RESIDUAL]`/`[BLOCKED]` — status-never-color-alone, design-extract C1 /
layouts-extract C2); the owo-colors/comfy-table pretty rendering is **ch3**, the isatty `inquire` pause is
**ch4**, the agent-mode JSON log sink + `error:`/`hint:` format is **ch5**, and the shell harness + standalone
`conductor preflight` verb are **ch2** (`boot=preflight`). a11y has no domain coverage (CLI surface is
not-assertable — a11y-extract).

2. **Bootstrap + dispatch** (`src/main.rs`) — replace the stub with `#[tokio::main(flavor="current_thread")]`;

   logic (obs-extract C2); parse the clap `Cli`; dispatch to the verb handler; map the handler's
   `anyhow::Result<ExitCode>` to the process exit, printing a sanitized `Display` error (via
   `sanitize_error`/`redact_value`) to stderr on `Err` (security-extract C3; obs-extract pattern 2).
3. **CLI surface** (`src/cli.rs`) — clap `Cli` + `Commands` enum:
   `Run { target: String, #[arg(long)] seed: Option<u64> }`, `Suite { #[arg(long)] filter: Option<String>,
   #[arg(long)] seed: Option<u64> }`, `Report { run_id: Option<String> }`. `--help`/`<verb> --help` derive from
   the doc comments (layouts-extract C5 — flat verb-noun).
4. **Path edge** (`src/paths.rs` or inline) — resolve `CONDUCTOR_SCENARIOS_DIR` (default `scenarios/`),
   `CONDUCTOR_RUNS_DIR` (default `runs/`), `CONDUCTOR_CONTRACT_MANIFEST` (default under `contracts/`) via
   `conductor_core::resolve_under(base, candidate)` before any read/write (security-extract C1; arch C5);
   resolve a `run` target to a scenario file by name, else by scanning for a TOML whose `p_ids` contains the
   P-ID. Apply seed precedence: `--seed` > `CONDUCTOR_SEED` > the scenario's own `seed`.
5. **Run pipeline** (`src/pipeline.rs`) — the orchestration that produces one `RunRecord` for a scenario:
   - Open the root span `scenario.run` (fields `run_id`, `seed`, `scenario`, `p_ids` — obs-extract pattern 1 /
     C5; bounded span name).
   - Build the preflight inputs (contract `ContractManifest`, `CanaryMarker`, resolved `data_dir`) and call
     `preflight_boot` (spawning the sidecar via `ReadbackClient`). **If `!ready`:** return
     `RunRecord::blocked(run_id, seed, scenario, p_ids, slo_tier)` and stop (no emission). This is the CI path.
   - **If `ready` (live):** `probe_egress(DEFAULT_OTLP_ENDPOINT)` (refused → harness `Err`); capture
     `journal_emitted_at = now_rfc3339()`; `let tl = PhaseTimeline::from(&scenario); run_timeline(&tl, seed)`;
     for each transition coarse-emit by the phase `Signal` (`Traces → TraceEmitter::export(trace_request(…))`,
     `Logs → LogsEmitter::export(severity_logs_request(…))`; `Metrics` has no builder → skip with a logged
     note). Do a basic read-back (`query_incident_list`), capture `read_back_observed_at = now_rfc3339()`,
     stringify the result as `observed`.
   - **Classify:** if `scenario.expected` is non-empty, `evaluate_check(check, &observed, slo_tier, emitted_ms,
     observed_ms)` per check, fold to the worst verdict, and assemble via `CheckOutcome::to_run_record(…)`
     (record.rs:22; verify-extract). If `scenario.expected` is empty (operator-checklist / declare-only),
     record the operator hold via `resolve_hold(&HeadlessResolver::proceed(), &hold)` and construct a
     **ManualCheck** record directly (`verdict: None`, `state: ReportState::ManualCheck`) — `Lamp::for_record`
     already maps `(ManualCheck, None) → Manual` (lamp.rs:44), so **no core change** is needed.
6. **`run` handler** (`src/commands/run.rs`) — resolve one scenario → `pipeline::run_scenario` → persist the
   single record (`JournalWriter::create(runs_dir, run_id).append(&rec)`, `RunsDb::open(runs_dir).insert(&rec)`,
   `RunReport::write(runs_dir, run_id, &[rec])`) → print the `Lamp::status_prefix()` line → return the
   exit code.
7. **`suite` handler** (`src/commands/suite.rs`) — enumerate `scenarios/*.toml` (optionally `--filter` by name
   substring), resolve+validate each, run them sequentially over the ONE runtime + ONE preflight gate
   (preflight once at suite start — arch §Standard Contracts), append each record to the same `run_id` journal
   + db + a single `RunReport::write(runs_dir, run_id, &records)`; exit non-zero iff any record lamps `Fail`.
   (`runs.db` PK `(run_id, scenario)` keeps each scenario a distinct row — research §Conventions.)
8. **`report` handler** (`src/commands/report.rs`) — read the persisted JSONL journal `runs/<run_id>.jsonl`
   (one `RunRecord` per line via `serde_json`), render with `RunReport::render(run_id, &records)` to stdout
   (read-only); when `run_id` is omitted, pick the newest journal in `runs_dir`.
9. **Exit mapping** (`src/exit.rs` or inline) — `ExitCode::SUCCESS` unless any record lamps `Fail`
   (`Lamp::for_record(rec) == Lamp::Fail`), else a non-zero code (test-plan §1; obs-extract C6).
10. **Tests** (`tests/cli_smoke.rs`) — extend the `assert_cmd` smoke (see Test Commands + Acceptance).

## Implementation notes
- **The two unbuilt content bridges are Epoch-10, not here** (research §Graph impact): (1) faithful per-scenario
  emission — `EmissionSpec` carries only a coarse `Signal`, so ch1 emits a generic span/log per phase, NOT each
  scenario's specific incident shape; (2) per-check read-back observed-extraction — ch1 feeds a stringified
  `query_incident_list` as `observed`, not a per-`ExpectedCheck` tool+slice. Both are live-only and are the
  substance of the Epoch-10 MCP-verified proof. Keep the orchestration durable; keep these two steps minimal +
  clearly commented as Epoch-10 enrichment points.
- **CI determinism of the Blocked path:** CI has no `andromeda-pulse-mcp` at the fixed spawn path, so
  `preflight_boot`'s spawn fails → `Blocked` deterministically. The `assert_cmd` test asserts exit 0 + a
  persisted envelope whose `state` is `Blocked` (do not assert a measured verdict — that needs a live Pulse /
  the rmcp stub). The ready-path may be exercised later via the `stub_pulse_mcp` feature-gated bin (the
  preflight chunk's pattern), but that is optional for ch1.
- **No clobber semantics:** `RunReport::write` is `create_new` and `RunsDb.insert` PK is `(run_id, scenario)` —
  the per-run millisecond `run_id` makes both safe; `suite` writes the report ONCE with all records (not per
  scenario), and inserts one db row per scenario.
- **Empty-`expected` scenarios** (constellation / report-render / cadence / degraded / project-context) →
  ManualCheck record built by direct `RunRecord` construction (`verdict: None`); confirmed representable today
  (`Lamp::for_record` lamp.rs:44) — do NOT add a core constructor (zero model change holds).
- **Verdict/error wall:** every seam returns typed `Err` for harness faults only; collapse to anyhow at the CLI
  edge; never treat a `Blocked`/`Fail` verdict as a Rust error (arch §Conventions; all seam error enums).
- **No new inbound listener** (scope law): the CLI is a gRPC/MCP client + artifact reader/writer; the only bind
  remains the Epoch-4 `:4317` port-occupier fault.
