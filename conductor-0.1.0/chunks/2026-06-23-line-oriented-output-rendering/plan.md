## Goal
Give the `conductor` CLI a presentation layer that renders its already-typed outcomes as human-readable
terminal output, using three new crates behind a thin render seam in `conductor-cli`: **owo-colors** (colored
status lines), **indicatif** (run progress), **comfy-table** (tabular results + the coverage matrix). This is a
render-only chunk — it reads existing types (`Lamp`/`Verdict`/`ReportState`, `RunRecord`, `ReadyState`,
`coverage_matrix()`) and adds **zero** verdict/report-model logic (per arch §Established Decisions
zero-model-change; design/a11y/tests all confirm "render reads only"). The single source of status truth is
`conductor-core`'s `Lamp` (lamp.rs:15 — its own doc: _"reused by the Markdown report, coverage matrix, cli, and
desktop"_); ch3 colorizes `Lamp::status_prefix()`/`label()` over the verdict-first `Lamp::for_record` projection
and never reclassifies (design §Color Palette; lamp.rs:37).

The defining invariant is **status is never color-alone** (CLAUDE.md universal · design §Color Palette
Anti-Patterns · a11y §11 §Universal · layouts §cli IA): the ASCII prefix `[PASS]`/`[FAIL]`/`[HOLD]`/`[MANUAL]`/
`[RESIDUAL]`/`[BLOCKED]` is ALWAYS present; color is a tty-gated overlay (owo-colors `supports-colors`:
NO_COLOR / TERM=dumb / non-tty all strip it transparently). Piped / agent output therefore carries no escape
bytes (the full agent-mode log format is ch5; the interactive operator-pause is ch4 — both out of scope here).

Two P4 user decisions shape the surface: **(D1)** add a new **`conductor coverage`** verb that renders the
static 60-P-ID matrix (`coverage_matrix()`: P-ID/title/category/mode) as a comfy-table and, with `--write`,
regenerates `coverage-matrix.md` at the repo root (closes the carried follow-up; introduces a layout-templates
amendment — precedented by ch2's `preflight` verb, and supersedes the arch extract's "no new verb in Epoch 8"
inference). **(D2)** switch `conductor report` stdout from raw Markdown to the colored comfy-table results view
(with a `Run report <id>` header), while the on-disk `<run_id>.md` artifact stays Markdown (unchanged).

2. **Build the render seam** `crates/conductor-cli/src/render.rs` (new module; register in `main.rs`):

   - `status_line(&RunRecord)` — the colored sibling of `print_record`: `{Lamp::status_prefix()} {scenario}`,
     prefix colored by `lamp_color`, ASCII prefix always present.
   - `results_table(&[RunRecord])` — comfy-table, 6 columns `P-IDs · scenario · state · slo_tier · latency_ms ·

## Implementation notes
- **Let the libraries gate, don't hand-roll.** owo-colors `if_supports_color(Stream::Stdout|Stderr, …)` already
  honors NO_COLOR / TERM=dumb / tty; indicatif's stderr draw target already hides on a non-tty. Don't add bespoke
  `is_terminal` branches beyond what they expose (ch4/ch5 own the interactive + agent-mode paths).
- **comfy-table truncation is the trap.** The scenario column (and the `[BLOCKED]` token) must render un-truncated,
  or the cli_smoke substring assertions break — use dynamic content arrangement with the name column unconstrained
  and verify on a narrow/non-tty width (where terminal-width detection returns a default).
- **D2 token preservation.** `report`'s new stdout MUST keep the literal `Run report` and `[BLOCKED]` strings
  (cli_smoke.rs:122) — put them in the header + the table's state cell respectively.
- **Small, deliberate duplication.** `conductor-report`'s `wire()`/`latency()`/`fingerprints()` helpers are
  private; the cli render duplicates the tiny serde-spelling helper rather than widen `conductor-report`'s API
  (keeps this chunk zero-report-change). Flag a DRY follow-up if a shared row projection is later wanted.
- **D1 is a spec amendment.** The new `coverage` verb means a layout-templates amendment (§cli Primary screens
  += `conductor coverage`) at wrap — same shape as ch2's `preflight` addition. The arch extract's "no new verb"
  bullet is superseded by the P4 decision.
- **indicatif + the hold-point.** ch3's spinner only covers the run loop and clears on completion; the
  paused-count "stops in place" hold mirror (design §Motion / Brand Identity) is ch4 (operator-pause) — do not
  build the freeze behavior here.
