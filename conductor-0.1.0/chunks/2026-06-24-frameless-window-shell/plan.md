## Goal

`init_observability(…, ObsSink::Stderr)` and exits; the only dep is `conductor-core`; there is no
`tauri.conf.json`, `capabilities/`, `tauri`/`tauri-build` dep, or `build.rs`). This chunk gives the optional

whole surface, a custom **drag-region titlebar** rendered as a `banner` landmark with native minimize/close
controls, and a **deny-by-default** capability ACL — all over the existing React 19 / Vite 8 / Tailwind v4.1
`ui/` skeleton (per frontend.md + design-system.md expression 0.3 + layout-templates §Component — Header).

`logs/conductor-tauri.jsonl` (obs-plan §3 sink table). The agent-mode-logging chunk already parameterized
`init_observability(…, sink: ObsSink)`; `ObsSink::AgentFile(PathBuf)` already does exactly the needed

code-graph shows `ObsSink` is referenced only at `conductor-cli/src/main.rs:9,44,46,48` outside core, so the

Engine/seam model is untouched: `Verdict`/`ReportState`, the scenario model, the journal/envelope schema, and

## Implementation notes
- **`generate_context!` ⇒ frontend-before-cargo (order-critical).** `tauri.conf.json` `build.frontendDist`
  (`ui/dist`) is resolved at compile time; with `ui/dist` absent, compiling `conductor-tauri` (and thus
  `cargo nextest --workspace` / `clippy --workspace`) fails. Build the frontend first (Step 9). A bare
  `cargo build` does NOT run `beforeBuildCommand` (only the Tauri CLI does), so the build-order wiring in
  agent-run + CI is load-bearing, not cosmetic.
- **Supply-chain is the main risk.** Expect `cargo deny check licenses` to fail first (the Tauri tree adds
  licenses beyond the 6 allowlisted — likely MPL-2.0, ISC, BSD-2-Clause, Unicode-DFS-2016, and many `windows-*`
  crates). Resolve by allowlisting each license actually present, with a justifying comment per the file's
  mandate; same for any advisory. Run BOTH `cargo audit` and `cargo deny check` (audit exit 0 ≠ deny green).
- **D1 rename is independent — verify it green first** (Step 2) so a Tauri build hiccup never masks an obs/cli
  regression. The rename is pure renaming (no behavior change); the file sink already inherits processor
  redaction (obs.rs:500) and falls back to stderr (obs.rs:517).
- **Tauri runtime stays the shell's concern** — this chunk wires NO core timeline/engine work into the Builder,
  so the core `current_thread` runtime and Tauri's event loop never meet yet (architecture §Async Runtime Flavor).
- **D3 icon** — provide a minimal placeholder icon set; `generate_context!`/`bundle.icon` expects one. Mechanical.
- **Tauri 2 capability identifiers** — verify the exact `core:window:*` permission identifiers against the
  installed Tauri 2.10.x ACL (the names are version-stable but confirm at implement; deny-by-default means an
  over-broad permission is a defect).
