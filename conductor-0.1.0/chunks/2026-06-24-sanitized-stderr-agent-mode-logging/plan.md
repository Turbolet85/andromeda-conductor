## Goal

The final Epoch-8 chunk makes `conductor-cli` cleanly agent-drivable and pipe-safe by wiring three tied
pieces over the obs/error layer the `2026-06-15-structured-logging-stack` + `…-log-error-boundary-redaction`
chunks already built (per obs-plan §3 + security-plan §Error Handling). **Zero engine/seam model change** —
this is cli-edge + one parameterized core obs entry point.

(1) A global **`--agent-mode`** flag that selects the self-obs **dual sink** (obs-plan §3): in agent mode the
`tracing` JSON stream routes to a file `logs/agent-latest.jsonl` (no self-obs JSON on stderr); in dev mode it
stays on stderr (the existing behavior). The flag also **forces the Headless operator-pause resolver
regardless of isatty** — the folded PREREQ, closing the release-gate-never-blocks invariant that
`2026-06-23-isatty-gated-operator-pause` left gated on `IsTerminal` only.

(2) A **sanitized `error:` / `hint:` edge** at `conductor-cli/main.rs` — the `error: <short>` + `hint: <fix>`
shape design-system §cli "Error output" specifies, built on the existing `conductor_core::sanitize_error`
(Display-only, host-path-redacted, single line), whose doc comment explicitly defers this wrapping to "Epoch
8". A new `--debug`/`-v` flag is the *only* path that surfaces the full error chain (to stderr only, never to
artifacts), per security-plan §Error Handling §334.

(3) The self-obs file sink **inherits the existing processor-stage redaction** (field-allowlist +
`redact_value`) so `logs/agent-latest.jsonl` cannot leak host paths or internal struct names (obs-plan §6), and
it remains a **distinct artifact + schema** from the per-run emission journal `runs/<run_id>.jsonl`
(test-plan-amendments §7 — the two must never be conflated).

## Implementation Steps

1. **Parameterize the core obs sink (`conductor-core`).** Add `pub enum ObsSink { Stderr, AgentFile(PathBuf) }`
   and change `init_observability(default_service_name, run_id, sink: ObsSink) -> ServiceIdentity`
   (obs.rs:57). For `AgentFile(path)`: create the parent dir + open the file (create+truncate — the file holds
   the *latest* invocation's stream) and build the subscriber over a `Mutex<File>`-backed `MakeWriter` (mirror
   the existing `SharedBuf` `Write + MakeWriter` test pattern at obs.rs:256; `std`-only, no new crate). **Init
   stays infallible:** an `AgentFile` open failure falls back to `Stderr` (never panics/Errs at startup).
   `build_subscriber<W: MakeWriter>` is already generic (obs.rs:70) — no layer/redaction change; the file sink
   inherits `JsonObsLayer`'s allowlist + `redact_value`. Export `ObsSink` from lib.rs.

2. **Add the global flags (`cli.rs`).** On the top-level `Cli` struct add
   `#[arg(long, global = true)] pub agent_mode: bool` and
   `#[arg(long, short = 'v', global = true)] pub debug: bool`. (Global so they attach to any verb.)

3. **Reorder + wire the bootstrap (`main.rs`).** Parse `Cli` **before** `init_observability` (safe — clap exits
   via its own error path on bad args, never panics; the panic hook still covers all post-init logic). Resolve
   `agent_mode = cli.agent_mode || std::env::var_os("CONDUCTOR_AGENT_MODE").is_some()` (read-only trigger env —
   see Note D). Pick the sink: agent mode → `ObsSink::AgentFile(agent_log_path()?)`, else `ObsSink::Stderr`.
   Then `init_observability("conductor", Some(run_id), sink)`.

4. **Agent-log path helper (`paths.rs` or a small cli helper).** `agent_log_path() -> anyhow::Result<PathBuf>`
   resolves `CONDUCTOR_RUNS_DIR` (default `runs`) under cwd via `conductor_core::resolve_under` (the same guard
   `resolve_handle` uses), then returns its **sibling** `…/logs/agent-latest.jsonl` (`runs_dir.parent()` +
   `logs`). Decision D3 (sibling-of-runs; moves with the runs override).

5. **Rewrite the anyhow edge (`main.rs`).** Replace `eprintln!("error: {}", sanitize_error(&*err))` with the
   `error:` / `hint:` formatter:
   - `error: {sanitize_error(root)}` (the existing sanitized single line);
   - `hint: {hint_for(&err)}` — **category-mapped** (Decision D2): downcast the error / inspect its root to a
     small high-value set — scenario-not-found → "list scenarios in scenarios/, or pass a P-ID like P-009";
     manifest-missing → point at `contracts/mcp-contract.toml` / `CONDUCTOR_CONTRACT_MANIFEST`; `:4317`
     egress-refused → "ensure a Pulse instance is listening on 127.0.0.1:4317"; **fallback** → "re-run with
     --debug for the full error chain". (Match on `err.root_cause()` downcast to `conductor_core::CoreError`
     where typed, else a narrow context-string check — keep the set small.)
   - When `cli.debug` is set, additionally print the full `{:?}` anyhow chain **to stderr only** (operator
     opt-in; never to logs/`runs.db`/report). Default mode never prints a trace (security-plan §334).
   - Color: tty-gated on `std::io::stderr().is_terminal()` (+ `NO_COLOR` unset, `TERM != dumb`), mirroring
     `render::stdout_color()` but for stderr — `error:` red / `hint:` dim; **piped/agent stderr is plain ASCII**
     (the `error:`/`hint:` labels are the color-independent signal — never color-alone, design-system §cli).

6. **Force-Headless override (`pause.rs`).** Change `select(spinner: Option<ProgressBar>, agent_mode: bool)`.
   Factor a pure `fn resolve_kind(agent_mode: bool, stdin_tty: bool, stdout_tty: bool) -> Kind` (the
   `*_styled(color: bool)` testable-core pattern): `agent_mode || !stdin_tty || !stdout_tty → Headless`, else
   Interactive. `select` reads the real `IsTerminal` then delegates. Update the existing
   `select_off_tty_is_headless` call; add `select_agent_mode_is_headless` + `resolve_kind` truth-table tests
   (incl. agent_mode=true with both ttys=true → Headless — proving the override matters without a pty).

7. **Thread the bool (`commands/run.rs`, `commands/suite.rs`).** Pass `agent_mode` into `select(...)`. The bool
   reaches the commands from `dispatch` (add it to the verb handlers' args, sourced from the parsed `Cli`).

8. **Keep the Tauri stub compiling (`conductor-tauri/src/main.rs`).** Update the call to
   `init_observability("conductor-tauri", None, ObsSink::Stderr)` (Decision D1 — one honest entry point; the
   Tauri backend's own `logs/conductor-tauri.jsonl` file sink is Epoch-9, out of scope here).

9. **Surface agent-mode on the harness (`scripts/agent-run.{sh,ps1}`).** On the optional scenario leg, pass

10. **Tests** (see Acceptance + Test Commands): obs file-sink unit (core), `select`/`resolve_kind` + error-edge

## Implementation notes (optional)
- **D1 — one obs entry point.** `init_observability` gains the `sink` param (both cli + tauri callers updated)
  rather than a parallel `…_with_sink` fn — honest single entry, and Epoch-9 Tauri will want its own file sink
  through the same door. Tauri's change is a trivial `ObsSink::Stderr`.
- **D2 — category-mapped hints + fallback** (user-decided P4). Keep the mapped set SMALL + high-value; the
  generic `--debug` pointer is the fallback. Match on `err.root_cause()` downcast to `CoreError` where typed;
  avoid brittle full-string matching.
- **D3 — agent-log path = sibling of `runs/`** (user-decided P4): `runs_dir.parent()/logs/agent-latest.jsonl`,
  resolved through `resolve_under` (never raw-join — security-plan §Input Validation). This is the CI
  artifact-upload path (obs-plan §509).
- **D4 — no `unsafe std::env::set_var` (justified deviation from obs-plan §3 "sets CONDUCTOR_AGENT_MODE=1").**
  Edition-2024 makes `set_var` `unsafe`; instead `CONDUCTOR_AGENT_MODE` is a **read-only trigger env**
  (agent-run scripts export it OR pass `--agent-mode`); main computes `agent_mode = flag || env`, never writes
  it. Same observable mode, no `unsafe`, more testable. Record in the chunk report for wrap's drift check.
- **Dev-mode is JSON-to-stderr, not pretty-print** (obs-plan §3 says "pretty-print in dev" but the
  structured-logging-stack impl emits JSON to stderr in both modes; pretty-print was never built and is out of
  scope). Agent mode adds only the *file* redirection. The `error:`/`hint:` summary still goes to stderr in
  BOTH modes — so an agent reads a clean stderr (error summary only) + the full JSON stream from the file.
- **Ordering safety:** parse-before-init is sound because clap exits via its own non-panicking error path on
  bad args; `mint_run_id` + the panic hook still bracket all real logic. The `current_thread` runtime spawns no
  workers, so the early env read is single-threaded.
- **No new deps** — `Mutex<File>` MakeWriter is `std`-only; reuse owo-colors' tty gate, not `anstream`
  (design.md synthesis note: the distiller's `anstream`/`anstyle` suggestion is rejected — the codebase uses
  one shared `stdout_color()` `IsTerminal` bool).
