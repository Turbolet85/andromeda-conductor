## Goal
Build the reusable, presentational React 19 primitives the later Epoch-9 views compose — the **six status-lamp variants**, an **operator-pause dialog scaffold**, and an **operator-checklist primitive** — design-token-driven and accessible, with no live data wiring (per scope.md + arch §Inherited Defaults Frontend).

The lamp set is the desktop projection of `conductor-core`'s **single lamp-truth** (`lamp.rs` — its module doc already names "desktop" as a reuse target): the six `Lamp` variants `Pass`/`Fail`/`Hold`/`Manual`/`Residual`/`Blocked`, each rendered as token-color **+ text label + glyph** (the universal *never-color-alone* invariant; design-system §Color Palette/§Iconography, a11y-plan §6/§11). The TS lamp labels/anchors mirror `lamp.rs` spellings verbatim (`Pass`/`Fail`/`HOLD`/`Manual`/`Residual`/`Blocked`; `[PASS]`…`[BLOCKED]`) — the verdict-first projection (`(state,verdict)→Lamp`) stays in Rust; this chunk's lamp takes a `Lamp` value directly (the report/coverage VIEWS that project records are ch6/ch7).

The dialog scaffold is built on `@radix-ui/react-alert-dialog` (P4 user decision) — `role="alertdialog"` + a required Proceed/Abort action, focus-trapped, Escape-escapable, focus-restoring (Radix defaults; a11y-plan §4/§5) — the base the ch8 operator-pause go/no-go consumes. The checklist primitive renders the ManualCheck/DriveObserve operator-checklist rows (ch7's base). All three follow the established **use-the-Radix/cmdk-primitive-directly + per-component `.css`** pattern (frontend.md 2026-06-26 learning; `ScenarioPicker`/`Titlebar` precedent), bind tokens by name, and bake accessibility in at the component level. ## Component API contracts
The prop shapes ch6/ch7/ch8 consume — WHAT, not HOW (/implement writes the bodies). Strict TS, no `any`/`as`; default-export functional components; controlled/presentational (no internal data fetch).
- **`Lamp` / `LAMP_META`** (`lamp.ts`) — `type Lamp = 'Pass'|'Fail'|'Hold'|'Manual'|'Residual'|'Blocked'`; `LAMP_META[lamp] = { label; prefix; token; glyph }` mirroring `lamp.rs`.
- **`StatusLamp`** — `{ lamp: Lamp; size?: 'sm' | 'md' }`. Renders glyph + label (`LAMP_META[lamp].label`); `role="status"` + `aria-label` = the label. Pure.
- **`OperatorPauseDialog`** — `{ open: boolean; onOpenChange(open: boolean): void; title: string; body: ReactNode; proceedLabel?: string; abortLabel?: string; onProceed(): void; onAbort(): void; allowNoGo?: boolean }`. Wraps Radix `AlertDialog`; the `open`/`onOpenChange` contract lets ch8 drive it from a `HoldPoint` (whose `allow_no_go` maps to `allowNoGo`). No command wiring here.
- **`OperatorChecklist`** — `{ items: ChecklistItem[]; onToggle(id: string, checked: boolean): void }` where `ChecklistItem = { id: string; induced: string; observation: string; checked: boolean }`. Controlled; native-checkbox rows with `aria-checked` + Space-toggle.

## Implementation notes
- **Lamp spellings are a hard contract** — `HOLD` is uppercase (matches `Verdict::CalibrationRegion.label()`), the rest TitleCase; the `[…]` ASCII anchors are the testing.md E2E selectors (ch9) — do not re-spell or localize.
- **No new design tokens** — all six lamp tokens + `--color-raised-3`/`--border-subtle`/`--color-focus`/`--radius-*`/`--motion-micro`/`--ease-quiet` already exist in `tokens.css`. If a glyph needs a size not in the scale, prefer an existing `--space-*`/`--radius-*` token over a literal.
- **Reduced-motion is already global** (`tokens.css` `* { animation:none; transition:none }`) — components need no per-file `motion-reduce:` handling for the basic transitions (may still use it for component-specific cases).
- **Radix dialog API is `#[non_exhaustive]`-style compositional** — compose `AlertDialog.Root/Trigger/Portal/Overlay/Content/Title/Description/Action/Cancel`; the controlled-open prop lets ch8 drive it from a hold-point. Keep the scaffold presentational (open/onOpenChange + slots), not wired to any command.
- **Strict TS** — typed props, no `any`/`as` (global rule); default-export functional components per the `ScenarioPicker`/`Titlebar` convention; no `@/` path alias (relative imports).
- **App.tsx untouched** — the live run surface (Channel/run-state) is out of scope; the gallery is a separate DEV mount in `main.tsx`.
