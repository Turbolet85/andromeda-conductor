## Goal
Build the desktop **Coverage-matrix view** — the dense, single-row-per-P-ID surface listing all 60 Pulse
capabilities (P-001..P-060) that is *the* mission-control instrument of Conductor's GUI (design §Brand
Identity / §Component Patterns §3), and the desktop twin of the CLI `coverage` table + the `coverage-matrix.md`
definition-of-done artifact. It is the first ch5-primitive-consuming *view* of Epoch 9.

The classification is **single-sourced** from `conductor-core::coverage_matrix()` (the `&'static [CapabilityRow; 60]`
at `crates/conductor-core/src/coverage.rs:60`, the code-native source of truth) via a thin read-only
`coverage_matrix` Tauri command — the view never re-authors the 60 rows in TypeScript (the mirror-don't-re-spell
rule the `lamp.ts` pattern is built on; arch §Conventions). Each row shows P-ID · title · category · coverage
mode, with the per-mode tally header (`60 · 40 auto · 13 drive+observe · 7 static-only`, matching
`conductor-report` `coverage.rs` `summary_line`).

Per the P4 decision (data-source AskUserQuestion → **classification + defer live join**): this chunk **reuses the
