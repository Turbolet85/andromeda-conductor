## Goal
Stand up the desktop accessibility + GUI-integration **test harness** for the optional Tauri 2 webview and land
the three batches of GUI-integration tests deferred from Epoch-9 ch4/ch7/ch8 — the home the route always
reserved for them (per test-plan §5 Integration + a11y-plan §3.5 Bootstrap phases). This is the **SETUP** chunk:
it erects the tooling and lands the *deterministic, CI-safe* test legs; the exhaustive per-path axe/contrast/
keyboard verification sweep + NVDA/VoiceOver manual spec are the NEXT chunk (*Desktop a11y verification*), and
the always-on a11y CI gate is the Epoch-10 route chunk *A11y CI gate + violation JSON*.

Per the P4 decision **"Deterministic now, webview deferred"**: the harness splits along the determinism + host
constraints. The **mock-runtime leg** (`tauri::test`) is display-free, Windows-runnable, and deterministic — it
lands now: the synchronous command contracts (`coverage_matrix`/`run_report`/`stop_run`/`resolve_operator_hold`)
+ the test-plan **Path 7** cross-surface parity asserted on the *persisted* `runs.db`/journal envelope (waiting
on the terminal completion signal, never a frame-sequence or `sleep`). The **real-webview leg** (axe-core +
colorjs.io + WebdriverIO keyboard over `@crabnebula/tauri-driver`) needs Linux+xvfb + a live Pulse (a11y-plan
§3.5, a11y.md) — it is **authored + typecheck-clean but display-gated** on this Windows/no-display host, run on
the Linux+xvfb operator/Epoch-10 CI matrix, and every gated leg is surfaced with its reason (never silently
skipped — tests §11, obs). conductor-tauri is a leaf crate (code-graph: outbound to core+run only, zero
inbound), so all of this is additive with zero cross-crate blast radius and **zero engine/seam model change**
(arch boundaries).

## Implementation notes
- **Path-7 hermetic-Blocked wrinkle (edition-2024):** forcing Blocked needs the read-back path unreachable. `cli_smoke` sets `ANDROMEDA_PULSE_DATA_DIR=pulse;injection` on a *child* `Command` (`.env()`, no process-global mutation). In-process, `std::env::set_var` is `unsafe` in edition 2024 (security.md review flag). Resolve in /implement by (a) a single reviewed/justified `unsafe` env-set in a serialized test, OR (b) driving the same `conductor_run` path the command runs rooted at a `TempDir` passed directly (avoiding env), OR (c) a subprocess. `Preflight{ready:false}` is NOT constructible outside conductor-run, so don't try to build it in conductor-tauri — go through `conductor_run::preflight`.
- **`tsc --noEmit` scope:** `npm run build` typechecks every file in the app `tsconfig` include — keep the wdio e2e specs in `test/` with their own tsconfig (or `exclude` them from the app build) so webdriverio/axe globals don't leak into the app type-graph and break the green build.
- **Inline-not-`tests/`:** conductor-tauri is a bin; its commands are crate-private. Add tests inline (`#[cfg(test)]`), not under `tests/` (which only sees a crate's public lib API) — mirrors the existing `pause.rs` tests.
- **Don't widen the gate:** the real-webview leg must not enter `agent-run run` / the always-on CI Rust job (no display/Pulse → guaranteed red). The always-on a11y CI gate is the Epoch-10 route chunk *A11y CI gate + violation JSON*.
- **tauri `test` feature unification:** adding `features=["test"]` in `[dev-dependencies]` unifies onto the `[dependencies]` `tauri` for test/dev builds — expected; it does not change the release bin.
