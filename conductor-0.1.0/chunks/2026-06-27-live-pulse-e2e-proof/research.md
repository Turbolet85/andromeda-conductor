## Patterns detected
- **Verdict/error wall** (`preflight.rs:172`, `:203`): `run_preflight`/`preflight_boot` return `Ok(ReadyState)` even when Blocked; only a genuine harness fault is `Err`. The canary bridge preserves this — a failed emit/poll/fidelity ⇒ `CanaryOutcome::Failed` → Blocked, never panic/`Err`.
- **Fingerprint = pure function of content** (`exception.rs:115`): `fingerprint(&spec)` is what Conductor expects Pulse to derive; the canary computes it locally and asserts it appears in read-back `fingerprint_refs` — the stable, non-scrubbed identity.
- **Hardened sidecar spawn** (`client.rs:45–49`): `ReadbackClient::connect` → `spawn::resolve_data_dir` (injection-reject) + `.env`; the bridge reuses it, adds no spawn code.
- **Coarse-emit shape** (`lib.rs:182–206`): per-phase `TraceEmitter`/`LogsEmitter` signal — the template the faithful per-family dispatcher replaces.
- **Raw-shape stub fidelity** (`common/mod.rs`, `stub_pulse_mcp.rs`): both stubs emit Pulse's un-enveloped `result`; extending them for `fingerprint_refs` keeps the CI spine faithful (the rmcp stub once hid the bug).

## Conventions to follow
- **`std::time` stamps** — `now_ms`/`now_rfc3339` (`lib.rs:240`, `conductor_core::now_rfc3339`), never tokio's virtual clock.
- **Bounded `tracing` spans** — `verify.readback.*` (preflight.rs:84) + `emit.batch` (obs §4); instrument the canary round-trip + bounded poll on existing low-cardinality names (NOT per-marker).
- **`CONDUCTOR_PREFLIGHT_TIMEOUT`** (default 30s, arch §Occupied Resources) bounds the canary ingest poll; the storm (≥5 identical-fp exceptions) must complete + read back within it.
- **Redaction at the edge** (preflight.rs:92,119; `redact_value`) — data-dir + error strings scrubbed before they enter `ReadyState`/precondition strings.
- **Scenario evaluation is single-read-back, no per-check scoping** (testing.md 2026-06-22) — faithful extraction feeds the existing `evaluate_check`→`classify` unchanged; per-family `expected` already authored (Epoch 7).
