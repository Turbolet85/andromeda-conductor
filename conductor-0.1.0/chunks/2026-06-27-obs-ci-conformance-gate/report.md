## Deviations from intent
- **Concretized check (c)'s stderr leg (strengthening, spec-faithful).** The plan's step 2(d) said grep "the file (and the producer's captured stderr, *if captured*)". The dogfood made it necessary + concrete: an **unstructured panic** (a bypassed `std::panic::set_hook`) is written by the default handler to **stderr, not the JSON file sink** — so a file-only grep would miss the exact failure the zero-panics gate guards. In scope (`ci.yml` only). Not a divergence from the spec; a divergence toward it.
