## Deviations from intent

1. **`tests/readback.rs` pins key SETS, not the log LINE.** The plan asked for "a stub-driven assertion that the key-set line is produced". Asserting a `tracing` line needs `tracing-subscriber` as a `conductor-verify` dev-dep; `Cargo.toml` is not in research's Files-to-modify, so that edit was out of scope. Implemented the in-scope equivalent: `the_read_back_key_sets_are_pinned_as_the_live_diff_baseline` commits the expected key sets, which is what the live diff compares *against*. Justified: same intent (make a live divergence detectable), no scope breach, and the pin proved its worth immediately — the live run matched it exactly.
2. **The timeout wrapper is proven by computation, not by a timeout firing.** Forcing a long run needs a live Pulse. Verified the budget function's three behaviours directly and confirmed `boot` ran to completion unkilled on both shells. Justified: the alternative is unrunnable in this environment; recorded as `unrunnable-here` above rather than claimed.
3. **The live leg found a different blocker than the plan predicted, and the plan's predicted outcome did not occur.** Plan expected "all three arms blocked, F10 confirmed live". Actual: all three arms blocked, **F10 NOT confirmed** — an upstream gate (the 3,600s bootstrap window) prevents any incident from forming under any cwd, so the workspace-key axis was unexercised for the second consecutive attempt. Justified as a faithful measurement: the chunk's value did not depend on which way it went, and the result is strictly more informative than the predicted one (it identifies the blocking mechanism and its constant, where 2026-08-10 recorded only the symptom).
4. **A fifth operator-recipe item was discovered mid-leg.** `ANDROMEDA_PULSE_MCP_ENABLED=true` must be set in Conductor's own environment (the sidecar inherits it; `spawn.rs` passes only the data dir via `.env(...)`). The recorded recipe lists four items. The first arm-1 attempt ran without it, measured the read-back-unreachable path, and was discarded and re-run.
