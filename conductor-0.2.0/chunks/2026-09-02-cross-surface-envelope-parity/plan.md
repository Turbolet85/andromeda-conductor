## Goal

Three deliverables, two of them matrix-claiming.

**(1) v2-25 — make cross-surface parity an actual comparison.** A parity-labelled test already exists
(`conductor-tauri/src/commands.rs:469-509`, `path7_tauri_persists_the_same_blocked_envelope_as_the_cli`), but
research measured that it **never runs the CLI**: it drives the Tauri-side composition into its own `TempDir`
and asserts `state`/`verdict`/`seed`/`scenario` against hand-written expectations, with a comment asserting
that "cli_smoke proves" the other side. Two tests each matching their own expectation is not the two surfaces
matching each other, and it is not what v2-25's acceptance asks for ("…write identical verdict, state and seed
**to the same runs.db**"). test-plan §5 mandates the driver pair and the medium: the `tauri::test` mock-runtime
run and the `assert_cmd` CLI subprocess run, **both pointed at one `assert_fs::TempDir` `runs.db` via
`CONDUCTOR_RUNS_DIR`**. This chunk builds that comparison and compares the two envelopes field-by-field, with
the wall-clock/identity fields explicitly excluded (per obs-plan §4/§5 — `run_id`, `journal_emitted_at`,
`read_back_observed_at`, `latency_ms` are per-run values, so a whole-row equality assertion would contradict
the SLO measurement definition).

**(2) CARRY-2 — give the desktop load-envelope banner its first rendered-DOM proof.** The spec already exists
and already asserts the label (`accessibility.e2e.ts:270-280`); it `this.skip()`s because the journal-only
fixture seed cannot create a `run_envelope` row — that is a `runs.db` table, not a journal line. The work is to
supply the SUBJECT through a production writer. Operator-selected (P4, 2026-09-02): **committed subject +
optional live pass** — the deterministic seed is what makes the routine `--e2e` arm assert, and it is required
regardless because a live run's artifacts land in gitignored `runs/`; the live GUI leg is strengthening
evidence that does not block the chunk.

**(3) v2-28 — reconcile the stale rmcp wording**, over the two in-repo sites this chunk owns
(`contracts/mcp-contract.toml:5`, `crates/conductor-verify/src/lib.rs:3`) plus the per-site classification pass
