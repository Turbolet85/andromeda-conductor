## Goal

`cargo mutants -p conductor-tauri --test-tool=nextest` plans 43 mutants and tests **0** — exit 4,
`cargo test failed in an unmutated tree` — so the epoch's most-touched crate (13 of 22 changed source
files) carries no test-quality measurement at all. The invocation is not the defect: the audit's own
`run-mutants.sh` already passes `--test-tool=nextest` and a gitignored `--output`, which is the full
test-plan §4 run discipline. The **unmutated-tree baseline itself fails**, because one test reaches a
build artifact that no Cargo dependency edge guarantees.

The chunk makes that binary a declared build-graph fact and then collects the score. Research measured
the fix available at zero cost: the parity test
`path7_the_two_surfaces_write_an_equal_envelope_into_one_runs_db` uses **no `tauri::*` item** — its
"Tauri arm" calls `conductor_run::{preflight, drive_run}` directly — and every crate it imports is
already a dependency or dev-dependency of `conductor-cli`, the package that declares
`[[bin]] name = "conductor"`. Relocating it there makes Cargo build the binary for the test target and
set `CARGO_BIN_EXE_conductor`, which is what `assert_cmd`'s own panic text, test-plan §11's
own-test-binary remedy and `.claude/rules/testing.md:52` each prescribe. Both directions are measured
(research.md §The two live probes): with the artifact absent, `-p conductor-tauri` panics
`CARGO_BIN_EXE_conductor is unset` while `-p conductor-cli` rebuilds the binary and passes 36/36.

With the baseline passing, the tier runs and the chunk's second half begins: every NAMED survivor ends
killed or classified accepted-deliberate against a cited rule (test-plan §10 — never a numeric
threshold), with the verdict read from the `mutants.out/` tallies, never the exit code (test-plan §4).
