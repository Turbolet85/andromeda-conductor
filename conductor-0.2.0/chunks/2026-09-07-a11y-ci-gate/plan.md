## Goal

Turn the existing routine a11y arm into a real CI gate: a named job in `.github/workflows/ci.yml` that runs
the WebdriverIO + tauri-driver session with **no live Pulse**, fails the build on any WCAG violation, and
uploads a redacted, service-tagged violation JSON conforming to the obs envelope. The specs, the driver stack
and the assertions already exist — what is missing is the CI arrangement, the emission, and two structural
properties without which the gate would be hollow.

Two of those properties are the substance of this chunk, both established by measurement rather than
assumption. First, **the gate cannot key on an exit code**: `verification-harness.md:58` measured that
`run --e2e` returns 0 both when every spec asserted against a live WebView2 session and when
`CONDUCTOR_MSEDGEDRIVER` was unset and the leg never started, so the gate must assert the runner's printed
spec tallies and reconcile them against the expected-skip set (per a11y-plan §11 Anti-Patterns → CI and
test-plan §6, where a context-skip is never a pass). Second, **the unset-handle skip must not stay green in
CI**: the skip is `process.exit(0)` at `wdio.conf.ts:269`, deliberate and correct for a dev host, so CI gets
an ADDED strict arm rather than a relaxed guard (per security-plan §Security Anti-Patterns → Input, which
forbids weakening the `isFile`/metacharacter guard to achieve redness, and architecture §Occupied Resources —
Environment variables, which makes the change an amendment rather than a silent swap).

The chunk also discharges the five CARRYs folded at promotion, and records one honest boundary: the
**Operable half of a11y-plan §11 stays out of the gate**. Measured in P3, the routine arm carries zero
`browser.keys` calls — all keyboard, focus-trap and restoration coverage lives in `operator-hold.e2e.ts`, the
`driven` suite, which test-plan §11 and architecture §CI/CD both bar from CI. Operator-selected: record the
carve-out rather than add routine keyboard specs, because CARRY 3(2)'s sequential-focus defect is open and
unmeasured, so such specs would gate on a known-red subject.
