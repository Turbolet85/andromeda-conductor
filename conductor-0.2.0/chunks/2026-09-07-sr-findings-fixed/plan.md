## Goal

The a11y CI gate shipped one chunk ago and its first run went red. This chunk owns that red, closes the three
measured screen-reader findings it inherits, and — on the operator's P4 ruling — extends the routine arm with
the hold-free half of the Operable set so `v2-24` can finally be claimed.

The CI failure is wiring, not mechanism. `ci.yml:258` builds `CONDUCTOR_MSEDGEDRIVER` from
`${{ env.EDGEWEBDRIVER }}`, and GitHub's `env` context holds only what a workflow/job/step declared — never a
variable inherited by the runner process — so the expression expanded empty, the handle became the literal
`\msedgedriver.exe`, and `nativeDriver()`'s `isFile` check correctly rejected it. Under `CONDUCTOR_A11Y_STRICT`
the strict arm then exited 1, exactly as designed. Nothing in the guard is at fault and nothing in it may move
(security-plan §Input Validation → `CONDUCTOR_A11Y_STRICT`; a11y-plan §11 CI): the fix makes the value
resolvable, upstream of the guard.

A second defect surfaced during the fold's re-verify and is in scope because it cost the diagnostic capability
the gate exists to provide: the step prepends `$PSNativeCommandUseErrorActionPreference = $true`, which turns
the non-zero `& npm run a11y` into a terminating error at `agent-run.ps1:270` — before the deliberate
`Get-Content $a11yLog` at `:273`. The job log therefore carried one line and none of wdio's output, including
the strict arm's own explanatory message. `agent-run.sh:247` survives the same failure by `|| e2e_rc=$?`, so
this is also a break in the `.sh`/`.ps1` identical-semantics contract (test-plan §3), visible only under CI.

On the SR side, finding (2) is the load-bearing one: a11y-plan §11 `:516` names it as the reason the Operable
carve-out exists. Research excluded the two leads the CARRY carried — DOM order is already correct
(`Titlebar.tsx:51-58` Minimize precedes `:59-66` Close) and the leg's own attribution to "the picker input at
mount" is unsupported by the code it names — so the holder is genuinely unmeasured and the plan measures
before it remedies.
