## Goal

Make the workspace `cargo fmt`-clean and add the gate that keeps it so. Two halves, neither sufficient
alone: `cargo fmt --check` exits 1 at HEAD over 282 sites in 60 files spanning 8 of the 9 crates, and no
workflow — nor either `agent-run` script — runs rustfmt at all, which is the mechanism by which the tree
rotted unobserved for four days after `rustfmt.toml` landed (2026-09-05, commit `59d5b7c`).

The pass itself is mechanical and its safety is measured, not argued. Parsing the pending diff gives
+1581/−486 lines whose change classes are exactly edition-2024 import re-sorting and expression
re-wrapping, and the load-bearing property — *the pass alters no code, only its layout* — is verified as
**per-file token-multiset identity**: for each of the 60 files the multiset of identifiers, string
literals and numerals on the added side equals that on the removed side (60/60, zero exceptions; 262
distinct string literals per side, none exclusive to either). That single whole-diff invariant is what
keeps a 60-file review tractable, and it is stronger than the byte-identity check the route entry
proposed (research.md §1).

The gate lands in the existing `rust` job — CI's Rust gate, `windows-latest` — which test-plan §9's Lint
row already names as fmt's home beside clippy (`test-plan.md:455`, with the build-failure clauses at
`:477`/`:507`). That row is TARGET state deliberately left standing under the
`2026-09-06-coverage-completeness-gate` narrow ruling: this chunk makes it TRUE rather than retiring it,
and no detector proposal to retire it is to be accepted. Per arch §Established Decisions [CI/CD] the gate
inherits the existing runner model and carries no `continue-on-error` and no `if:`; per a11y-plan §3 and
test-plan §9 it is described by JOB NAME, never by `ci.yml` line coordinates.

   meaningful after the chunk commits), group hunks per file, and for each file compare the multiset of
   identifiers, string literals and numerals on the `+` side against the `-` side. **`cargo fmt --check`
   output prefixes every `+`/`-` with an ANSI colour escape and `git diff` may too — strip ANSI before
   classifying** (measured: a classifier keying on `startswith('+')` returned 0/0 against 282 real
   hunks). Print `token-multiset differences: N` as the last line; exit non-zero when `N > 0`.

3. **Add the gate step to `ci.yml`, job `rust`.** One new step named `Formatting gate (cargo fmt)`

   (rust-toolchain.toml)`, becoming index 2** of that job (which grows 21 → 22 steps). Operator ruling
   at the P5 review; rationale and its honest counter are in Implementation notes. rustfmt resolves
   through the toolchain installed by the preceding step and needs nothing else — no cache restore, no
   node, no bundle, no compile. No `continue-on-error`, no `if:`, no new job, no new runner label, no
   new env handle, no `needs:` edge. The `a11y` and `frontend` jobs are byte-unchanged.

4. **Run the gates** in the `## Test Commands` order and record each reading. The coverage floor is not
