## Implementation notes

- **ONE predicted-equivalent `quantile` mutant, not five — and the difference is floating point, not algebra.**
  Measured under EXACT f64 comparison across 5 profiles × 10 008 points (P5 review, 2026-09-14):
  - `:126:10 <→<=` — **0 differing points: predicted EQUIVALENT.** At `u = 0.5` both branches evaluate to
    exactly `p50` (`u/0.5` and `(u−0.5)/0.45` give exactly `1.0` and `0.0`), so no value assertion can kill it.
  - `:128:17 <→<=` (6 differing points), `:130:17 <→<=` (8), `:130:17 <→==` (1616), `:130:17 <→>` (2012) —
    **predicted KILLS.** The branches are one line *algebraically* but not in IEEE754: `(0.95−0.5)/0.45` is not
    exactly `1.0`, and `(u−0.95)/0.04` and `(u−0.99)/0.01` round differently, so the re-routed branch returns a
    neighbouring float — e.g. `500.0` vs `499.99999999999994` at `u = 0.95`, `2000.0` vs `2000.0000000000014`
