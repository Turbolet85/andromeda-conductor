## Goal

The a11y routine arm has a registered CI job that fails, and the failure is not a defect in the assertion.
The honest-terminal machinery is already shipped and correct: `CONDUCTOR_A11Y_STRICT: '1'` is set on the job
(`ci.yml:383`) and `Assert-A11yVerdict` (`agent-run.ps1:68-100`) asserts the driven-session banner, the
`Spec Files:` failed count and a skip tally against an expected set of two — so a wholly skipped run cannot
read as a pass. The asserting step already carries no `continue-on-error` and no `if:`; all four such keys in
the job sit on diagnostics and uploads. What is missing is not honesty but a **session**: the runner refuses
to give the app a debuggable WebView2 endpoint, so the arm never reaches its assertions (per a11y-plan §11
Anti-Patterns → CI, test-plan §9 Pipeline structure, arch §Established Decisions [CI/CD]).

The cause is elevation, and this chunk acts on it. It is established by direct variation with a control on
both sides — elevated and non-elevated on one dev host differing on `IsElevatedAdmin` alone, the non-elevated
side a recorded green at 12 passing / 2 skipped — and run 35079315258 is a third independent confirmation:
`IsElevatedAdmin: True` on the runner with every rival cause measured away in the same run (driver resolution,
driver/runtime/browser skew at a coherent 152.0.4191.66 triple, the 152 floor, all five Edge policy keys
absent, app alive, WebView2 running, no port file anywhere scanned). The **mechanism** behind that cause stays
`hypothesis:`-marked at its source and is not derivable from this repo — this plan states the cause and never
the mechanism.

The chunk therefore attempts outcome **(A)**, a green arm via a limited-token launch of the wdio leg, and
pre-commits outcome **(B)**, a ratified exclusion, if the run does not produce the endpoint. Both are what the
route entry allows and what `v3-02`'s acceptance already names. Because each CI run costs ~12 minutes and the
decisive behaviour is observable only on the runner, the same run additionally probes a second candidate route
the CARRY never names — `--remote-debugging-pipe`, which msedgedriver's own log recommends over the port file
— as a `continue-on-error` diagnostic that can never decide the gate (operator-chosen at the P4 fork). Two
obligations folded into `v3-02` at the 2026-09-11 route Phase 4 are discharged here: the WebView2 float's
pin-or-retire disposition, whose stated exit condition IS this terminal's fork, and the landmark measurement,
settled below.

- **Dropping the token at the wdio spawn site — rejected.** `wdio.conf.ts:405` is three levels above the app
  in the measured chain (msedgedriver launches it), so a drop there leaves node/wdio elevated and complicates
  attribution for no gain. The step-level drop covers every descendant with one change.
- **A `runas` form that prompts for credentials — rejected.** The headless invariant forbids an interactive

  silently break the release gate. The mechanism must be non-interactive.
- **Reaching outcome (B) by relaxing the gate — rejected, and forbidden by three extracts independently.**
  No `continue-on-error` on the asserting step, no disabling of the strict arm, no touching the handle guards.
- **Concretizing `v3-02`'s acceptance into the token-drop clause — rejected.** The decisive premise (does the
  drop produce the endpoint?) is exactly what this chunk measures, so clauses downstream of it would be
  WEAKER than the outcome they replace. The acceptance is already concrete about the printed verdict and the
  counts, and research confirms `Assert-A11yVerdict` implements precisely that — so it is **premise-checked,
  not re-worded**, and stays outcome-level across the fork.
- **A second browser-automation stack (puppeteer / CDP attach) to obtain a session — banned** (a11y-plan §11
  Anti-Patterns → CI + §3 tool pick; arch §Cross-cutting Patterns Scope law).
- **An inbound listener in a shipped binary to expose the endpoint — banned** (security-plan §Security
  Anti-Patterns → Universal; the `4444`/`4445` carve-out does not extend to `conductor-tauri`).
