## Constraints & rejected approaches
- **Deriving the posture from the environment — REJECTED.** A forgotten `L4_DETERMINISTIC=true` would silently become
  a real-model run and downgrade the deterministic suite's refusal (security-plan §Security Anti-Patterns → Universal).
- **A per-invocation `--real-model` flag — REJECTED at P4 (operator).** A forgotten flag grades the scenario under
  canned L4 with an indistinguishable envelope.
- **Setting or unsetting any `ANDROMEDA_PULSE_*` handle from the harness or a test — REJECTED** (READ SET: read, never
  written). Removing `RUST_LOG` for the capture invocation touches no READ SET handle.
- **Naming P-033 (or any cluster id) now — REJECTED (lean).** v3-10 moves the cluster's pin and the committed matrix
  together.
- **Grading through an `[[expected]]` `Contains` — REJECTED.** The composed text unions every active incident's report
  and the list fields (`extract.rs:90-103`), so it can express neither rank nor attribution.
- **A production self-obs line carrying hypothesis text, or in-process grading — REJECTED at P4 (operator).**
- **Re-driving after any graded outcome (Pass, miss, or a model-side Blocked) — REJECTED** (posture §The grading
  rule).
- **A long burst train as keep-alive — REJECTED.** Pulse refreshes `updated_at_unix_nano` only on registry writes
  (`crates/triage/src/incident/registry.rs:305-313`; auto-resolve reads it at `:322`), so a dismissed digest keeps
  nothing alive. The capture polls instead.
- **Skipping or softening the preflight canary under the real model — REJECTED** (never downgrade a preflight that
  runs). A dismissed canary is an honest `Blocked`.
- **Firing `boot` (or any preflight) before the leg — REJECTED** (`verification-harness.md:53` (a)).
- **A new `service` field on `EmissionSpec` — REJECTED.** The whole-word rule separates `conductor` from
  `conductor-canary`; a new identity would need arch registration and a model change for no grading gain.
- **Editing the posture's grading rule, launch posture, window rule or census — out of bounds.** Only its falsified
  mechanism clauses carry dated corrections.
