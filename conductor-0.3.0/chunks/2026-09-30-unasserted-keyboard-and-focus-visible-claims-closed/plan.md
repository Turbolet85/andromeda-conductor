  leaves `v3-03` unclaimable without weakening its acceptance.
- Single-letter k9s keys — rejected (P4 fork): NVDA browse mode swallows letters and the picker input needs them. The
  design-system register is amended at wrap instead.

  capabilities widening is the playbook's `Boundary widening` escalate pattern. A webview `keydown` listener reaches

  `CONDUCTOR_RUNS_DIR` (`App.tsx:202-229`, `wdio.conf.ts:373`): a `Blocked` record lands in the fixture, and with a

  (verification-harness.md 2026-08-16, 2026-08-19); one run with two holds carries all four shortcuts.
- `aria-selected` on the `<tr>` — do not. A plain table row is not a selectable-row composite; `aria-current` is the
  picker's shipped precedent and a11y-plan §5 admits either.
- Keeping the scroll `<div>` focusable beside focusable rows — do not. That makes two tab stops for one region, against
  the overseer's one-stop ruling, and moves the SR leg's Tab rows twice.
- Changing button TEXT to carry the key — do not: `button=Start` selectors and the restoration-by-name checks key on

  the `sr-empty` / `sr-error` subjects (`:394`).
- Grading hold decisions by the dialog closing — do not. Proceed and Abort both close it; only the backend's
  `: Go (` / `: No-Go (` lines discriminate them.

## Implementation notes
- **cmdk Enter interplay.** Inside the picker, cmdk's own Enter handling selects the highlighted item. The window
  listener skips a `defaultPrevented` event, so Ctrl+Enter pressed IN the picker input may only select. The driven spec
  starts from a matrix row, which is the non-activating position a11y-plan §5 means. Do not move the listener to the
  capture phase to "fix" this: that would make Ctrl+Enter change the selection and start in one keystroke.
- **Log path.** The Tauri backend log for the driven suite is `runs/driven/logs/conductor-tauri.jsonl`
  (`runs_dir.parent()/logs`, obs-plan §3 Log file location). The spec reads only the lines added after its own baseline
  count, because the file persists across runs.
- **`No-Go` spelling.** The label is `No-Go` with a hyphen (`pause.rs:43`). `: Go (` does not match `: No-Go (`,
  which is why the atoms include the leading colon and space.
- **Stop does not cancel a scenario in flight.** `drive_run` polls abort between scenarios and after the last
  (`drive.rs:75-93`). So after Ctrl+. the second scenario still runs to its hold, which is what lets Ctrl+Enter proceed
  it. The titlebar reads `aborted` immediately (`App.tsx:241`), and the final `Aborted` stage confirms it.
- **Count update.** The first scenario's progress event (`drive.rs:83-86`) sets the titlebar count to `1` only AFTER
  hold 1 resolves, which is exactly when focus has just been restored to the row. Waiting for `1` and re-reading
  `activeElement` is the no-focus-steal witness.
- **SR regrade runs HERE (P5 condition).** Three SR rows Tab into the coverage region: S0-09
  (`screen-reader.e2e.ts:430`), E0-05 (`:591`) and E0-09 (`:601`). Their DOM assertion is
