## Implementation notes
- **Function reach — the B4 answer** (research.md §Function reach; `inputs#I1` §3). When the window goes, four
  functions lose their only entry point. All four are given their command by the next entry, `Panel-shaped types
  retired` (`:13`), whose text is "command line reaches every function":
  1. **The catalogue listing** (the picker): there is no listing verb. A command word is new, so `:13` asks the
     operator for it.
  2. **A graceful mid-run stop**: Ctrl-C ends the process; `drive_run`'s abort flag has no CLI caller.
  3. **A past run's load-envelope standing**: `report` prints the results table only.
  4. **A hold's `[[checklist]]` items**: the CLI hold prints scenario · P-ID · step · prompt.

  `Window grading retired` (`:77`) later removes the hold and checklist themselves. Until `:13` wraps, the four are
